## 현재 경험

- 첫 건반 입력으로 Web Audio를 활성화한다. 시작 버튼과 모델 다운로드가 없다.
- 실제 DOM 건반과 물리 키보드, 다중 포인터 터치, 가로 글리산도, 서스테인, 음량을 지원한다.
- 넓은 화면 C4~C6, 700px 이하 C4~C5. 흰 건반뿐 아니라 검은 건반도 연주된다.
- 같은 음 상태를 버튼, 합성음, 첫 장면의 기구 모형에 전달한다. 마지막 연주 음과 누른 시간을 다음 관찰로 이어받는다.
- 관찰 모형은 3차원 좌표를 Canvas 2D로 투영한 도형이다. 드래그/방향키 회전, 부품 간격, 직전 동작 3배 느린 무음 관찰을 지원한다.
- 마지막에는 사물 원리와 분리한 실제 구현 기록 및 한계를 보여준다.

## 한계와 발행 전 작업

실제 녹음 음원, 정밀한 물리 음향, 실측 피아노 전체 모델이 아니다. 이스케이프먼트 등 세부 기구는 생략했다. 타건 속도는 일정하다. 88건반, 조율·고장·수리는 미구현이다. 실제 iPhone Safari·Android Chrome에서 음향과 다중 터치를 확인해야 한다.

검토용 페이지는 `noindex,nofollow`다. 최종 주소와 발행 번호를 확정하지 않았으므로 canonical/og:url을 추측해 넣지 않았다. 정식 발행 시 확정 URL, 실제 대표 이미지와 공유 메타데이터, 승인된 글로벌 헤더·더보기·발행 데이터와의 연결을 별도 처리해야 한다. 현재 첫 화면은 사용자의 작은 굳이구지 표기 지시를 적용한 독립된 **콘텐츠 시제품**이며 별도 서비스나 배포 프로젝트를 만들지 않았다.

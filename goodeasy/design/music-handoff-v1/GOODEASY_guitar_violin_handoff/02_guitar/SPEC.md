# 02 기타 · 어쿠스틱 6현

## 도면 좌표 (모두 시각화용 가정; SVG viewBox px)
- desktop 1440×900: 본체 중심 (850,445), 외형 ellipse rx275/ry345, 사운드홀 중심 (850,380) 반지름 76, 브리지 y615, 줄 시작 y260, 새들 y605.
- desktop 현 중심 x = 797.5, 818.5, 839.5, 860.5, 881.5, 902.5. 위→아래 줄 번호가 아닌 **도면의 왼쪽→오른쪽** 순서 E2/A2/D3/G3/B3/E4. 실제 기타를 바라보는 관점의 줄 번호와 혼동 금지.
- mobile 390×844: 본체 중심 (210.6,420), 외형 rx145/ry235, 사운드홀 (210.6,355) 반지름 54, 브리지 y558, 새들 y548, 줄 시작 y285.
- mobile 현 중심 x = 168.1,185.1,202.1,219.1,236.1,253.1.
- 실제 선과 동일한 x 중심의 투명 히트 영역: desktop 폭 14px, mobile 폭 17px. `data-string` 사용. **이 히트폭은 포인터 충돌 판정용**이며 44px 독립 터치 목표를 만족하지 않으므로 모바일은 화면 하단의 44×44px 이상 대체 현 선택 버튼을 반드시 구현할 것. SVG 시안에는 그 버튼을 여는 자리만 표시함.
- 문자열 좌표는 도면용, 실제 3D 모델의 현 길이·현간 간격·기타 치수가 아님.

## 부품 / 역할 / 포인터
- Strings(현): 여섯 개 선 각각; 진동 시작. 각 현 SVG `data-string` 히트영역이 대응 선과 동일 x축.
- Saddle(새들): 브리지 위 밝은 얇은 띠. 현의 지지점.
- Bridge(브리지): 몸통 아래쪽 짙은 목재 가로 부품. 현 진동을 상판에 전달.
- Soundboard/Top(상판): 기타 전면 목재. 브리지에서 전달된 진동으로 소리 방사.
- Sound hole(사운드홀): 몸통 가운데 검은 원형 개구. 공명통 내부와 외부 공기 결합.
- Sides/Back(측판·후판): 몸통 공명 구조. 도면에서 실제 단면은 생략.
- Neck/Nut/Tuners(넥/너트/튜너): 최종 3D에서 별도 자산. 현 지지와 장력 조절; 이 SVG는 전체 넥을 묘사하지 않음.

## 동작 / 음향
- 클릭: 해당 현을 한 번 뜯음. 드래그: 포인터 경로가 서로 다른 현의 중심선을 통과할 때마다 1회 뜯음. 같은 현 위에서 포인터가 머무르는 동안 반복 발음 금지.
- 주파수 A4=440Hz 평균율 기준: E2 82.4069, A2 110, D3 146.8324, G3 195.9977, B3 246.9417, E4 329.6276 Hz.
- `plucked` 이벤트 `{stringId, pitch, frequencyHz, atMs, velocityNorm, source}`. 속도는 횡방향 이동량에서 추정한 0..1의 **합성 파라미터**, 실측 타현 속도가 아님.
- Audio: Web Audio API 감쇠하는 합성 파형/필터 + 짧은 어택. Karplus–Strong은 선택 사항. 실제 어쿠스틱 기타 샘플·물리 모델 정확도 주장 금지.
- 관찰: 현 변위(단순 감쇠) → 브리지 전달 → 상판 모드(설명용) → 공명통/사운드홀. 실제 FEM/실측 음향판 모델 아님.
- 마우스/터치 pointer capture, pointercancel 종료. 버튼 대안: 6개 현 이름의 native button, focus-visible, Enter/Space 발음, aria-label=`6번 줄 미(E2) 튕기기` 등.

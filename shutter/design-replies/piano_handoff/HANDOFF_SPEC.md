# 굳이구지 03 → 구현 인계 보완 v1.1

**대상:** VISUAL NEWSIS 피아노 개별 콘텐츠 2단계 관찰 화면. **기술:** 정적 HTML, CSS, 순수 JavaScript, 로컬 SVG. React·서버 필수 아님. **기준:** 앞선 이미지 보드는 미술 방향 참고이며 기구 검증 도면이나 실제 작동 화면이 아님.

## 1. 부품 용어·포인터 정정

좌표는 카메라 화면 픽셀이 아닌 **3D 모델 로컬 좌표의 앵커**를 사용한다. 포인터는 메시의 중심이 아닌 실제 기능 표면/축에 고정한다. 이미지 보드의 `Crippa`처럼 보이는 문자는 오류: **위펜(Wippen)**으로 통일한다. `잭(Jack)`을 해머 목재 생크에, `캡스턴(Capstan)`을 액션 레일/위펜에 꽂은 기존 포인터는 무효다.

| UI 한국어 | 영문 | 기능 | 포인터가 가리킬 정확한 대상 | 주의 |
|---|---|---|---|---|
| 건반 | Key | 손의 입력을 후단 상승으로 변환 | 해당 음의 흰/검은 건반 전면 상면 | 주변 건반과 구분 |
| 밸런스 핀 | Balance pin | 건반 지지/회전 기준 | 건반 중앙 지지점의 금속 핀 | 앞쪽 가이드 핀 아님 |
| 캡스턴 | Capstan screw | 건반 후단에서 위펜 하부를 민다 | 건반 뒤쪽에 솟은 조정 나사 머리와 위펜 접촉부 | 레일이나 해머 기둥을 가리키지 않음 |
| 위펜 | Wippen / Whippen | 잭·반복 레버를 싣는 중간 지렛대 | 위펜 몸체 중앙, 회전축과 잭 베이스 사이 | Crippa 표기 금지 |
| 위펜 플랜지 | Wippen flange | 위펜의 고정 회전축 | 액션 레일에 고정된 위펜 피벗 | 목재 몸체와 구분 |
| 잭 | Jack | 너클을 밀어 해머를 가속한 뒤 이탈 | 위펜 위의 가늘고 직립한 회전 레버 **자체** | 해머 생크나 너클 아님 |
| 반복 레버 | Repetition lever | 부분 복귀에서 해머 지지·재타격 준비 | 너클 아래의 반복 레버 상면/몸체 | 잭과 별도 객체 |
| 너클 | Knuckle / Roller | 잭·반복 레버가 접촉하는 해머측 부품 | 해머 생크 아래의 가죽 덮인 둥근 롤러 | 해머 펠트 아님 |
| 해머 생크 | Hammer shank | 회전축에서 해머 헤드로 힘 전달 | 길고 가는 목재 생크 중간 | 해머 펠트와 구분 |
| 해머 펠트 | Hammer felt | 현과 순간 접촉해 타격 | 해머 헤드 최상단의 펠트 타격면 | 현 접촉면에 포인터 끝 |
| 해머 플랜지 | Hammer flange | 해머 회전축 지지 | 생크 후단의 고정 피벗 | 너클 아님 |
| 백체크 | Backcheck | 반발한 해머를 받음 | 건반 후단에서 솟은 펠트/가죽 받침의 접촉면 | 해머와 항상 접촉하지 않음 |
| 이탈 조정 버튼 | Let-off regulating button | 잭 회피 회전 시점 결정 | 잭 꼬리가 닿는 고정 조정면 | 움직이는 잭과 구분 |
| 현 | String | 타격 후 진동 | 해당 음의 해머가 치는 실제 현(복수 현 가능) | 옆 음 현 제외 |
| 댐퍼 | Damper | 현 진동 억제/페달에 따라 상승 | 해당 음 현 위의 펠트 접촉면 | 해머와 혼동 금지 |

**라벨 표시:** 기본은 선택 1개 + 맥락 최대 2개(모바일 선택 1개). 포인터 앵커는 `mesh.getWorldPosition()`이 아니라 명시적 로컬 앵커를 `localToWorld`로 변환해 매 프레임 투영. 가림(occlusion)·뷰포트 밖·라벨 교차 시 맥락 라벨부터 숨긴다. 카메라 전환 시 보간하고 접근성 부품 목록은 항상 별도로 제공한다. 모든 이름은 기구 모델 담당자의 실물 대조 검수 전까지 `reviewRequired=true`.

## 2. 정정된 타임라인과 이벤트

6개 **표시 구간**(길이는 실제 연주 기록 또는 시뮬레이션 값으로 결정; 균등 1/6을 물리 시간으로 해석하지 말 것):

| 번호 | UI 명칭 | 진입 조건/기구 이벤트 | 표시 및 오디오 |
|---|---|---|---|
| 00 | REST · 대기 | 건반 위, 댐퍼 접촉(페달 OFF 기준) | 무음 |
| 01 | 건반 누름·전달 | keyDown → 건반 후단 상승 → 캡스턴→위펜→잭 추진, 댐퍼 상승 | 힘 전달 경로 표시 |
| 02 | **잭 이탈** | 잭 꼬리가 조정면과 접촉, 잭이 너클에서 벗어남; 해머는 관성 운동 | 잭·너클 간격 확대 강조 |
| 03 | **타현** | 해머 펠트가 현과 순간 접촉, 충격 전달 | 진동 시작; 관찰 재생은 무음 |
| 04 | 반발·백체크 / 현 진동 | 해머 반발 후 백체크 포착(건반 유지 시); 현은 계속 진동 | 해머는 현에서 떨어짐 |
| 05 | 손 뗌·댐퍼 분기 | keyUp → 기구 복귀; pedal OFF이면 댐퍼 하강·소리 감쇠, pedal ON이면 댐퍼 상승 유지; pedalUp에서 하강 | `PEDAL ON / OFF` 분기 표시 |

**불변 순서:** `keyDown < jackEscapement < hammerStrike < hammerRebound` (시간 동률 허용하지 않음). `hammer release`라는 모호한 레이블 금지. **잭 이탈**은 타현 *전*, **해머 반발**은 타현 *후*. 건반을 누른 채 해머가 백체크에 머무를 수 있다. 반복 타건은 건반의 부분 복귀/잭 재설정 조건이 충족될 때만 가능하다. pedal ON 시 keyUp 이후 현 진동 지속, pedalUp에서 댐퍼 접촉. 실제 현 진동·음향 감쇠는 별도 오디오/물리 모델이며 UI 애니메이션의 정밀도와 동일시하지 않는다.

`observationPlayback`은 항상 **무음**; 0.25/0.5/1/2×는 시각화 시간 배율이다. 실제 연주 오디오는 1단계에서만 사용. 시간축 스크럽 시 paused. 분해 전환 시 재생 정지, 조립 복귀 완료 후 paused 상태. 원본 `lastPerformance`(음, 누른 길이, 페달 이벤트)는 불변, 별도 `selectedObservationNote` 변경은 기록을 덮어쓰지 않는다.

## 3. 픽셀 레이아웃 및 레이어

**레이어 순서(z-index):** 0 `scene-canvas` (3D 모델·텍스처·광원), 10 `scene-effects`(선택 외곽/접촉 강조), 20 `scene-labels`(투영된 주석, 기본 pointer-events:none), 30 `scene-header`(제목·연주 스냅샷), 40 `scene-controls`(재생·타임라인), 50 `aux-toolbar`, 60 `popover/sheet`, 70 `tooltip`, 80 `status/toast`, 90 `modal/fallback`. 3D 캔버스는 독립 레이어, UI DOM과 렌더 분리. 모형이 읽히는 영역 위에 불투명 카드 배치 금지.

### 데스크톱 1440×900 (CSS 픽셀, 브라우저 viewport 기준)
- 전체 `position:relative; min-height:100dvh`, 내부 안전 여백 좌우 32, 상단 24, 하단 24.
- 헤더 `x=32,y=24,w=1376,h=48` (워드마크 160, 보조 링크 오른쪽; 관찰 재생은 헤더에 두지 않음).
- 3D 장면 `x=0,y=72,w=1440,h=676` (오른쪽/중앙 주 기구, 왼쪽 제목의 빈 공간 유지). 중요한 건반·위펜·해머·현은 화면 `x=350..1290,y=130..665` 안에 들어오도록 카메라 맞춤.
- 제목·설명 `x=48,y=125,w<=290`, 연주 정보 `x=48,y=340,w=240`; 모델 실루엣과 충돌 시 정보 패널을 위쪽/왼쪽으로 이동하거나 접는다.
- 주 라벨 앵커 후보: 모델 좌·우 외곽 24px 이격, 라벨 박스 최대 176×60, 라벨 간 최소 12px, 화면 가장자리 24px; 기본 최대 3개.
- 하단 조작대 `x=24,y=748,w=1392,h=128`; 좌측 재생/처음 `w=144`, 타임라인 `w>=560`, 속도 `w=180`, 보조 도구 `w=260`. 재생 버튼 56×56, 일반 컨트롤 44×44. 내부 간격 12~20px. 푸터 크레딧은 하단 바를 가리지 않는 별도 문서 푸터.
- 선택 부품 확대: 3D 카메라만 해당 부품으로 이동, 우측 정보 패널 `x=1090,y=110,w=302,h<=390`, 선택 라벨 1개, 닫기 44×44. 분해: 부품 오프셋을 장면 좌표에서 적용, 조작대의 재생/스크럽 disabled+이유 표시.

### 모바일 세로 390×844
- 헤더 `x=16,y=safeTop+8,w=358,h=44`; 스냅샷 줄 `x=16,y=safeTop+58,h=32`.
- 3D 관찰 `x=0,y=safeTop+96,w=390,h≈426` (남은 높이에 따라 flex). 모바일 카메라는 선택 기구를 크게, 이웃 1~2개만 희미하게. 제목은 한 줄 또는 두 줄, 모델 위 긴 문장 금지.
- 라벨 최대 1개 `max-width:160`, 화면 가장자리 12px, 포인터와 조작대 사이 12px 유지.
- 하단 고정 도크 `left=0,right=0,bottom=0`, 높이 `min(296px, 42dvh)+safeBottom`, 패딩 `12px 16px calc(12px + env(safe-area-inset-bottom))`; 상단 단계 정보 36, 타임라인 48, 재생·속도 56, 보조 아이콘 52. 시트가 열리면 도크 위로 표시, 닫기 48×48.
- 390×844는 CSS viewport 예시이며 주소창 변동에 따라 `100dvh`를 사용. `100vh` 고정 금지.

### 320px 작은 세로
- 좌우 패딩 12, 버튼 최소 44×44, 도크 최대 `min(328px, 49dvh)+safeBottom`, 2열 또는 가로 스크롤 가능한 보조 도구(주 재생·타임라인은 스크롤 불가).
- 제목 최대 2줄, 부품 설명은 별도 하단 시트, 라벨 최대 1개·최대 폭 128. 속도는 축약된 단일 선택 버튼으로 열고 메뉴에서 4개 배율 선택.
- 텍스트 200% 확대 시 도크는 내용에 맞춰 세로 스크롤하고, 타임라인·재생은 sticky; 화면 높이가 매우 작으면 상세 부품 설명을 별도 페이지/시트로 이동.

### 모바일 가로 / breakpoint
- `<=359px`: compact portrait; `360..679px`: portrait; `680..1023px`: tablet/landscape; `>=1024px`: desktop.
- `orientation:landscape` + 높이 `<=500px`: 3D 뷰 좌측 68%, 오른쪽 조작 컬럼 32%, 최소 터치 44px, 타임라인 세로 스크럽 대신 가로 트랙 유지; 헤더 축약. 가로 회전 **권장 가능**, 강제하지 않음.
- 모든 모드에서 `safe-area-inset-{top,right,bottom,left}` 사용. `viewport-fit=cover` 설정, `overflow:hidden`을 body 전체에 무조건 적용하지 않음.

### 라벨 충돌 알고리즘
1. 3D 앵커를 screen 좌표로 투영하고 깊이/가림 검사. 2. 우선순위 `selected > step-relevant > context`. 3. 후보 위치 `[right, left, top, bottom]` 중 화면/컨트롤/제목 제외영역과 교차 면적 최소 선택. 4. 라벨 간 12px, 화면 테두리 12px(데스크톱 24px). 5. 실패 시 맥락 라벨 숨김, 선택 라벨은 가장 가까운 가장자리로 도킹하고 연결선 사용. 6. DOM 텍스트는 시각 라벨과 별개로 부품 목록에서 접근 가능.

### 제스처 우선순위
`modal/sheet > toolbar/button > timeline slider > selected-part tap > 3D orbit > page scroll`.
- 타임라인만 `touch-action:none` + pointer capture. 슬라이더 이외 3D 영역은 한 손가락 드래그로 orbit(수직 스크롤은 관찰 뷰에 명시된 핸들/제스처 안내를 제공); 두 손가락 pinch 줌. 모바일 일반 문서 영역은 `touch-action:pan-y`.
- 탭 이동 8px 이하, 250ms 이하를 부품 선택으로 처리하는 **초기 권장값**; 장치별 검수. 부품 선택은 `pointerup`에서 판정, 드래그 끝 선택 금지.
- 메뉴 열림/닫힘: Esc 또는 닫기, 포커스 원래 트리거 복귀. 모바일 하단 시트는 내부 스크롤을 우선하고 장면 orbit 중지.

## 4. 접근성·상태

재생 상태 `empty|ready|playing|paused|ended|loading|error`; 조립 `assembled|exploding|exploded|reassembling`; 카메라 `default|side|oblique|part`. `exploding/exploded/reassembling`에서는 재생·타임라인 disabled. 오류는 `role=alert`, 재시도/정적 6단계 대안. 전체 화면 불가 시 인라인 확대. 스크린리더 이름: `관찰 재생`, `관찰 일시정지`, `처음부터 보기`, `작동 단계 타임라인`, `관찰 속도`, `부품 선택`, `분해 보기`, `조립 상태로 복귀`, `시점 초기화`, `전체 화면`. 타임라인 `role=slider`와 `aria-valuetext`(예: `3단계 잭 이탈`). 화살표 단계 이동, Shift+화살표 미세 이동, Home/End 양끝. 전역 Space 단축키 금지(피아노 건반 충돌). `prefers-reduced-motion`이면 장면 전환은 컷, 작동 단계는 사용자가 명시적으로 재생할 때만 실행.

## 5. 자산 및 검증 상태

| 대상 | 필요한 제작물 | 아직 검증/제작해야 할 항목 |
|---|---|---|
| 건반 | 둥근 모서리 목재 키스틱, 아이보리/흑색 상판, 밸런스 홀·가이드, 캡스턴 나사 | 실제 치수·축·접촉 높이 미확인 |
| 위펜 | 곡선 측면 윤곽, 테이퍼 몸체, 플랜지, 핀·부싱, 접촉 펠트 | 캡스턴 접촉점 운동학 미검증 |
| 잭/반복 레버 | 개별 곡선 메시, 얇은 레버, 회전 핀, 스프링과 접촉면 | 너클과 이탈 궤적 미검증 |
| 해머 | 생크 테이퍼, 목재 코어, 라운드 펠트 단면, 너클 가죽·플랜지 | 타현 거리·회전각·반발 충돌 미검증 |
| 백체크 | 곡선 지지 와이어/목재, 가죽·펠트 받침 | 반발 후 포착 위치 미검증 |
| 현/댐퍼 | 음별 현 묶음, 금속 질감, 펠트 블록, 수직 가이드 | 현 진동은 교육용 근사, 실제 파동 모델 없음 |
| 하우징 | 액션 레일, 흑색 외장, 주변 건반/인접 액션 | 악기별 실제 조립 간격 미확인 |
| PBR 텍스처 | 목재 grain/normal/roughness, 펠트 섬유 normal, 금속 roughness, 가죽 | 저작권/라이선스 확인 후 자체 제작·허가 자산만 사용 |
| 라이팅 | warm key 3000–3600K, cool fill 4500–5500K, soft rim, 접촉 그림자 | 기기별 톤매핑·노출 검수 필요 |
| UI | `icons.svg` sprite, `tokens.css`, HTML 템플릿, JS 상태 머신 | 실기기 터치·스크린리더·성능 검수 필요 |

**중요:** 기존 v0.2 2D 관계도는 제조용 CAD가 아니다. 캡스턴↔위펜, 잭↔너클, 반복 레버, 백체크 등 **접촉점·강체 구속·치수는 실측 또는 별도 운동학 검증이 끝나지 않았다.** 이미지 보드의 정교한 렌더는 미술 목표이고, 실제 3D 모델·리깅·텍스처 완성 자산이 아니다. 시각화용 가정은 파일·코드에서 `assumption`으로 표시하고 검수 전 `validated`로 바꾸지 않는다.

## 6. 크레딧 정정

`크리에이티브 디렉터 = 안재현`은 **(1) 첫 체험 하단, (2) 제작 과정, (3) 사이트 푸터** 세 위치에 유지한다. 이전 명세의 ‘제작 과정 하단에만’은 폐기. 관찰 기구 위에 큰 크레딧을 얹지 않는다.

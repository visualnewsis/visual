## 회사 PC에서 이어받기

이 자료는 **codex/braille-100-assets** 브랜치에 보관합니다. 기존 main 배포 workflow가 전체 저장소를 배포하므로, 기사 공개와 자료 보관을 구분하기 위해 자료 전용 브랜치를 사용합니다.

새 사본을 받을 때:

```sh
git clone --branch codex/braille-100-assets --single-branch https://github.com/visualnewsis/visual.git visual-braille-100
cd visual-braille-100
```

기존 회사 PC 사본은 미커밋 변경을 먼저 보존하고 fetch한 뒤, 별도 worktree에서 시작할 수 있습니다:

```sh
git fetch origin
git worktree add -b codex/braille-100-work ../visual-braille-100 origin/codex/braille-100-assets
```

Windows Codex 앱에서는 원격 Git 명령에 `C:\Program Files\Git\cmd\git.exe`를 사용합니다. 작업 시작 때 최신 origin/main과 AGENTS.md를 확인하세요. 이 브랜치가 장기간 사용되면 최신 main을 안전하게 반영해야 합니다.

GPT·Claude에 전달할 때는 이 README와 PHOTO-CATALOG 링크를 함께 전달하고, 이미지를 실제로 열어 본 뒤 사진번호로 검수 의견을 남기도록 요청하면 됩니다. 링크만으로 모델이 사진을 자동으로 봤다고 간주하지 마세요. 계정/도구 접근이 안 되면 해당 원본 파일을 첨부합니다.

프로젝트 정책의 단일 원본은 저장소 루트 AGENTS.md입니다. 공용 랜딩·헤더·자동화는 이번 보존 작업에서 변경하지 않았습니다.

# 뉴스맵부심 (가칭)

VISUAL NEWSIS의 별도 지도 탐색 페이지. 편집# 작품이 아니며 작품 번호를 부여하지 않았다. 현재는 공개 뉴시스 기사 일부를 수집한 로컬 시제품이고, 공용 랜딩·공통 asset·배포 workflow는 수정하지 않았다.

## 실행

서비스 파일은 `index.html`, `style.css`, `core.js`, `app.js`, `basemap.js`, `data/`, `vendor/`, `assets/`다. 별도 빌드나 상시 서버 없이 정적 호스팅에서 동작하며 로컬 `index.html`로도 지역 검색·필터와 기사 목록을 사용할 수 있다. 외부 배경지도와 기사 이미지는 인터넷 연결이 필요하다. 서버 보안 정책이나 연결 오류로 외부 지도를 사용할 수 없으면 자체 행정구역 지도로 전환한다. 이 지도는 시군구·읍면동 범위를 보여주며 도로·건물 지도는 아니다. 공통 서버 보안 설정은 변경하지 않는다. 미리보기에서는 저장소 루트에서 정적 HTTP 서버를 실행해 `/newsmap/`을 연다.

## 동작과 위치 기준

- 전국 행정구역 검색, 시도 → 시군구 → 읍면동 선택, 지도 확대·이동, 기간·새 기사 필터, 지도 화면 범위 필터.
- 동네 기사는 상위 구·시에도 포함한다. 구·시까지만 확인된 기사를 하위 동네에 넣지 않는다.
- 지도 원은 지역별 기사 묶음의 대표 위치다. 사건의 정확한 좌표가 아니다. 좁은 지도에서는 인접 지역을 묶으며 누르면 확대된다.
- 법정동·통칭인 성수동/역삼동/전포동은 번호가 붙은 행정동과 별도 지역으로 저장한다. 행정동 경계들을 묶어 만든 참고 범위이며 법정동 경계를 대체하지 않는다.
- 첫 방문 파동은 실제 현재 시각 기준 최근 24시간, 재방문은 이 브라우저 마지막 방문 이후 발행된 기사다. localStorage가 차단되면 첫 방문 기준을 사용한다. 파동 끄기와 reduced-motion을 지원한다.
- URL에 지역·기간·새 기사 선택 상태를 보존한다. ‘내 위치 보기’를 누를 때만 브라우저 위치 권한을 요청한다. 좌표와 정확도는 메모리에서만 사용하고 별도 서버나 저장소에 기록하지 않는다. 전국 행정동 경계에 현재 좌표가 포함되는지 브라우저 안에서 판별해 해당 지역 기사를 보여준다. 외부 역지오코딩 API는 사용하지 않는다. 배경지도 타일은 이동한 지도 범위에 따라 OpenStreetMap에서 불러온다. HTTPS 또는 localhost가 필요하다.

## 기사 데이터 갱신

`python newsmap/tools/collect_news.py`를 실행하면 공식 RSS 4개와 동네 탐색용 실제 기사 일부의 공개 메타데이터를 모아 `data/articles.js`를 갱신한다. RSS 오류·분류 결과 부족 시 기존 데이터를 유지한다. 페이지의 다시 확인 버튼은 배포된 스냅샷 파일만 다시 읽으며 뉴시스에 실시간 수집을 요청하지 않는다.

자동화 연결 전 단계다. 내부 기사 공급 경로가 확보되면 같은 데이터 형식으로 교체 가능하다. 공유 배포·기사 수집 workflow는 별도 승인 후 연결한다. 현재 `noindex`이며 정식 발행 때 이를 검토한다.

현재 수집기는 지명 사전에 기반한 보수적 규칙 매칭이다. 기자 발신지·사진 설명은 위치 판단에서 제외하고, 동명이 지역은 상위 지명과 대조한다. 기사별 `evidence`에 위치 판단 근거를 남긴다. 제목과 짧은 리드만으로 판단하기 때문에 기관 이름·인용·복수 지역·법정동 등에서 오류나 누락이 가능하다. 정식 서비스에는 원문 기반 검수 및 편집자가 위치를 확정하는 절차가 필요하다. ‘기사가 없음’은 ‘일이 없음’을 의미하지 않는다. 속보·종합 등 서로 다른 기사 ID의 같은 사건을 묶는 기능은 아직 구현하지 않았다.

## 출처와 준비 도구

- 기사: 뉴시스 공식 RSS 및 공개 기사 메타데이터. 원문은 뉴시스로 연결한다. 본문 전체를 배포하지 않는다.
- 배경지도: © OpenStreetMap contributors. 공개 타일은 시제품용이며 서비스 규모 확정 시 타일 제공 방식과 이용정책을 점검한다.
- 경계: 통계청 SGIS, [vuski/admdongkor](https://github.com/vuski/admdongkor)의 2026-10-01 GeoJSON을 단순화했다. 원출처 표시를 페이지에 유지했다.
- Leaflet 1.9.4: 로컬 `vendor/`, BSD-2-Clause 라이선스 포함.
- `tools/prepare_assets.py`: 최초 경계·지도 asset 준비용. 배포 때 실행할 필요 없음.
- `tools/generate_share.py`: 코드로 그린 공유 이미지 생성용.

## 검증

`node newsmap/tests/rules.cjs`로 계층 포함·하향 추정 금지·기간·재방문·중복 집계·확대 시 지역 정밀도·전국 지역 참조 무결성·기사 URL·JSON-LD·GA 1회 삽입을 검사한다. PC 및 모바일 viewport는 브라우저에서 별도 확인한다. 실제 iPhone Safari/Android Chrome 검증은 별개다.

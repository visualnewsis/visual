## 배경과 복구

기존 공개 국내 화면은 `newsmap/basemap.js`의 자체 행정구역 지도를 사용한다. 한중일 버전은 새 별도 지도 서비스가 아니라 기존 `app.js`의 외부 OpenStreetMap 타일 경로를 사용하는 시안이다. 로컬에서는 외부 타일이 허용돼 주변 국가가 보였고, 공개 서버는 CSP 등에 따라 자체 지도를 사용했다. 원본 국내 데이터·상세 지역 탐색·기사 목록을 없애지 않는다.

호출되면 현재 repository/working tree/main을 먼저 확인하고, 위 Git ref의 `newsmap/app.js`, `basemap.js`, `style.css`, `index.html`, `vendor/leaflet.*`를 현재 구현과 비교한다. 다른 채팅이나 다른 기기에서도 백업명이 같다는 이유로 새 지도를 처음부터 만들지 않는다. 브랜치는 로컬 Git ref이며 원격 업로드 완료로 간주하지 않는다.

복구 시 기존 작업을 덮어쓰지 않고, 필요하면 `git worktree add`로 이 ref의 별도 검토 공간을 만든다. 후속 코드의 `DOMESTIC_BASEMAP`이 `administrative`라면 외부 타일 경로는 `context`로 선택할 수 있게 보존되어 있다. 사용자 요청에 맞춰 해당 설정과 첫 화면만 비교·반영한다. 백업 폴더 전체나 옛 기사 데이터를 현 서비스에 무조건 덮어쓰지 않고, 새 세계 뉴스·필터·공용 헤더·추적 태그·후속 변경은 유지한다.

외부 OpenStreetMap 타일은 인터넷과 실제 서버 CSP/타일 이용 조건의 영향을 받는다. 백업 소스만으로 타일 이미지까지 오프라인 보관한 것은 아니다. 공개 배포 시 외부 타일이 허용되는지 확인하며, 보안 설정과 공용 배포 구조를 임의 변경하지 않는다. PC/모바일, 전국 초기화, 세계와 국내 왕복, 지역 선택·줌·기사 목록을 확인한 뒤 복구한다.

현재 기본 국내 화면은 기존 행정구역 지도를 사용하고, 세계 뉴스 확장은 별도로 유지한다. 이 기록은 해당 백업과 복구 지시이며 다른 프로젝트 정책을 변경하지 않는다.

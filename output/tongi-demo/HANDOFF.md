## 랜딩에서 돌아다니는 동작: 마지막 수정 사항

동작 미리보기는 **좌측 상단 고정**이다. 사용자가 펼쳐 조작하고, 동작을 실행하면 접힌다. 이 테스트 컨트롤은 서비스에 그대로 넣을 UI가 아니다.

1. **선 잡고 올라오기**: 손이 먼저 나타난 뒤 몸이 올라오며 손은 실제 구분선에 남는다. 마지막에 손을 잘못 잘라 흰 사각형이 보이던 문제를 전용 투명 손 PNG로 수정했다. 최종 캡처 `grip-fixed-desktop.png`.
2. **기사 커튼 들기**: 빈 종이를 든 포즈로 대체하는 것이 아니다. 실제 기사 썸네일의 하단을 커튼처럼 올리고 통이가 그 뒤에서 등장한다. 제목·설명과 링크는 유지하고 카드 위치/높이를 밀지 않는다. `curtain-desktop-fixed.png`, `curtain-mobile-fixed.png`가 마지막 수정 캡처다.
3. **옆으로 빼꼼**: 카드 옆 빈 공간 또는 안전한 구분선 여백에서 나온다. 다른 카드의 링크 전체 영역을 가리지 않도록 검사한다.

동시에 통이 하나만 보인다. 자동 등장은 최초 화면을 피하고 스크롤 정지 1.55초 후에만 검토, 간격 90초 이상·페이지당 최대 2회다. 안전한 여백이 없으면 생략한다. 스크롤/리사이즈/메뉴/대화창/비활성 탭에서 중단한다. 숨김은 sessionStorage에 유지된다. reduced-motion에서는 자동 등장을 끈다. 무거운 주제의 본문에는 적용하지 않았다. 현재는 랜딩만 대상이며 커튼 대상 작품도 제한한다.

썸네일과 통이의 상승 시간/이징을 맞췄고 카드 26개의 문서 위치·높이 변화 0px를 확인했다. hover/focus 후 닫힘이 영구 정지하던 문제는 leave/blur 후 1.5초 타이머를 다시 걸도록 고쳤다. 가장 마지막 수정은 자동 커튼 첫 실행에서 lazy 이미지 decode를 기다린 뒤 조건을 재검사하는 경로다. 문법 검사는 했지만 이 마지막 경로의 실제 90초 자동 주기는 다시 기다려 재검증하지 않았다.

## 다음 작업: 굳이구지 조작 안내 (논의 완료, 미구현)

국장 의견은 독자가 무엇을 눌러야 할지 모를 때 통이가 알려주자는 것이다. 삼단 논의 결과 별도 AI 서버 없이 브라우저 상태와 이벤트로 가능하다. 다만 모든 기사에서 자동으로 알아서 안내하는 범용 기능은 아니다.

첫 실험은 굳이구지 키보드 도입부 한 화면, 두 단계만 제안했다. (1) 입력칸에서도 글자를 써볼 수 있다고 안내 (2) 실제 입력 후 기존 `파헤쳐보기` 버튼을 강조한다. 현재 어디에도 구현하지 않았다.

수동 `어디부터 하지?` 도움과, 짧은 시간 실제 키보드 canvas raycast miss 2회일 때 1회 조용히 제안하는 방향이다. 단순 8초 무행동만으로 헤맸다고 판단하지 않는다. 드래그·스크롤·UI 클릭·WebGL 장애를 miss에서 제외하고, 임계값은 사용자 검증 전 제안치다.

실제 파일은 최신 main의 `goodeasy/assets/landing-keyboard.js`. 입력 대상 `#landing-typing`, 3D canvas `#landing-keyboard-canvas`, 다음 이동 `.hero-next`. 일반 입력은 input/compositionend, 3D 클릭은 change 이벤트가 발생한다. clear는 별도 처리해야 한다. input 경험은 지운 뒤에도 기억하고, pageshow 복원·실제 WebGL 상태를 고려한다. raycast miss 이벤트는 해당 모듈 내부에서 내보내야 한다.

강제 포커스/스크롤/자동 클릭/음성은 피하고 닫으면 자동 재등장을 멈춘다. 입력 내용 수집·전송 없이 비었는지만 확인한다. WebGL 실패 시 DOM 안내는 유지할 수 있다. 실제 3D 부품을 따라다니는 안내는 카메라 투영·가림·모바일 대응이 더 필요해 별도 범위다. 근거는 `guide-source-evidence.txt`.

## 공개 상태와 문서 이력

예전 외부 공개 샘플은 사용자 요청으로 소유자 전용 접근으로 전환했다. 현재 통이 최신 샘플을 재공개하거나 서비스 배포하지 않았다. 예전 공유 사이트는 오래된 Google 검색 시안이므로 최신본으로 혼동하지 않는다. 공유 사이트 자격 증명·토큰은 인수인계에 포함하지 않는다.

초기 보고서와 `CONCEPT.md`, 이전 README는 전체 검색/Google 우회 등 과거 검토 내용을 포함한다. **현재 범위 판단은 이 문서가 우선**이다. 별도 공용 정책은 저장소 최신 `AGENTS.md`를 읽는다. 사용자가 전체 변경을 main에 합치라고 한 것이 아니라 맥북으로 가져갈 수 있게 GitHub에 보존해 달라고 요청한 상태다.

# 여기뉴스

VISUAL NEWSIS의 별도 지도 탐색 페이지. 편집# 작품이 아니며 작품 번호를 부여하지 않았다. 공개 뉴시스 기사 일부를 10분 주기로 수집하는 정적 서비스다. 관리자 승인으로 메인 랜딩과 공통 메뉴에 진입점을 추가했다.

2026-10-23 서비스명을 **여기뉴스**로 확정했다. 기존 주소 /newsmap/는 유지한다. 이전 이름 ‘뉴스맵부심’은 과거 인수인계·시안에만 남기며, 개발기·제작 후기 제목 후보로 보존한다.

## 실행

서비스 파일은 `index.html`, `style.css`, `core.js`, `app.js`, `basemap.js`, `mobile-sheet.js`, `data/`, `vendor/`, `assets/`다. 별도 빌드나 상시 서버 없이 정적 호스팅에서 동작하며 로컬 `index.html`로도 지역 검색·필터와 기사 목록을 사용할 수 있다. 외부 배경지도와 기사 이미지는 인터넷 연결이 필요하다. 서버 보안 정책이나 연결 오류로 외부 지도를 사용할 수 없으면 자체 행정구역 지도로 전환한다. 이 지도는 시군구·읍면동 범위를 보여주며 도로·건물 지도는 아니다. 공통 서버 보안 설정은 변경하지 않는다. 미리보기에서는 저장소 루트에서 정적 HTTP 서버를 실행해 `/newsmap/`을 연다.

## 동작과 위치 기준

- 전국 행정구역 검색, 시도 → 시군구 → 읍면동 선택, 지도 확대·이동, 기간·새 기사 필터, 지도 화면 범위 필터.
- 모바일 첫 화면은 44px 서비스명 줄 아래 전체 화면을 지도로 사용한다. 검색·기사 목록은 72px 손잡이로 접어 두고 위로 당기거나 눌러 펼친다. 펼친 패널의 기사 목록은 내부 스크롤을 사용하며, 패널 개폐는 지도 확대 비율을 변경하지 않는다. 위·아래 화살표 키로도 패널을 열고 닫을 수 있다. PC는 기존 지도·기사 목록의 좌우 배치를 유지한다.
- 동네 기사는 상위 구·시에도 포함한다. 구·시까지만 확인된 기사를 하위 동네에 넣지 않는다.
- 지도 원은 지역별 기사 묶음의 대표 위치다. 사건의 정확한 좌표가 아니다. 좁은 지도에서는 인접 지역을 묶으며 누르면 확대된다.
- 법정동·통칭인 성수동/역삼동/전포동은 번호가 붙은 행정동과 별도 지역으로 저장한다. 행정동 경계들을 묶어 만든 참고 범위이며 법정동 경계를 대체하지 않는다.
- 첫 방문 파동은 실제 현재 시각 기준 최근 24시간, 재방문은 이 브라우저 마지막 방문 이후 발행된 기사다. localStorage가 차단되면 첫 방문 기준을 사용한다. 새 기사 묶음은 파동이 두 번 확산한 뒤 색상으로 표시하며, 같은 지역·새 기사 조합은 현재 페이지에서 다시 움직이지 않는다. 파동 끄기와 reduced-motion을 지원한다.
- URL에 지역·기간·새 기사·지도 안만 선택 상태를 보존한다. 지도 안만 모드에서는 지도 중심과 확대 비율도 보존하며, 필터·지역 변경 후 브라우저 뒤로/앞으로 가기로 탐색 상태를 복원한다. 지도 이동 자체는 방문 기록을 늘리지 않는다. ‘내 위치 보기’를 누를 때만 브라우저 위치 권한을 요청한다. 좌표와 정확도는 메모리에서만 사용하고 별도 서버나 저장소에 기록하지 않는다. 전국 행정동 경계에 현재 좌표가 포함되는지 브라우저 안에서 판별해 해당 지역 기사를 보여준다. 외부 역지오코딩 API는 사용하지 않는다. 배경지도 타일은 이동한 지도 범위에 따라 OpenStreetMap에서 불러온다. HTTPS 또는 localhost가 필요하다.

## 기사 데이터 갱신

‘내 위치 보기’를 사용한 세션에서는 현재 위치가 공유 링크에 남지 않도록 지도 중심 좌표를 URL에 기록하지 않는다.

`python newsmap/tools/collect_news.py`를 실행하면 공식 RSS 8개와 필요한 신규 기사의 공식 원문 도입부를 모아 `data/articles.js`를 갱신한다. RSS 오류·분류 결과 부족 시 기존 데이터를 유지한다. 페이지의 다시 확인 버튼은 배포된 스냅샷 파일만 다시 읽으며 뉴시스에 실시간 수집을 요청하지 않는다. 수집 이력은 최근 30일 범위에서 최대 10,000건을 보존하고 기사 ID로 중복을 제거한다. 위치 불명확 기사·사진 발신지·인물의 과거 이력 지명은 제외하며 구 단위 기사를 동네로 추정하지 않는다. 확인 중·완료·실패 상태를 구분하고, 읽기 실패 또는 잘못된 기사 데이터가 오면 기존 목록을 유지한다. 목록 위에는 이 브라우저의 새 기사 판정 기준과 현재 목록 범위를 표시한다.

2026-10-23 사용자 선택에 따라 공식 RSS 8종과 필요한 새 기사의 도입부(회당 최대 24건)로 10분 주기 수집을 연결했다. 새 workflow update-here-news.yml은 검증을 통과하고 기사 내용이 바뀐 경우에만 기존 서버의 newsmap/data/articles.js를 교체한다. 기존 전체 사이트 배포 workflow는 유지하며 전체 배포 성공 뒤에도 수집을 재실행한다. 예약 실행·runner 대기 때문에 실제 반영은 지연될 수 있다. 내부 기사 공급 경로가 확보되면 같은 데이터 형식으로 교체 가능하다. 2026-10-22 사용자 요청에 따라 검색 색인을 허용하고 섹션 sitemap에 등록했다. 공용 랜딩에는 노출하지 않는다. 검색 제목·설명·canonical·공유 메타와 JSON-LD를 제공하며, 전용 파비콘과 홈 화면 아이콘은 `tools/generate_icons.py`로 생성한다. 검색엔진 수집·색인 및 순위는 별도이며 자동 기사 갱신 연결을 의미하지 않는다.

현재 수집기는 지명 사전에 기반한 보수적 규칙 매칭이다. 기자 발신지·사진 설명은 위치 판단에서 제외하고, 동명이 지역은 상위 지명과 대조한다. 기사별 `evidence`에 위치 판단 근거를 남긴다. 제목과 짧은 리드만으로 판단하기 때문에 기관 이름·인용·복수 지역·법정동 등에서 오류나 누락이 가능하다. 정식 서비스에는 원문 기반 검수 및 편집자가 위치를 확정하는 절차가 필요하다. ‘기사가 없음’은 ‘일이 없음’을 의미하지 않는다. 속보·종합 등 서로 다른 기사 ID의 같은 사건을 묶는 기능은 아직 구현하지 않았다.

## 수집 운영 검증

python newsmap/tests/collector.py 및 python newsmap/tools/validate_snapshot.py newsmap/data/articles.js로 누적 보존·변경 감지·중복·만료·실패 보존·배포 후보 무결성을 검사한다. 실제 점검에서 whol.xml(지방)은 XML 대신 HTML을 반환해 경고로 기록했다. 정상 피드를 이용하되 전체 지방 기사 공급을 보장하지 않는다. 애매한 기사와 위치를 만들어 채우지 않는다. 30일은 보관 범위이며 10,000건 상한과 RSS 노출 범위 때문에 기간 내 모든 뉴시스 기사를 의미하지 않는다.

로고 제작은 내장 imagegen의 background-extraction 방식이며 최종 프롬프트는 “원본 여기뉴스 글자·핀 형태 보존, 배경/부가 문구 제거, 여기 짙은 남색·핀/뉴스 청록색, 투명 alpha, 경계 잡티 정리”다. tools/generate_icons.py는 기존 아이콘 형태를 보존한 도구이며 최종 워드마크는 별도 PNG 자산이다.

## 2026-10-23 메뉴·파동·검색 반영

공통 메뉴 맨 끝에 작은 핀과 여기뉴스를 추가했다. PC는 앞 간격 12px, 모바일은 8px이며 충무로딩 자체 헤더 구조는 유지했다. 메인 랜딩에는 별도 서비스 카드로 연결하며 작품 번호를 부여하지 않는다.

새로고침 시 시작 파동을 짧게 재생한다. 새 수집본에서 처음 확인한 기사만 미확인 파동을 반복하며, 기사 원문 링크를 열거나 수집 시각으로부터 10분이 지나면 종료한다. 다음 수집본에서는 이전 기사 파동을 종료한다. 첫 방문은 최신 수집본의 최근 10분 발행 기사부터 시작한다. 읽음·수집본 비교는 해당 브라우저 저장소 기준이며 원문을 실제로 끝까지 읽었는지는 알 수 없다. 동작 줄이기 설정과 파동 끄기를 존중한다.

파비콘은 기존 VISUAL NEWSIS의 공식 뉴시스 아이콘과 통일했다. 여기뉴스 제목·설명·제작자 구조화 데이터와 섹션 사이트맵을 갱신했다. 충무로딩·계산대로 탭 제목과 추적 설정은 유지한다.

## 위치 분류 v3

사진 영역의 잘못 닫힌 div 때문에 실제 기사 도입부가 누락되던 파서를 수정했다. 사진 설명·제공처·기자 발신지·출생지·과거 이력·역사 자료의 지명과 다음 단신을 현재 사건 장소로 사용하는 것을 제한한다. 읍면동은 상위 지역 근거를 함께 요구하며 일반 단어인 ‘내면’ 등의 오인을 막는다. 근거 문장에는 실제로 일치한 지명·별칭을 남긴다. 알고리즘 버전이 바뀌면 같은 기사 fingerprint여도 다시 분류한다. 도입부는 최대 600자만 보존하며 기사 전문은 보존하지 않는다. 위치를 확정하지 못한 기사는 지도에서 제외한다.

공식 RSS 8개 중 whol 피드는 현재 XML 대신 HTML을 반환하여 경고로 남긴다. 나머지 정상 피드로 수집하며 전체 소스가 충분하지 않으면 기존 스냅샷을 보존한다. 규칙 기반 분류라 모든 기사에서 위치 정확도를 보장하지 않는다.

## 지도 화면과 지역 안내 동기화

마우스 휠·지도 드래그·두 손가락 확대축소·지도 키보드 조작·확대축소 버튼을 사용하면 고정 동네 필터를 해제하고 현재 지도 안의 기사로 전환한다. 지도를 충분히 축소하면 전국 전체 기사와 전국 안내로 돌아온다. 가까운 지도 안내는 중심점의 행정구역과 확대 단계, 화면 크기를 따라 갱신한다. 표시 거리는 지도 중심부터 화면 모서리까지의 대략적인 범위이며 정확한 원형 반경 검색은 아니다. 검색·지역 선택·내 위치 찾기처럼 사용자가 직접 지역을 정한 동작은 고정 지역 선택을 유지한다. 여러 지역에 관련된 기사도 현재 화면에 포함된 지역을 카드에 먼저 표시하고 화면 밖 마커는 제외한다.

‘내 위치’는 오른쪽 위 ‘전국 보기’ 바로 아래에 배치하며 확대축소 버튼은 기존 오른쪽 아래 위치를 유지한다. 접속 즉시 공개 스냅샷을 확인해 캐시된 초기 데이터 때문에 파동이 늦게 켜지는 경우를 줄였다.

# GOODEASY 후속 6편 — 정적 웹 구현 인계 v1

**범위**: 02~07. 01 피아노는 기존 상태 유지. 라우트 `/goodeasy/{fishing-reel,camera,watch,projector,keyboard,espresso-machine}/`.

## 공통 경험 계약
1. 첫 진입에서 실제 조작 활성. `start` 게이트 없음. JS 로딩 중에는 기본 동작 가능한 HTML 버튼을 남기고 향상한다.
2. 사용자 조작은 `{episodeId, actionType, timestamp, parameters, result}`의 **스냅샷**으로 보관. 관찰 진입 시 마지막 이벤트를 복사하여 원본 보존.
3. 관찰은 해당 동작을 재생/스크럽하고 부품을 선택. 교육용 모션 속도는 실제 물리 시간·오디오와 구별.
4. 마지막은 '브라우저에서 만든 과정': 조사, 설계, 자산, 오디오, 코딩, AI 협업, 미검증 부분. 제조법 튜토리얼 아님.
5. 모든 첫 체험 하단·제작 과정·푸터에 `크리에이티브 디렉터 = 안재현`.

## 공통 레이아웃 수치 (CSS px)
| 영역 | 1440×900 | 390×844 | 320px | 가로 844×390 |
|---|---|---|---|---|
| 헤더 | x24~1416 y0~58 | x0~390 y0~58 | h52 | 좌측 52 |
| 설명 | x64 y112~240 | x24 y82~145 | 좌우 16 | 우측 패널 상단 |
| 조작물 | x458 y95 w923 h685 | x12 y158 w366 h410 | x8 w304 h=min(43dvh,350) | 좌측 약 65% |
| 주 버튼 | x64 y375 w340 h66 | x24 y633 w342 h52 | x16 w288 h48 | 우측 패널 48h |
| 상태 | x480 y716 w875 h44 | x24 y523 w342 h38 | x16 w288 h38 | 우측 하단 |
| 크레딧 | 하단 12px | 하단 10px | 본문 뒤 배치 | 스크롤 영역 |

390×844 화면의 절대 Y값은 **디자인 기준 위치**다. 실제 구현에서는 `100dvh`, `min-height`, 문서 스크롤과 `env(safe-area-inset-*)`로 재배치하며 320px에서는 수직 스크롤을 허용한다. 화면이 작다고 버튼을 44px 미만으로 줄이지 않는다.

Breakpoints: `max-width:359px` 소형, `360~600px` 세로, `601~1023px` 태블릿/가로, `min-width:1024px` 데스크톱. 가로 높이 480px 미만이면 모델 왼쪽·조작 오른쪽. 긴 설명은 모델 위에 겹치지 않도록 별도 문서 흐름에 둔다.

## 6편 별 핵심 작동 / 관찰 / 단순화

### 02 낚시 릴 — 스피닝 릴
- 첫 행동: 드래그 노브 조정 후 손잡이를 드래그/버튼/화살표로 감는다. 베일 닫힘이 감기 조건. 가상 장력이 드래그 설정을 넘으면 스풀에서 줄이 풀리는 슬립을 보여준다.
- 내부: 손잡이 → 구동 기어 → 피니언/로터 → 베일/라인 롤러 → 스풀 줄 감김. 스풀의 왕복 이동을 별도 구속으로 표시. **스풀은 일반적인 회수 중 로터처럼 회전하지 않는다.** 드래그 슬립 시 스풀 회전 가능.
- 상태: IDLE/WINDING/SLIP/STOP; 전달: 회전수, 로터 각, 스풀 위치, 드래그, 장력, 회수 길이, 베일 상태.
- 형상: 타원형 바디, 곡선 베일 와이어, 홈이 있는 라인 롤러, 원통 스풀, 기어 톱니, 마찰 와셔. 실제 기어비·드래그 토크는 미검증.

### 03 카메라 — 디지털 카메라, 가상 장면
- 첫 행동: 가상 피사체 뷰파인더를 보고 셔터 누름. 노출 다이얼은 셔터 속도 조정; 조리개/ISO는 선택 보조값. **카메라 권한 요청 없음**.
- 내부: 렌즈 → 조리개 → 기계식 포컬플레인 셔터의 선막/후막 → 센서. 가상 촬영 결과는 로컬 canvas 이미지. 실물 특정 기종의 미러/셔터 구조 혼합 금지.
- 상태: LIVE/FOCUS/EXPOSE/CAPTURED; 전달: 장면 ID, 노출값, 이미지 데이터, 시각. 이미지 파일은 브라우저 내부 생성.
- 형상: 렌즈 배럴, 중첩 조리개 날, 얇은 셔터 날, 센서 표면. 블러/노출은 시각 교육용 근사.

### 04 시계 — 수동감기 기계식
- 첫 행동: 용두 회전으로 메인스프링 에너지 증가. 충분히 감기면 바늘/밸런스 움직임 시작.
- 내부: 용두·스템 → 래칫/배럴 → 기어열 → 이스케이프 휠·팔렛 포크 → 밸런스. 용두와 이스케이프 휠 직접 연결 금지.
- 상태: UNWOUND/WINDING/RUNNING/STOPPED; 전달: 감기 회수, 에너지, 기어 위상, 틱, 가상 시각.
- 형상: 원형 브리지/플레이트, 인벌류트에 가까운 톱니 근사, 코일 태엽, 루비 핀, 앵커. 진동수 표기 `6회/초`는 선택한 교육용 모델 가정이며 실제 특정 무브먼트 사양 아님.

### 05 영사기 — 수동 35mm 필름 교육 모델
- 첫 행동: 크랭크를 돌려 가상 영상이 움직이게 함.
- 내부: 공급 릴 → 연속 이송 스프로킷 → 루프 → 간헐 이송/게이트 → 루프 → 권취 릴. **필름이 움직일 때 광로를 셔터가 가리고, 정지할 때 화면 투사**하도록 위상 동기화.
- 상태: STOP/TURN/ADVANCE/HOLD/PROJECT; 전달: 크랭크 회전, 프레임 인덱스, 이송 위상, 셔터 위상, 투사 프레임.
- 형상: 스프로킷 이빨, 퍼포레이션 필름 띠, 셔터 원판, 렌즈, 릴. 18fps는 교육용 기본값, 모든 영사기의 표준 아님.

### 06 기계식 키보드 — 접점형 스위치
- 첫 행동: 물리 키 또는 화면 키캡을 눌러 문자 표시. 조합키/IME 입력은 실제 `beforeinput`/`input` 결과를 우선하고 키 다운은 기구 애니메이션에 사용.
- 내부: 키캡 → 스템 → 스프링 압축 → 접점 닫힘 → PCB 입력. **광학·홀 효과 스위치와 금속 접점 모델 혼합 금지.**
- 상태: UP/TRAVEL/ACTUATION/BOTTOM/RELEASE; 전달: `code`, 출력 문자, 누름/해제 시각, 유지시간, 작동 횟수. key repeat은 별도 기록.
- 형상: 키캡 곡면 상판, 십자 스템, 하우징 클립, 코일 스프링, 두 금속 리프, PCB. 실제 작동점 mm 미확정.

### 07 에스프레소 — 펌프식 포터필터 머신
- 첫 행동: 포터필터를 돌려 그룹헤드에 잠근 후 추출 스위치 누름. 물·커피는 준비된 가상 상태.
- 내부: 물 공급 → 펌프/가열 → 밸브 → 그룹헤드/샤워스크린 → 커피 퍽 → 바스켓/스파웃. 압력과 유량은 서로 다른 변수이며 임의로 비례시키지 않는다.
- 상태: UNLOCKED/LOCKED/PREWET/EXTRACT/STOP; 전달: 장착 상태, 시간, 가상 압력·유량 프로필, 추정 추출량.
- 형상: 원통 보일러, 금속 그룹헤드, 가스켓, 바스켓 미세 홀, 포터필터 손잡이, 유체 스트림. `8.5bar` 표기는 예시 상태이며 측정값 아님.

## 조작 컴포넌트 / 접근성
- SVG 상세 시트: 각 편의 기본/포커스/선택/비활성. `:hover`, `:focus-visible`, `:active`, `:disabled` 구현. 조작 영역 최소 44×44, 권장 48×48.
- 손잡이/용두/크랭크는 포인터 캡처를 사용하고 이동량을 누적; 키보드에서는 화살표 ±고정 단위. `pointercancel`, 탭 비활성화 시 드래그 종료.
- 타임라인은 native range 기반, Home/End 및 방향키, `aria-valuetext` 단계 설명. 재생 중 스크럽 시 일시정지.
- 모바일: 컨트롤 위 수평 드래그는 컨트롤 우선, 모델 빈 공간 한 손가락은 궤도 회전, 두 손가락은 줌, 페이지 세로 스크롤은 바깥 문서 영역 우선. 모델 영역 `touch-action`은 제스처 방식에 맞게 제한; 화면 전체 `touch-action:none` 금지.
- 스크린리더는 시각적인 회전 각도 대신 행동 결과를 알려줌. 실제 키보드 입력을 훔치는 전역 단축키는 텍스트 필드 포커스 중 비활성.
- 모션 감소 시 기구를 정적 단계/전후 프레임으로 대체하고 수치 갱신 유지. 소리 자동재생 금지.
- 지원 실패 시 SVG 단계도와 텍스트 설명을 표시; 입력 자체는 유지.

## 구현/검수 게이트
1. 각 에피소드의 상태와 관찰 스냅샷을 구분. 뒤로 가도 마지막 기록 보존.
2. 물리 작동의 회전축/접촉면을 모델링 후 독립 검증. 도면은 비실측 컨셉 아트.
3. 실제 3D 메시, UV, PBR 텍스처, 마이크로 접점, 오디오 샘플, 장면별 2D 렌더, 기구 검증 자료는 **미제작**. 현재 SVG는 개념 일러스트.
4. 폰트/아이콘은 로컬 에셋으로 제공; 외부 API 의존 금지. 브라우저별 터치·키보드·safe-area QA 필요.
5. 제작 과정에는 출처, 선택한 모델 가정, AI 사용 위치, 검증되지 않은 부분을 명시.

## 브라우저 작업에서 확인한 점

Whale의 기존 창은 Windows 도구의 창 소유권 오류로 접근하지 못했다. 앱 안의 브라우저는 사용자의 수동 로그인 후 의뢰와 다운로드에 성공했다. 브라우저 검사 실패가 한 번 발생했고 페이지의 정상 ‘다시 불러오기’로 회복됐다. 계정 비밀번호·인증 코드·쿠키·토큰은 파일에 저장하지 않았다.

긴 의뢰서의 `typeText` 입력 과정에서 줄바꿈이 메시지를 나누어 전송하는 문제가 발생했다. 해당 대화에 이를 설명하고, Playwright의 접근 가능한 작성기 `fill`로 전체 의뢰서를 한 번에 채운 다음 전송 버튼을 클릭하는 방식으로 수정했다. 파일 업로드 완료와 실제 답변 완료를 각각 확인한 후 패키지를 다운로드했다.

이 기록은 이번 디자인 의뢰의 실행 기록이다. 프로젝트의 정책 문서는 루트 AGENTS.md이며, 실제 사이트 구현·공용 영역 변경·배포 승인을 대신하지 않는다.

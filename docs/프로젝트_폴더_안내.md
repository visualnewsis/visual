`웹사이트/` 항목은 실제 저장소 `/Users/jaehyeon/Projects/visual`로 연결됩니다. 사용자용 안내는 상위 `프로젝트안내.md`에 있으며, 결과물·원본과작업물·검수자료·개발도구·프로젝트문서·이동기록을 구분합니다. 기존 `portal/`, `docs/handoffs/`의 공개 경로는 보존하고 한국어 폴더에서는 같은 단일 원본으로 연결합니다.

Codex는 기존 등록 작업 폴더가 심볼릭 링크가 되면 기본 실행을 거부합니다. 따라서 기본 저장소만 기존 실제 위치로 복구했고, 에딧샵의 `웹사이트/`가 그 원본으로 연결됩니다. 영사기 임시 경로는 새 작업트리로 연결되는 호환 링크입니다. 열려 있는 Codex 채팅과 서버는 계속 같은 파일을 사용합니다. 앱의 프로젝트 등록 경로 표시는 자동 변경하지 않았습니다. 앱 설정 데이터베이스를 직접 수정하지 않았습니다.

현재 통이 브랜치와 미커밋 작업은 그대로 유지했습니다. 영사기 배포 소스와 수정 전 소스는 상위 `개발도구/작업트리/`에서 별도로 관리하며 검수 증거는 `검수자료/굳이구지/`에 있습니다. 파일 이동만으로 원격 main이나 공개 사이트에 배포하지 않습니다.

이동 전후 목록·SHA-256과 경로 대응표는 상위 `이동기록/`에서 확인합니다. 저장 규칙의 단일 원본은 이 저장소 `AGENTS.md` 25절입니다.

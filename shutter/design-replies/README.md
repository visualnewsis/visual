## 채택 전 확인할 한계

기구 v0.2는 캡스턴–위펜·잭–너클·반복 레버·백체크 접촉을 검증하지 않았다. 단순 SVG 압출로 목표 수준의 모델을 완성할 수 없다. 곡면 형상·리깅·목재와 펠트 재질·조명·고정 피벗 및 접촉 운동을 별도로 제작하고 검증해야 한다. 보드 이미지의 정교함을 완성된 모델 자산으로 해석하지 않는다.

`piano_handoff/state-machine.js`는 외부에서 받은 참고 컨트롤러다. 원본 연주 스냅샷의 깊은 불변성, 선택 음 복귀 시 전체 상태 초기화, 단계/시간 업데이트 및 입력 검증은 실제 연결 전 추가 검토가 필요하다. 프로젝트 코드에 복사하거나 실행하지 않았다.

모든 ZIP은 원본을 보존했다. 압축 해제 시 대상 폴더 밖 경로를 거부하고 파일 종류를 확인했다. SVG는 XML 파싱 및 script/foreignObject 포함 여부를 검사했다. 이는 기계적 정확성·렌더 품질·실기기 기능 검증을 의미하지 않는다.

이번 작업은 의뢰·회수·검토·보관까지다. 기존 `shutter/piano/` 실행 파일, 원격의 카메라, 공용 파일, 배포 구성은 변경하지 않았다. 실제 기기 검증·사이트 반영·커밋·공개 배포는 하지 않았다. 사용자 최종 디자인 승인을 받았다는 기록도 아니다.

## 새 Mac에서 열기
GitHub 로그인이 가능한 상태에서 새 폴더에 받는다. Windows SSH 별칭·절대경로·실행 중인 서버는 복사하지 않는다.

```sh
git clone --branch codex/tongi-piano-sample-20261107 https://github.com/visualnewsis/visual.git visual-tongi
cd visual-tongi
python3 -m http.server 8798 --bind 127.0.0.1
```

브라우저에서 http://127.0.0.1:8798/output/tongi-piano-demo/ 를 연다. 종료는 터미널 Ctrl+C. `python3`이 없으면 Python 3 설치가 먼저 필요하다. 페이지 파일만 따로 열지 말고 저장소 루트를 정적 서버로 제공해야 공통 피아노 자산까지 연결된다. 새 서비스 서버/API/빌드는 필요 없다.

이미 저장소가 있다면 먼저 미커밋 작업을 안전하게 보존하고 `git fetch origin` 후 해당 브랜치로 이동한다. 기존 작업에 강제 checkout/reset하지 않는다. 같은 이름의 로컬 브랜치가 있으면 이동 후 `git pull --ff-only`로 갱신한다.

## 현재 샘플
- `output/tongi-piano-demo/`: 최신 **호출형** 피아노 샘플. 옆 시연 패널 폐기.
- 작은 통이 클릭 → 현재 보이는 조작 한 가지 안내 → × 또는 Esc → 원래 호출 자리 복귀.
- 버튼 숨기기는 별도. 같은 브라우저에서 기억하고 상단/본문 `통이 도움`으로 복구.
- 자동으로 계속 등장하지 않는다. 첫 조작 구간에서 소개 한 번. 안내는 읽는 도중 시간만으로 닫지 않는다.
- 실제 조작에 성공하면 짧게 반응 후 복귀. 19개 장면 미리보기는 상단 **샘플 도구**다.
- 안전한 빈 공간이 없으면 호출된 동안만 작은 아래 안내 영역을 확보한다. ×를 누르면 확보한 영역도 사라진다.
- `크리에이티브 디렉터 = 안재현`은 열린 안내 아래 작게 유지.

## 실서비스 상태
통이 안내가 실제로 들어갔던 커밋 `8e53aa6d`는 `642b9f5b`에서 되돌렸다. 제거 배포 Actions 성공 및 공개 `/goodeasy/` HTML에 통이 import/호출 버튼이 없는 것을 확인했다. 임시 외부 통이 사이트는 공개 철회 상태다. 새 샘플은 로컬 검토용이며 실서비스 피아노/공용 랜딩에는 적용하지 않았다.

## 구현 위치 / 유지 사항
- sample.js: 명시적 구간별 안내, 현재 조작 상태, 호출/닫기/숨김/복구
- sample.css/sprite.css: 팝업/버튼과 승인 PNG 몸 전체 모션
- piano.html: 실제 기사 복사본, noindex. 원본 피아노 JS/3D/소리 자산 재사용
- frame.css: 복사본에서만 강조/첫 체험 높이/본문 도움 버튼
- 실제 기사 `goodeasy/piano/`, 공용 헤더/분석태그/배포 자동화는 수정하지 않았다.
- 최신 AGENTS.md가 정책 원본이다. 이 문서는 현재 작업 상태를 설명하며 영구 정책을 추가하지 않는다.

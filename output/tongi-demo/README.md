## 보기

저장소 루트에서 `node output/tongi-demo/serve.cjs`를 실행한 뒤 `http://127.0.0.1:8794/`를 엽니다. `index.html`을 브라우저에서 직접 열어도 작동합니다. 기존 랜딩의 이미지·폰트·공통 헤더는 실제 서비스 URL을 사용하므로 인터넷 연결이 필요합니다.

같은 사내망/Wi-Fi의 휴대폰용 미리보기는 별도로 실행합니다. PowerShell에서 `$env:TONGI_HOST='172.1.1.125'; $env:TONGI_PORT='8795'; node output/tongi-demo/serve.cjs`. 현재 PC 주소 기준 `http://172.1.1.125:8795/`이며 PC 주소가 바뀌면 다시 확인해야 합니다. PC와 휴대폰 사이에 방화벽/망 분리/무선 단말 격리가 있으면 접속되지 않을 수 있습니다. 페이지와 이미지의 해당 주소 HTTP 200은 PC에서 확인했으며 휴대폰 실접속은 아직 확인하지 않았습니다. 외부 공개 배포는 하지 않았습니다.

`node output/tongi-demo/build.cjs`는 현재 받아둔 origin/main의 랜딩에 panel.html과 CSS/JS 참조를 삽입합니다. 로컬 working tree의 메인 페이지를 변경하지 않습니다.

## 체험

- 검색창 포커스: 귀 기울이기. 입력: 눈과 고개 반응. 한글 조합 중 Enter 검색 방지.
- 전체 기사 찾기: 검색 범위를 뉴시스 전체 기사로 설정한 시안. 실제 데이터·AI 연결 전이며 공식 홈페이지 검색으로 이동하는 안내만 제공합니다. 외부 출처 POST /search/는 뉴시스에서 접근을 차단하는 것을 실제 확인해 제거했습니다. 실제 전체 기사 검색 완료로 간주하지 않습니다.
- 브리핑: 전체 기사 검색 연결 및 기존 주제별 샘플 링크. 실제 AI 호출·개인화·전체 기사 요약은 아직 연결 전입니다.
- 마우스 또는 터치를 좌우로 문질러 쓰다듬기: 눈웃음·볼 홍조·몸 흔들기와 “헤헤 간지러워요”. 이동 거리와 방향 전환으로 인식하며 쓰다듬은 직후 클릭을 억제합니다. 터치 세로 스크롤은 허용합니다.
- 통이를 빠르게 세 번 클릭/탭: 고글에 `− _ −`, “아파요 -_-” 표시 후 복귀. 검색 중에는 장난 반응 억제.
- 화면 안에 있을 때 스크롤 반응. 입력/탐색 중 스크롤이 상태를 덮어쓰지 않음.
- 탭 전환·처음부터·탐색 중 입력 변경 시 이전 탐색 취소.
- 키보드 탭/방향키, 터치, 상태 알림, reduced-motion 대응.

페이지는 noindex/nofollow이며 기존 추적 ID를 한 번 유지하되 localhost에서는 GA config를 실행하지 않습니다. 이 파일을 실서비스 랜딩으로 배포하지 마세요.

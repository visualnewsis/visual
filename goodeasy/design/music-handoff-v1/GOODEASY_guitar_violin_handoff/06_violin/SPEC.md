# 06 바이올린 · 활로 지속 발음

## 좌표/피벗 (시각화용 가정)
- desktop 1440×900: 몸통 중심 (845,470), 곡선 외형의 상단 (845,250), 브리지 중심 (845,550), 활털 가로축 y428, x630..1060. 활털 히트 영역 x630..1060, y404..448.
- mobile 390×844: 몸통 중심 (206.7,430), scale .63, 활털 중심 y403.54, x71.25..342.15, 히트 영역 y388.42..423.42.
- 활의 횡이동을 **기준 좌표 x축**으로 투영; 활이 멈추면 소리 정지. 활 자체의 피벗/회전각은 2D 시안에서 고정. 3D 구현 시 손잡이(frog), 활대(stick), 활털(hair)을 독립 메시로 구성.
- 현 G3 D4 A4 E5는 중앙 x축에 나란히 배치. 도면의 현간 간격 16×scale px. 이는 악기 실측이 아님.
- 실제 연주에서 활은 현과 거의 직각 방향으로 움직이고, 지판 끝과 브리지 사이의 접촉 위치를 사용. 화면 드래그 x축은 이 동작을 화면에 투영한 입력 비유이며 실제 물리 좌표와 동일하지 않음.

## 부품 / 역할 / 포인터
- Bow hair(활털): 활대 아래 밝은 수평 선. 현을 붙잡았다 놓는 마찰 상호작용.
- Bow stick(활대): 활털 위 어두운 평행 선. 탄성/장력은 정밀 해석하지 않음.
- Strings(현): 중앙 세로선 네 개. 개방현 G3 D4 A4 E5.
- Bridge(브리지): 현 아래 밝은 목재 곡면; 현 진동을 상판에 전달.
- Top plate(상판): 바니시 목재 몸통 전면. 진동 방사.
- Sound post(사운드포스트): 상판과 후판 사이 기둥; 외부 도면에서 보이지 않으므로 3D 단면 관찰에서만 표시.
- Bass bar(베이스바): 상판 안쪽 길이 방향 보강재; 3D 분해에서만 표시.
- f-holes(f홀): 상판 좌우 검은 곡선 개구. SVG는 상징적 형태.

## 동작/정지 규칙
- `pointerdown`은 선택/접촉 시작만. 이동량과 시간으로 `speedPxPerSec` 계산. 움직임이 임계치 이상일 때 `BOWING`, 정지하면 `CONTACT_IDLE` 및 음소거.
- **정지 검출은 pointermove만으로 불가능**. 각 animation frame에서 마지막 좌표/시각을 평가해, 새 이동 이벤트가 80ms 이상 없으면 `stopSound()` 실행. 이 80ms는 입력 안정화용 가정이며 실제 바이올린 반응 시간 아님.
- `pointerup`, `pointercancel`, `lostpointercapture`, `window.blur`, `document.visibilitychange`(hidden), 페이지 이탈에서 즉시 stopSound, active pointer 해제.
- 키보드 대안: G/D/A/E 현 선택 버튼, 방향키를 누르고 있는 동안 반복 `BOW_MOVE` 발생, keyup에서 즉시 중단. 자동반복 여부와 무관하게 키 홀드 상태를 관리. 스크린리더 전용 `활 긋기 시작`/`활 긋기 중지` 토글 대안도 제공하되 사용자에게 지속음을 분명히 고지.
- 기록 `{stringId, pitch, startedAtMs, endedAtMs, movementSamples:[{tMs, xNorm, speedNorm}], reason}`. 원본을 보존하고 관찰용 깊은 복제 생성.
- 음향: Web Audio의 연속 오실레이터 + 필터 + envelope/약한 노이즈. stick-slip의 교육용 근사만 사용하며 실측 바이올린·마찰 PDE·진짜 Helmholtz motion 구현이라고 주장 금지.
- 관찰: 활털-현 마찰 → 현의 지속 진동 → 브리지 → 상판/후판 및 사운드포스트. 활을 멈추면 합성음 정지; 남는 몸통 잔향은 선택적 짧은 감쇠로만 표현.

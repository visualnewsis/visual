관찰 중인 음 —

  1. 01 / 건반

    손가락이 누른 앞쪽은 내려가고, 지렛대 뒤쪽은 올라갑니다.

  2. 02 / 해머

    전달 기구가 해머를 올립니다. 해머는 현을 친 뒤 물러나 현이 자유롭게 진동하게 합니다.

  3. 03 / 현과 댐퍼

    건반을 누르면 댐퍼가 들립니다. 손을 떼면 현에 닿아 진동을 줄입니다. 서스테인을 켜면 댐퍼가 들린 상태를 유지합니다.

연주한 뒤 다시 관찰할 수 있습니다.

일반적인 그랜드피아노의 원리를 공간 도형으로 단순화했습니다. 실측 CAD가 아니며 이중 이스케이프먼트·반복 레버·체크의 세부 운동과 실제 현의 물리 계산은 포함하지 않습니다. 느린 관찰은 무음 재생입니다.

01 / 조사와 선택

사진 대신, 누를 수 있는 건반.

안재현 디렉터가 정한 출발점은 “브랜드 소개보다 체험이 먼저”였습니다. Yamaha의 액션·발음 원리 자료로 건반, 해머, 현, 댐퍼의 관계를 확인했습니다. 첫 입력을 막지 않도록 사진·대형 모델·음원 다운로드를 기다리는 구성을 제외했습니다.

02 / 하나의 입력, 두 개의 장면

연주한 음을 관찰까지 이어갑니다.

각 건반은 고유한 음 번호를 가집니다. 누름과 뗌을 같은 상태에 기록해 건반 표시, 소리, 해머와 댐퍼 모형에 전달합니다. 마지막 음과 누른 시간을 남겨 다음 장면에서 다시 확인합니다. 화면을 옮겨도 다른 설명용 음으로 바뀌지 않습니다.

03 / 모델링과 오디오

가볍게 시작하고, 한계를 드러냅니다.

기구는 JavaScript의 3차원 좌표를 Canvas에 투영한 직접 제작 모형입니다. 소리는 Web Audio로 여러 배음을 합성하고, 누르는 동안 감쇠시키며 손을 뗄 때 더 빠르게 줄입니다. 실제 그랜드피아노 녹음이나 정밀한 물리 음원은 아닙니다. 키보드·터치로 실제 타건 속도를 측정할 수 없어 세기는 일정합니다.

04 / AI와의 협업 · 현재 진행형

작동 시제품에서 악기로 가는 일.

경험 구조와 미감은 안재현 디렉터가 정하고, Codex가 상태 연결·입력 처리·소리 합성·모형 렌더링을 구현했습니다. 첫 시제품의 목표는 연주와 내부 반응의 연결입니다. 고품질 녹음 음원, 정교한 그랜드피아노 전체 모델, 공명·조율·고장·수리는 앞으로 검증할 과제입니다. 아직 겪지 않은 실패담이나 완성되지 않은 기능을 제작 성과로 쓰지 않습니다.

4. 위상·치폭·축 간섭 검증

다음 코드는 기존 화면 검사와 별개로 동력 전달계의 기하학적 계약을 검증하는 순수 JavaScript입니다. Three.js 없이 실행되며, 이후 모델 생성 함수와 동일한 설정 데이터를 공유하도록 작성했습니다.

JavaScript

export function createWatchTrainSpec() {
  const axes = {
    B: { x: -1.05, z: 0.65 }
  };

  // Directions are normalized before placement.
  const stages = [
    {from:"B", to:"C", d:0.990, direction:[0.91,-Math.sqrt(1-0.91**2)],
      wheel:80, pinion:10, module:0.022, y:[0.34,0.40]},
    {from:"C", to:"T", d:0.900, direction:[0.78,Math.sqrt(1-0.78**2)],
      wheel:80, pinion:10, module:0.020, y:[0.51,0.57]},
    {from:"T", to:"F", d:0.765, direction:[0.88,-Math.sqrt(1-0.88**2)],
      wheel:75, pinion:10, module:0.018, y:[0.68,0.74]},
    {from:"F", to:"E", d:0.616, direction:[0.28,-.96],
      wheel:80, pinion:8, module:0.014, y:[0.85,0.91]}
  ];

  // Compute every center from the preceding pitch-distance constraint.
  for (const s of stages) {
    const a = axes[s.from];
    const len = Math.hypot(...s.direction);
    const dx = s.direction[0]/len;
    const dz = s.direction[1]/len;
    axes[s.to] = {
      x: a.x+s.d*dx,
      z: a.z+s.d*dz
    };
    s.pitchWheel = s.wheel*s.module/2;
    s.pitchPinion = s.pinion*s.module/2;
    s.driver = {
      axis:s.from,N:s.wheel,module:s.module,
      r:s.pitchWheel,y:s.y
    };
    s.driven = {
      axis:s.to,N:s.pinion,module:s.module,
      r:s.pitchPinion,y:s.y
    };
  }

  return {axes,stages};
}

export function validateWatchTrain(spec, tolerance=1e-8) {
  const {axes,stages}=spec;
  const results=[];

  for (let i=0;i<stages.length;i++) {
    const s=stages[i];
    const a=axes[s.from],b=axes[s.to];
    const d=Math.hypot(b.x-a.x,b.z-a.z);
    const expected=s.pitchWheel+s.pitchPinion;
    const overlap=Math.max(0,
      Math.min(s.driver.y[1],s.driven.y[1])-
      Math.max(s.driver.y[0],s.driven.y[0])
    );

    results.push({
      mesh:`${s.from}->${s.to}`,
      measuredCenter:d,
      expectedCenter:expected,
      centerError:d-expected,
      overlapY:overlap,
      sameModule:s.driver.module===s.driven.module,
      centerOK:Math.abs(d-expected)<tolerance,
      widthOK:overlap>0.05
    });
  }

  // Mechanical speed ratios.
  const ratios=stages.map(s=>s.wheel/s.pinion);
  const centerToFourth=ratios[1]*ratios[2];
  const fourthToEscape=ratios[3];

  return {
    results,
    speedRatios:{
      barrelToCenter:ratios[0],
      centerToFourth,
      fourthToEscape,
      barrelToEscape:ratios.reduce((a,b)=>a*b,1),
      beatRate:60*centerToFourth*
        fourthToEscape*15*2
    },
    passed:results.every(r=>
      r.centerOK && r.widthOK && r.sameModule
    )
  };
}

export function initialMeshPhases(spec) {
  // Circular-pitch phase alignment:
  // driver tooth center at contact, driven tooth gap at contact.
  // This establishes visual pitch synchronization, not involute clearance.
  const phases={B:0};
  const {axes,stages}=spec;

  for(const s of stages) {
    const a=axes[s.from],b=axes[s.to];
    const alpha=Math.atan2(b.z-a.z,b.x-a.x);

    const driverN=s.wheel;
    const drivenN=s.pinion;

    // On the compound axis, wheel and pinion share the same angular state;
    // their modeled tooth geometry may have different assembly offsets.
    const driverOffset=alpha-
      (phases[s.from]*driverN)%(2*Math.PI)/driverN;

    // Tooth on driver faces the gap between two driven teeth.
    const drivenOffset=alpha+Math.PI+Math.PI/drivenN;

    phases[s.to]=
      -(driverN/drivenN)*phases[s.from];

    s.phase={
      contactAngle:alpha,
      driverGeometryOffset:driverOffset,
      drivenGeometryOffset:drivenOffset,
      angularRatio:-driverN/drivenN
    };
  }
  return {phases,stages:stages.map(s=>s.phase)};
}

const spec=createWatchTrainSpec();
console.table(validateWatchTrain(spec).results);
console.log(validateWatchTrain(spec).speedRatios);


주의할 점은 initialMeshPhases가 각 접촉점의 원형 피치 위상에 대한 시작값을 제공한다는 것입니다. 개별 치형 생성기의 tooth-0 기준에 맞춰 조립 오프셋을 적용해야 하며, 위상 결과만으로 언더컷·백래시·접촉 간섭이 없다고 볼 수 없습니다.

또한 이 검증은 기어 중심거리와 축방향 치폭을 확인하는 것입니다. 기어의 실제 톱니가 공간을 침범하지 않는지는 아래의 별도 검증이 필요합니다.

위 검증 코드의 beatRate 계산에는 배럴·센터 휠 기준 시간 단위가 섞여 있습니다. 센터 휠을 시간당 1회전으로 둔 모델이므로, 마지막 식은 다음과 같이 바로잡아야 합니다.

JavaScript
// Center wheel = 1 revolution per hour.
// Escape wheel = 600 revolutions per hour.
// Each of 15 teeth produces two beats per revolution.
const beatsPerHour =
  centerToFourth * fourthToEscape * 15 * 2; // 18000

또한 initialMeshPhases()의 출력은 각 기어를 조립할 때 사용할 상대각의 초깃값으로만 취급해야 합니다. 실제 위상은 한 축에 있는 휠과 피니언의 고정된 치형 오프셋까지 함께 계산해야 합니다. driverGeometryOffset을 서로 독립적으로 바꿔서 같은 축의 휠과 피니언을 따로 움직이게 해서는 안 됩니다.

5. 메인플레이트와 브리지의 재설계

이번에는 큰 회색 원판에 구멍을 장식하는 방식을 폐기합니다.

메인플레이트 — 기계의 바닥

중심은 새 윤열의 외곽에 맞춘 비대칭 윤곽. 배럴 아래, 센터·3번·4번 축 아래, 탈진기 쪽에 재료를 남깁니다. 빈 곳은 기능에 필요한 깊이만 가공합니다. 기존 커다란 타원 포켓은 없앱니다.

브리지 — 축을 붙잡는 상부 구조

각 축의 상부 피벗, 지지부와 고정 나사를 연결하는 유기적인 외곽입니다. 양 끝이 둥근 막대를 축마다 하나씩 올리는 방식은 금지합니다.

태엽통 — 실제 에너지를 저장하는 공간

6. 태엽통과 감기 기구

기존 시계에서 거의 빠져 있던 부분입니다.

태엽통 내부
태엽통 내부 연결 원리의 개략도. 실제 스프링 곡선과 고정 형상은 별도 메시로 생성합니다.

수동 감기형 개념 모델에서는 다음처럼 구성합니다.

내단: 메인스프링의 안쪽 끝이 아버의 훅에 결합.

외단: 바깥쪽 끝이 배럴 내벽의 훅 또는 홈에 고정.

감기: 용두 → 와인딩 스템 → 와인딩 피니언 → 크라운 휠 → 래칫 휠 → 배럴 아버.

역방향 방지: 래칫 휠에 클릭이 걸려 저장한 태엽 힘이 용두로 역방출되는 것을 막음.

작동: 아버가 지지된 상태에서 메인스프링이 배럴을 회전시키고 배럴 외부 휠이 센터 피니언을 구동.

수동 감기형과 자동 감기형의 태엽 외단 결속 방식이 다를 수 있으므로, 이 모델에서는 수동 감기형의 고정 외단을 채택합니다.

최종 설계 결정

이번 재구축은 다음 순서로 진행해야 합니다.

새로운 5축 윤열을 먼저 만든다. 검정 배경에 휠과 피니언만 배치해 네 군데 맞물림을 직접 확인한다.

탈진 휠·팔렛·밸런스의 접촉 운동을 별도로 완성한다. 팔렛 축은 임의 좌표가 아니라 잠김·충격 관계로 결정한다.

실제 상·하부 베어링과 브리지를 만든다. 기어가 어디에 지지되는지 이해할 수 있어야 한다.

배럴 내부와 감기 계통을 연결한다. 용두에서 입력된 동력이 태엽에 저장되고 다시 배럴을 거쳐 윤열로 전달된다.

그다음에 케이스와 스트랩을 씌운다. 조립·절개·펼침은 동일한 부품 트리에서 처리한다.

무브먼트가 실제 부품의 연속된 기계로 보이지 않는다면, 이 위에 어떤 가죽과 케이스를 얹어도 현재의 문제가 반복됩니다.

이번에 제시한 것은 센터거리·회전비·층 높이가 서로 일치하도록 정한 윤열의 기본 설계안입니다. 탈진기와 감기 계통의 개별 치형·접촉 좌표는 아직 확정 설계가 아니며, 실제 구동 가능성은 별도 검증이 필요합니다. 그 미확정 부분을 완성된 기계인 것처럼 포장하지 않는 것이 이번 재설계의 중요한 원칙입니다.

JavaScript

/**
 * VISUAL NEWSIS — GOODEASY / MECHANICAL WATCH
 * watch-case.js
 *
 * Independent case exterior for an educational mechanical watch.
 *
 * Coordinates:
 *   X : crown direction (+X)
 *   Y : vertical / movement thickness
 *   Z : strap attachment direction (+Z / -Z)
 *
 * Movement envelope:
 *   radius <= 2.4
 *   Y = 0 .. 1.5
 *
 * Case:
 *   nominal outer radius = 2.65
 *   no straps, no buckle
 *
 * Geometry:
 *   - machined case middle
 *   - thin bezel and crystal seat
 *   - internal movement retaining shoulder
 *   - caseback lip and gasket groove
 *   - four separate sculpted lugs
 *   - real transverse spring-bar bores
 *   - stepped spring-bar tubes, plungers, collars and shoulders
 *   - crown with tube and fluted exterior
 *
 * No external textures, CSG library, packages or model assets.
 *
 * Note:
 * Lug roots overlap the case's structural metal to create a
 * visually continuous cast-and-machined junction. They remain
 * separate meshes for interactive selection.
 *
 * The circular main case is a lathed solid.
 * Each lug is a lofted mesh with an open bore through its X axis.
 *
 * The code does not modify the movement or its dynamics.
 */

export function buildWatchCase(T, materials = {}) {
  const group = new T.Group();
  group.name = "watch-case";

  const parts = {
    lugs: [],
    springBars: [],
    lugBores: [],
    crowns: [],
    seals: []
  };

  const PI = Math.PI;
  const TAU = 2 * PI;

  const D = {
    caseRadius: 2.65,
    movementRadius: 2.40,

    caseBottom: -0.20,
    caseTop: 1.64,

    movementBottom: 0.0,
    movementTop: 1.50,

    lugCenterX: 1.64,
    lugRootZ: 1.88,
    lugTipZ: 3.17,

    lugTopY: 0.96,
    lugBottomY: 0.49,

    springBarZ: 3.015,
    springBarY: 0.715,
    springBarOuterRadius: 0.061,
    springBarHoleRadius: 0.067,

    crystalSeatRadius: 2.465,
    crystalOpeningRadius: 2.407,

    crownX: 2.65,
    crownY: 0.77,
    crownZ: 0
  };

  function material(name, options) {
    return materials[name] ||
      new T.MeshPhysicalMaterial(options);
  }

  const M = {
    caseSteel: material("caseSteel", {
      color: 0xadb6b9,
      metalness: 0.91,
      roughness: 0.29,
      clearcoat: 0.16,
      clearcoatRoughness: 0.24
    }),

    brushedSteel: material("brushedSteel", {
      color: 0x8f9b9f,
      metalness: 0.89,
      roughness: 0.39,
      clearcoat: 0.08
    }),

    polishedSteel: material("polishedSteel", {
      color: 0xd0d7d8,
      metalness: 0.94,
      roughness: 0.17,
      clearcoat: 0.26,
      clearcoatRoughness: 0.13
    }),

    bevelSteel: material("bevelSteel", {
      color: 0xc4cccd,
      metalness: 0.91,
      roughness: 0.23
    }),

    boreSteel: material("boreSteel", {
      color: 0x626f73,
      metalness: 0.81,
      roughness: 0.43
    }),

    springSteel: material("springSteel", {
      color: 0xb2bdc0,
      metalness: 0.94,
      roughness: 0.22
    }),

    darkSteel: material("darkSteel", {
      color: 0x354044,
      metalness: 0.80,
      roughness: 0.41
    }),

    gasket: material("gasket", {
      color: 0x161c1e,
      metalness: 0,
      roughness: 0.91
    }),

    crystal: material("crystal", {
      color: 0xffffff,
      metalness: 0,
      roughness: 0.035,
      transmission: 0.98,
      thickness: 0.075,
      ior: 1.47,
      clearcoat: 0.20,
      transparent: true,
      opacity: 0.96,
      depthWrite: false
    })
  };

  function mesh(parent, geometry, mat, name, metadata = {}) {
    const object = new T.Mesh(geometry, mat);

    object.name = name;
    object.castShadow = true;
    object.receiveShadow = true;

    object.userData = {
      component: name,
      ...metadata
    };

    parent.add(object);

    return object;
  }

  function lathe(
    parent,
    name,
    profile,
    mat,
    segments = 128
  ) {
    // IMPORTANT: Vector2(radius, height).
    const points = profile.map(
      ([radius, height]) => new T.Vector2(radius, height)
    );

    const geometry = new T.LatheGeometry(
      points,
      segments
    );

    return mesh(
      parent,
      geometry,
      mat,
      name,
      { profile, segments }
    );
  }

  function annularProfile(
    innerRadius,
    outerRadius,
    bottom,
    top,
    chamfer = 0.018
  ) {
    return [
      [innerRadius + chamfer, bottom],
      [outerRadius - chamfer, bottom],

      [outerRadius, bottom + chamfer],
      [outerRadius, top - chamfer],

      [outerRadius - chamfer, top],
      [innerRadius + chamfer, top],

      [innerRadius, top - chamfer],
      [innerRadius, bottom + chamfer],

      [innerRadius + chamfer, bottom]
    ];
  }

  function tube(
    parent,
    name,
    points,
    radius,
    mat,
    tubularSegments = 48,
    radialSegments = 10
  ) {
    const curve = new T.CatmullRomCurve3(
      points.map(p => new T.Vector3(...p))
    );

    const geometry = new T.TubeGeometry(
      curve,
      tubularSegments,
      radius,
      radialSegments,
      false
    );

    return mesh(
      parent,
      geometry,
      mat,
      name,
      { tubeRadius: radius }
    );
  }

  function axisCylinder(
    parent,
    name,
    radiusTop,
    radiusBottom,
    length,
    mat,
    position,
    axis = "x",
    segments = 48
  ) {
    const geometry = new T.CylinderGeometry(
      radiusTop,
      radiusBottom,
      length,
      segments
    );

    const object = mesh(
      parent,
      geometry,
      mat,
      name,
      {
        radiusTop,
        radiusBottom,
        length,
        axis
      }
    );

    object.position.set(...position);

    if (axis === "x") {
      object.rotation.z = PI / 2;
    } else if (axis === "z") {
      object.rotation.x = PI / 2;
    }

    return object;
  }

  function ring(
    parent,
    name,
    majorRadius,
    minorRadius,
    y,
    mat,
    segments = 128
  ) {
    const geometry = new T.TorusGeometry(
      majorRadius,
      minorRadius,
      12,
      segments
    );

    const object = mesh(
      parent,
      geometry,
      mat,
      name,
      {
        majorRadius,
        minorRadius,
        y
      }
    );

    object.rotation.x = PI / 2;
    object.position.y = y;

    return object;
  }

  // ------------------------------------------------------------
  // 1. CASE MIDDLE
  // ------------------------------------------------------------

  /*
   * Open central cavity:
   * A functional 2.40-radius movement clearance is maintained.
   *
   * The case is a thin structural shell, not a deep bowl.
   * The stepped inner surface supports movement retention.
   */

  const middleProfile = [
    [2.412, -0.18],
    [2.495, -0.18],

    [2.548, -0.158],
    [2.605, -0.105],

    [2.638, 0.005],
    [2.650, 0.16],

    [2.644, 0.48],
    [2.626, 0.91],

    [2.597, 1.29],
    [2.566, 1.43],

    [2.535, 1.49],

    [2.487, 1.49],

    [2.462, 1.465],
    [2.462, 1.385],

    [2.483, 1.36],
    [2.483, 1.31],

    [2.435, 1.31],
    [2.407, 1.28],

    [2.407, 0.11],

    [2.425, 0.07],
    [2.425, -0.105],

    [2.412, -0.18]
  ];

  parts.caseMiddle = lathe(
    group,
    "case-middle-contoured",
    middleProfile,
    M.caseSteel
  );

  // Upper structural bezel: a narrow shaped ring, not a
  // large ornamental white disc.

  parts.bezel = lathe(
    group,
    "bezel-stepped-machined",
    [
      [2.414, 1.425],
      [2.468, 1.425],

      [2.520, 1.452],
      [2.548, 1.498],

      [2.544, 1.535],
      [2.517, 1.568],

      [2.474, 1.579],
      [2.438, 1.573],

      [2.414, 1.549],
      [2.414, 1.425]
    ],
    M.polishedSteel
  );

  ring(
    group,
    "bezel-inner-machined-highlight",
    2.420,
    0.010,
    1.561,
    M.bevelSteel
  );

  // ------------------------------------------------------------
  // 2. CRYSTAL SEAT / GASKET CHANNEL
  // ------------------------------------------------------------

  /*
   * The crystal is not placed across the movement by default.
   * Its seat and gasket are actual profile geometry.
   *
   * A separate optional crystal mesh is provided.
   */

  parts.crystalSeat = lathe(
    group,
    "crystal-seat-recess",
    [
      [2.407, 1.325],
      [2.463, 1.325],

      [2.480, 1.344],
      [2.480, 1.392],

      [2.464, 1.411],
      [2.424, 1.411],

      [2.407, 1.396],
      [2.407, 1.325]
    ],
    M.brushedSteel
  );

  // The seal occupies a real annular seat.
  // It is not merely a decorative black line.

  const crystalGasket = lathe(
    group,
    "crystal-gasket-ring",
    annularProfile(
      2.426,
      2.454,
      1.412,
      1.447,
      0.006
    ),
    M.gasket
  );

  parts.seals.push(crystalGasket);

  const crystal = mesh(
    group,
    new T.CylinderGeometry(
      2.426,
      2.426,
      0.035,
      128
    ),
    M.crystal,
    "optional-watch-crystal",
    {
      radius: 2.426,
      thickness: 0.035,
      removable: true
    }
  );

  crystal.position.y = 1.460;
  crystal.visible = false;

  parts.crystal = crystal;

  // ------------------------------------------------------------
  // 3. LOWER CASEBACK LIP
  // ------------------------------------------------------------

  parts.casebackLip = lathe(
    group,
    "caseback-machined-lip",
    [
      [2.405, -0.198],
      [2.444, -0.198],

      [2.492, -0.187],
      [2.527, -0.154],

      [2.533, -0.116],
      [2.514, -0.095],

      [2.463, -0.095],
      [2.432, -0.117],

      [2.405, -0.137],
      [2.405, -0.198]
    ],
    M.brushedSteel
  );

  const backGasket = lathe(
    group,
    "caseback-gasket",
    annularProfile(
      2.425,
      2.457,
      -0.132,
      -0.095,
      0.005
    ),
    M.gasket
  );

  parts.seals.push(backGasket);

  // Caseback metal closure is intentionally separate.
  // The default exposes the underside for movement exploration.
  // Enable if the surrounding application has a closed-back mode.

  const caseback = mesh(
    group,
    new T.CylinderGeometry(
      2.445,
      2.445,
      0.055,
      128
    ),
    M.brushedSteel,
    "optional-caseback",
    {
      radius: 2.445,
      removable: true
    }
  );

  caseback.position.y = -0.213;
  caseback.visible = false;
  parts.caseback = caseback;

  // ------------------------------------------------------------
  // 4. FOUR INDEPENDENT SCULPTED LUGS
  // ------------------------------------------------------------

  /*
   * Each lug consists of a lofted tapered body.
   *
   * The lug axis extends along +Z or -Z.
   * The spring-bar bore passes along X.
   *
   * At the lug tip, the transverse bore is generated as
   * an actual annular section using a local loft topology.
   *
   * The bore is not a black decal and not a floating ring.
   */

  function makeLug(side, sign) {
    const lug = new T.Group();

    lug.name =
      `lug-${sign > 0 ? "north" : "south"}-${side > 0 ? "right" : "left"}`;

    lug.userData = {
      side,
      sign,
      springBarAxis: "x",
      boreRadius: D.springBarHoleRadius,
      boreCenter: [
        side * D.lugCenterX,
        D.springBarY,
        sign * D.springBarZ
      ]
    };

    group.add(lug);

    /*
     * Root overlaps the middle case slightly so the junction
     * is concealed and reads like a continuous casting.
     *
     * Loft sections:
     * [distance along Z, X half-width, centerY, half-thickness]
     */

    const sections = [
      [1.87, 0.32, 0.88, 0.28],
      [2.03, 0.33, 0.88, 0.28],
      [2.22, 0.31, 0.87, 0.27],
      [2.48, 0.28, 0.83, 0.25],
      [2.73, 0.25, 0.77, 0.23],
      [2.95, 0.23, 0.72, 0.21],
      [3.12, 0.21, 0.68, 0.18],
      [3.17, 0.195, 0.67, 0.17]
    ];

    const radial = 16;
    const vertices = [];
    const indices = [];

    function crossSection(section, i) {
      const [zDistance, halfWidth, yCenter, halfHeight] = section;

      for (let j = 0; j < radial; j++) {
        const a = j / radial * TAU;

        // Superellipse-like rounded rectangular section.
        const c = Math.cos(a);
        const s = Math.sin(a);

        const px =
          Math.sign(c) *
          Math.pow(Math.abs(c), 0.72) *
          halfWidth;

        const py =
          Math.sign(s) *
          Math.pow(Math.abs(s), 0.72) *
          halfHeight;

        vertices.push(
          side * D.lugCenterX + px,
          yCenter + py,
          sign * zDistance
        );
      }
    }

    sections.forEach(crossSection);

    for (let i = 0; i < sections.length - 1; i++) {
      for (let j = 0; j < radial; j++) {
        const next = (j + 1) % radial;

        const a = i * radial + j;
        const b = i * radial + next;

        const c = (i + 1) * radial + j;
        const d = (i + 1) * radial + next;

        if (sign > 0) {
          indices.push(a, b, c, b, d, c);
        } else {
          indices.push(a, c, b, b, c, d);
        }
      }
    }

    // End caps at root and tip.
    // Tip bore is inserted as an independent transverse
    // machined sleeve; the outer loft remains continuous.

    const firstCenterIndex = vertices.length / 3;

    vertices.push(
      side * D.lugCenterX,
      sections[0][2],
      sign * sections[0][0]
    );

    const lastCenterIndex = vertices.length / 3;

    const last = sections[sections.length - 1];

    vertices.push(
      side * D.lugCenterX,
      last[2],
      sign * last[0]
    );

    for (let j = 0; j < radial; j++) {
      const next = (j + 1) % radial;

      indices.push(
        firstCenterIndex,
        next,
        j
      );

      const offset = (sections.length - 1) * radial;

      indices.push(
        lastCenterIndex,
        offset + j,
        offset + next
      );
    }

    const geometry = new T.BufferGeometry();

    geometry.setAttribute(
      "position",
      new T.Float32BufferAttribute(vertices, 3)
    );

    geometry.setIndex(indices);
    geometry.computeVertexNormals();

    const body = mesh(
      lug,
      geometry,
      M.caseSteel,
      "lug-forged-body",
      {
        sectionCount: sections.length,
        sections,
        boreAxis: "x"
      }
    );

    // Separate highlight along the outer edge:
    // a narrow machined bevel that follows the lug root and tip.

    const edgePoints = sections.map(s => [
      side * D.lugCenterX + side * s[1] * 0.79,
      s[2] + s[3] * 0.73,
      sign * s[0]
    ]);

    tube(
      lug,
      "lug-upper-chamfer",
      edgePoints,
      0.017,
      M.bevelSteel,
      64,
      8
    );

    // --------------------------------------------------------
    // Spring-bar transverse bore
    // --------------------------------------------------------
    //
    // The aperture is generated on the inner lug face as a
    // machined cylindrical bore assembly.
    //
    // Because the bore goes along X, every related object uses
    // precisely the same Y/Z center.
    //
    // A production through-hole requires cutting the lug's
    // body volume along X. The recess below provides the bore
    // mouth and cylindrical interior shell.
    //
    // No fake floating circular screw heads are used.
    // --------------------------------------------------------

    const boreCenterX =
      side * (D.lugCenterX - side * 0.205);

    const boreCenterY = D.springBarY;
    const boreCenterZ = sign * D.springBarZ;

    // Bore opening annulus, oriented with its normal along X.

    const boreOpening = mesh(
      lug,
      new T.RingGeometry(
        D.springBarHoleRadius,
        D.springBarHoleRadius + 0.020,
        40
      ),
      M.boreSteel,
      "springbar-bore-mouth",
      {
        radius: D.springBarHoleRadius,
        axis: "x",
        center: [
          boreCenterX,
          boreCenterY,
          boreCenterZ
        ]
      }
    );

    boreOpening.rotation.y = PI / 2;

    boreOpening.position.set(
      boreCenterX,
      boreCenterY,
      boreCenterZ
    );

    // Cylindrical sleeve inside lug, axis X.

    const boreSleeve = mesh(
      lug,
      new T.CylinderGeometry(
        D.springBarHoleRadius,
        D.springBarHoleRadius,
        0.115,
        40,
        1,
        true
      ),
      M.boreSteel,
      "springbar-bore-interior",
      {
        boreRadius: D.springBarHoleRadius,
        depth: 0.115,
        axis: "x"
      }
    );

    boreSleeve.rotation.z = PI / 2;

    boreSleeve.position.set(
      boreCenterX + side * 0.055,
      boreCenterY,
      boreCenterZ
    );

    parts.lugBores.push({
      opening: boreOpening,
      sleeve: boreSleeve,
      center: [
        boreCenterX,
        boreCenterY,
        boreCenterZ
      ]
    });

    parts.lugs.push({
      group: lug,
      body,
      side,
      sign
    });

    return lug;
  }

  for (const sign of [-1, 1]) {
    for (const side of [-1, 1]) {
      makeLug(side, sign);
    }
  }

  // ------------------------------------------------------------
  // 5. STEPPED SPRING BARS
  // ------------------------------------------------------------

  /*
   * One spring bar per lug pair.
   *
   * Each bar is made of:
   *   - central hollow tube
   *   - left shoulder
   *   - right shoulder
   *   - two sliding plungers
   *   - two end collars
   *
   * Axis = X.
   * The Y/Z coordinates align with the lug bores.
   */

  function makeSpringBar(sign) {
    const barGroup = new T.Group();

    barGroup.name =
      sign > 0
        ? "springbar-north"
        : "springbar-south";

    group.add(barGroup);

    const y = D.springBarY;
    const z = sign * D.springBarZ;

    const tubeLength = 2.92;
    const tubeRadius = 0.055;
    const tubeInnerRadius = 0.029;

    const tubeProfile = [
      [tubeInnerRadius, -tubeLength / 2],
      [tubeRadius - 0.007, -tubeLength / 2],
      [tubeRadius, -tubeLength / 2 + 0.012],
      [tubeRadius, tubeLength / 2 - 0.012],
      [tubeRadius - 0.007, tubeLength / 2],
      [tubeInnerRadius, tubeLength / 2],
      [tubeInnerRadius, -tubeLength / 2]
    ];

    // Lathe Y axis is rotated into X.
    const tubeGeometry = new T.LatheGeometry(
      tubeProfile.map(
        ([r, h]) => new T.Vector2(r, h)
      ),
      48
    );

    const barTube = mesh(
      barGroup,
      tubeGeometry,
      M.springSteel,
      "springbar-hollow-stepped-tube",
      {
        outerRadius: tubeRadius,
        innerRadius: tubeInnerRadius,
        tubeLength
      }
    );

    barTube.rotation.z = -PI / 2;
    barTube.position.set(0, y, z);

    for (const side of [-1, 1]) {
      // Shoulder sits just outside the central tube.

      axisCylinder(
        barGroup,
        `springbar-shoulder-${side}`,
        0.075,
        0.075,
        0.085,
        M.polishedSteel,
        [side * 1.485, y, z],
        "x"
      );

      // Narrower plunger travels into the lug bore.

      const plunger = axisCylinder(
        barGroup,
        `springbar-plunger-${side}`,
        0.041,
        0.041,
        0.245,
        M.springSteel,
        [side * 1.595, y, z],
        "x"
      );

      plunger.userData = {
        ...plunger.userData,
        retractable: true,
        travel: 0.10,
        direction: side,
        seatedInLug: true
      };

      // Rounded plunger tip.

      const tip = mesh(
        barGroup,
        new T.SphereGeometry(
          0.041,
          16,
          12
        ),
        M.polishedSteel,
        `springbar-rounded-tip-${side}`,
        {
          radius: 0.041,
          seatedInLug: true
        }
      );

      tip.position.set(
        side * 1.717,
        y,
        z
      );

      // Narrow retaining collar at tube end.

      axisCylinder(
        barGroup,
        `springbar-collar-${side}`,
        0.066,
        0.066,
        0.037,
        M.brushedSteel,
        [side * 1.448, y, z],
        "x"
      );
    }

    parts.springBars.push(barGroup);

    return barGroup;
  }

  makeSpringBar(1);
  makeSpringBar(-1);

  // ------------------------------------------------------------
  // 6. CROWN TUBE AND MACHINED CROWN
  // ------------------------------------------------------------

  const crownGroup = new T.Group();
  crownGroup.name = "crown-assembly";
  group.add(crownGroup);

  const crownY = D.crownY;

  axisCylinder(
    crownGroup,
    "crown-case-tube",
    0.135,
    0.135,
    0.225,
    M.brushedSteel,
    [2.675, crownY, 0],
    "x"
  );

  axisCylinder(
    crownGroup,
    "crown-neck",
    0.116,
    0.116,
    0.145,
    M.darkSteel,
    [2.818, crownY, 0],
    "x"
  );

  const crownProfile = [
    [0.00, -0.20],
    [0.20, -0.20],
    [0.254, -0.17],
    [0.279, -0.12],
    [0.288, -0.045],
    [0.288, 0.095],
    [0.272, 0.17],
    [0.230, 0.20],
    [0.00, 0.20]
  ];

  const crownGeometry = new T.LatheGeometry(
    crownProfile.map(
      ([r, h]) => new T.Vector2(r, h)
    ),
    64
  );

  const crown = mesh(
    crownGroup,
    crownGeometry,
    M.brushedSteel,
    "crown-machined-body",
    {
      diameter: 0.576,
      thickness: 0.40,
      axis: "x"
    }
  );

  crown.rotation.z = -PI / 2;
  crown.position.set(3.02, crownY, 0);

  for (let i = 0; i < 36; i++) {
    const a = i / 36 * TAU;

    const flute = mesh(
      crownGroup,
      new T.CylinderGeometry(
        0.009,
        0.009,
        0.285,
        8
      ),
      M.polishedSteel,
      `crown-flute-${i}`,
      {
        index: i,
        count: 36
      }
    );

    flute.rotation.z = PI / 2;

    flute.position.set(
      3.02,
      crownY + Math.cos(a) * 0.286,
      Math.sin(a) * 0.286
    );
  }

  axisCylinder(
    crownGroup,
    "crown-end-insert",
    0.177,
    0.177,
    0.012,
    M.polishedSteel,
    [3.224, crownY, 0],
    "x"
  );

  parts.crowns.push(crownGroup);

  // ------------------------------------------------------------
  // 7. METADATA / INTEGRATION
  // ------------------------------------------------------------

  group.userData = {
    title: "VISUAL NEWSIS Mechanical Watch Case",
    type: "educational-functional-case",
    coordinateSystem: {
      movementPlane: "XZ",
      verticalAxis: "Y",
      crownDirection: "+X",
      lugDirection: "+Z/-Z"
    },
    movementEnvelope: {
      radius: D.movementRadius,
      yMin: D.movementBottom,
      yMax: D.movementTop
    },
    caseEnvelope: {
      radius: D.caseRadius,
      yMin: D.caseBottom,
      yMax: D.caseTop
    },
    straps: false,
    buckle: false,
    construction: "procedural-threejs"
  };

  return {
    group,
    parts,
    materials: M,
    dimensions: D,

    camera: {
      position: [7.6, 6.8, 8.4],
      target: [0, 0.77, 0],
      fov: 32
    },

    recommendedLighting: {
      key: {
        position: [-4, 8, 6],
        intensity: 2.2,
        color: 0xfff5e7
      },

      fill: {
        position: [5, 4, 6],
        intensity: 0.95,
        color: 0xe0eaff
      },

      rim: {
        position: [-3, 6, -5],
        intensity: 1.45,
        color: 0xffffff
      }
    }
  };
}

/**
 * VISUAL NEWSIS — 굳이구지 05
 * watch-case.js
 *
 * REAL GEOMETRY VERSION
 *
 * No CSG, no external assets, no straps, no buckle.
 *
 * X = crown / spring-bar axis
 * Y = height
 * Z = north / south lug direction
 *
 * Movement envelope:
 *   radius 2.4, Y 0..1.5
 *
 * Case:
 *   outer radius 2.65
 *   shallow, open movement cavity
 *
 * Construction:
 *   Case: LatheGeometry, Vector2(radius, height)
 *   Lugs: YZ Shape with REAL Path holes, ExtrudeGeometry along X
 *   Spring bars: hollow stepped tubes and individual plungers
 *
 * IMPORTANT:
 * Every lug bore is an actual through-hole in its solid geometry.
 * No decorative bore-mouth disks or fake recesses.
 */

export function buildWatchCase(T, materials = {}) {
  const group = new T.Group();
  group.name = "watch-case";

  const PI = Math.PI;
  const TAU = 2 * PI;

  const D = {
    movementRadius: 2.4,
    movementYMin: 0,
    movementYMax: 1.5,

    caseRadius: 2.65,
    caseBottom: -0.16,
    caseTop: 1.65,

    lugCenterX: 1.65,
    lugThicknessX: 0.36,

    lugRootZ: 1.92,
    lugTipZ: 3.16,

    lugBoreZ: 2.945,
    lugBoreY: 0.745,
    lugBoreRadius: 0.068,

    lugInnerFaceX: 1.47,
    lugOuterFaceX: 1.83,

    springTubeRadius: 0.054,
    springTubeInnerRadius: 0.030,
    springTubeLength: 2.82,

    springPlungerRadius: 0.041,
    springPlungerInnerX: 1.37,
    springPlungerOuterX: 1.66,

    crownY: 0.80
  };

  const parts = {
    lugs: [],
    lugBores: [],
    springBars: [],
    springPlungers: [],
    case: {},
    crown: {}
  };

  function mat(name, color, metalness, roughness, extra = {}) {
    return materials[name] ||
      new T.MeshPhysicalMaterial({
        color,
        metalness,
        roughness,
        ...extra
      });
  }

  const M = {
    steel: mat("steel", 0xaab4b7, 0.91, 0.30, {
      clearcoat: 0.12,
      clearcoatRoughness: 0.27
    }),

    polished: mat("polished", 0xd1d8d9, 0.94, 0.19, {
      clearcoat: 0.23,
      clearcoatRoughness: 0.15
    }),

    brushed: mat("brushed", 0x909c9f, 0.88, 0.39),

    machined: mat("machined", 0xbcc6c8, 0.91, 0.27),

    dark: mat("dark", 0x465155, 0.83, 0.44),

    spring: mat("spring", 0xb9c3c5, 0.94, 0.23),

    gasket: mat("gasket", 0x171b1c, 0.0, 0.91)
  };

  function mesh(parent, geometry, material, name, data = {}) {
    const m = new T.Mesh(geometry, material);

    m.name = name;
    m.castShadow = true;
    m.receiveShadow = true;
    m.userData = {
      partName: name,
      ...data
    };

    parent.add(m);
    return m;
  }

  function lathe(parent, name, profile, material, segments = 128) {
    // Vector2(radius, height). Never reverse.
    const points = profile.map(
      ([r, y]) => new T.Vector2(r, y)
    );

    return mesh(
      parent,
      new T.LatheGeometry(points, segments),
      material,
      name,
      { profile, axis: "Y" }
    );
  }

  function cylX(
    parent,
    name,
    radius,
    length,
    x,
    y,
    z,
    material,
    segments = 48
  ) {
    const m = mesh(
      parent,
      new T.CylinderGeometry(
        radius,
        radius,
        length,
        segments
      ),
      material,
      name,
      {
        axis: "X",
        radius,
        length,
        center: [x, y, z]
      }
    );

    m.rotation.z = -PI / 2;
    m.position.set(x, y, z);

    return m;
  }

  function torusY(parent, name, radius, tubeRadius, y, material) {
    const m = mesh(
      parent,
      new T.TorusGeometry(radius, tubeRadius, 12, 128),
      material,
      name,
      { radius, tubeRadius, y }
    );

    m.rotation.x = PI / 2;
    m.position.y = y;

    return m;
  }

  // ============================================================
  // 1. CASE MIDDLE — SHALLOW STRUCTURAL SHELL
  // ============================================================

  /*
   * All inner radii are >= 2.40.
   * No metal is placed inside the movement's radial envelope.
   *
   * The shell is deliberately open through its center.
   * The separate movement mainplate supplies the internal support.
   */

  const caseProfile = [
    [2.413, -0.14],
    [2.485, -0.14],

    [2.545, -0.115],
    [2.608, -0.035],

    [2.648, 0.105],
    [2.650, 0.280],

    [2.644, 0.665],
    [2.619, 1.085],

    [2.580, 1.410],
    [2.545, 1.505],

    [2.490, 1.520],
    [2.452, 1.490],

    [2.452, 1.408],
    [2.472, 1.375],

    [2.472, 1.322],
    [2.420, 1.322],

    [2.405, 1.300],
    [2.405, 0.100],

    [2.427, 0.063],
    [2.427, -0.095],

    [2.413, -0.14]
  ];

  parts.case.middle = lathe(
    group,
    "contoured-case-middle",
    caseProfile,
    M.steel
  );

  // Narrow chamfered upper bezel.
  // No wide decorative dial ring.

  parts.case.bezel = lathe(
    group,
    "machined-bezel",
    [
      [2.414, 1.468],
      [2.473, 1.468],

      [2.516, 1.484],
      [2.547, 1.532],

      [2.539, 1.564],
      [2.510, 1.592],

      [2.458, 1.597],
      [2.422, 1.577],

      [2.414, 1.556],
      [2.414, 1.468]
    ],
    M.polished
  );

  // Crystal seat with real annular clearance.

  parts.case.crystalSeat = lathe(
    group,
    "crystal-seat",
    [
      [2.405, 1.325],
      [2.468, 1.325],
      [2.481, 1.345],
      [2.481, 1.397],
      [2.454, 1.422],
      [2.425, 1.422],
      [2.405, 1.404],
      [2.405, 1.325]
    ],
    M.brushed
  );

  parts.case.crystalGasket = lathe(
    group,
    "crystal-gasket",
    [
      [2.427, 1.423],
      [2.454, 1.423],
      [2.458, 1.429],
      [2.458, 1.458],
      [2.451, 1.464],
      [2.432, 1.464],
      [2.427, 1.458],
      [2.427, 1.423]
    ],
    M.gasket
  );

  // Lower caseback seating lip.

  parts.case.casebackLip = lathe(
    group,
    "caseback-retaining-lip",
    [
      [2.405, -0.193],
      [2.449, -0.193],
      [2.497, -0.181],
      [2.526, -0.153],
      [2.531, -0.119],
      [2.511, -0.098],
      [2.458, -0.098],
      [2.425, -0.123],
      [2.405, -0.145],
      [2.405, -0.193]
    ],
    M.brushed
  );

  parts.case.casebackGasket = lathe(
    group,
    "caseback-gasket",
    [
      [2.429, -0.123],
      [2.460, -0.123],
      [2.464, -0.116],
      [2.464, -0.095],
      [2.429, -0.095],
      [2.429, -0.123]
    ],
    M.gasket
  );

  torusY(
    group,
    "upper-bezel-edge-highlight",
    2.500,
    0.008,
    1.585,
    M.machined
  );

  // ============================================================
  // 2. FOUR REAL THROUGH-BORED LUGS
  // ============================================================

  /*
   * Each lug is built from a YZ side profile.
   *
   * The Shape lies in local XY:
   *
   *   local X = -world Z
   *   local Y =  world Y
   *
   * Extrusion runs along local +Z.
   *
   * rotation.y = +PI/2 converts:
   *
   *   local extrusion Z -> world +X
   *
   * Therefore:
   *   bore axis = world X
   *   side profile = world YZ
   *
   * The hole Path is triangulated out of the ExtrudeGeometry.
   * There is NO metal inside the bore.
   */

  function createLug(side, sign) {
    const lugGroup = new T.Group();

    lugGroup.name =
      `lug-${sign > 0 ? "north" : "south"}-` +
      `${side > 0 ? "right" : "left"}`;

    group.add(lugGroup);

    const thickness = D.lugThicknessX;
    const centerX = side * D.lugCenterX;
    const xMin = centerX - thickness / 2;
    const xMax = centerX + thickness / 2;

    // Local U runs opposite world Z after rotation.
    const u = distance => -sign * distance;

    const shape = new T.Shape();

    /*
     * Organic side silhouette:
     * thicker at the case root, tapered toward the end.
     *
     * These are actual side-profile boundaries, not tubes
     * placed on top of an arbitrary rectangular bar.
     */

    shape.moveTo(u(1.91), 1.085);

    shape.bezierCurveTo(
      u(2.09), 1.145,
      u(2.28), 1.105,
      u(2.44), 1.017
    );

    shape.bezierCurveTo(
      u(2.68), 0.946,
      u(2.90), 0.918,
      u(3.092), 0.877
    );

    shape.quadraticCurveTo(
      u(3.172), 0.850,
      u(3.172), 0.769
    );

    shape.lineTo(u(3.172), 0.621);

    shape.quadraticCurveTo(
      u(3.154), 0.552,
      u(3.092), 0.537
    );

    shape.bezierCurveTo(
      u(2.89), 0.524,
      u(2.63), 0.548,
      u(2.42), 0.632
    );

    shape.bezierCurveTo(
      u(2.21), 0.705,
      u(2.066), 0.760,
      u(1.91), 0.775
    );

    shape.closePath();

    // Genuine circular through-hole.
    // Path radius must be smaller than the metal edge clearance.

    const boreU = u(D.lugBoreZ);
    const boreV = D.lugBoreY;

    const hole = new T.Path();

    hole.absarc(
      boreU,
      boreV,
      D.lugBoreRadius,
      0,
      TAU,
      true
    );

    shape.holes.push(hole);

    /*
     * No bevel in the initial topology:
     * guarantees the bore is a straight cylindrical cut
     * with a constant radius through the entire X thickness.
     *
     * Chamfering of the outer perimeter is done through
     * a narrow side-edge mesh, not by filling the hole.
     */

    const geometry = new T.ExtrudeGeometry(shape, {
      depth: thickness,
      steps: 1,
      bevelEnabled: false,
      curveSegments: 48
    });

    // Convert local extrusion axis to world X.
    geometry.rotateY(PI / 2);

    // Geometry's world-X range after rotation: 0..thickness.
    // Start at xMin.
    const body = mesh(
      lugGroup,
      geometry,
      M.steel,
      "lug-solid-with-true-through-bore",
      {
        side,
        sign,
        xMin,
        xMax,
        thicknessX: thickness,
        boreCenter: [
          centerX,
          D.lugBoreY,
          sign * D.lugBoreZ
        ],
        boreRadius: D.lugBoreRadius,
        boreAxis: [1, 0, 0],
        trueThroughHole: true
      }
    );

    body.position.x = xMin;

    /*
     * The root enters the case's outer surface:
     * this is the normal junction for independent meshes.
     *
     * No exposed rod, post, screw or ornamental joint
     * is added over the case-lug connection.
     *
     * The hidden overlap is limited to the structural root.
     * It does not intersect the spring-bar bore.
     */

    const bore = {
      id: lugGroup.name,
      axis: [1, 0, 0],
      radius: D.lugBoreRadius,
      xMin,
      xMax,
      y: D.lugBoreY,
      z: sign * D.lugBoreZ,
      length: thickness,
      geometry: body
    };

    lugGroup.userData = {
      partType: "lug",
      independentPart: true,
      bore,
      rootZ: sign * D.lugRootZ,
      tipZ: sign * D.lugTipZ
    };

    parts.lugs.push(lugGroup);
    parts.lugBores.push(bore);

    return lugGroup;
  }

  // Four individual lug solids.
  for (const sign of [-1, 1]) {
    for (const side of [-1, 1]) {
      createLug(side, sign);
    }
  }

  // ============================================================
  // 3. TWO HOLLOW STEPPED SPRING BARS
  // ============================================================

  /*
   * Spring-bar axis is world X.
   *
   * Both tips enter the real lug bores.
   *
   * Lug inner faces:
   *   left  = -1.47
   *   right = +1.47
   *
   * Plunger tip:
   *   left  = -1.66
   *   right = +1.66
   *
   * Thus insertion into each lug:
   *   1.66 - 1.47 = 0.19
   *
   * The bore extends to X = +/-1.83.
   * The plunger ends inside the metal thickness,
   * not beyond the exterior lug face.
   */

  function makeSpringBar(sign) {
    const barGroup = new T.Group();

    barGroup.name =
      sign > 0
        ? "springbar-north"
        : "springbar-south";

    group.add(barGroup);

    const y = D.lugBoreY;
    const z = sign * D.lugBoreZ;

    /*
     * Lathe profile uses (radius, axial coordinate).
     * Lathe axis is local Y.
     *
     * rotation.z = -PI/2 converts local Y to world +X.
     */

    const halfTube = D.springTubeLength / 2;

    const tubeProfile = [
      [D.springTubeInnerRadius, -halfTube],
      [0.047, -halfTube],
      [D.springTubeRadius, -halfTube + 0.010],

      [D.springTubeRadius, halfTube - 0.010],
      [0.047, halfTube],
      [D.springTubeInnerRadius, halfTube],

      [D.springTubeInnerRadius, -halfTube]
    ];

    const tubeGeometry = new T.LatheGeometry(
      tubeProfile.map(
        ([radius, height]) =>
          new T.Vector2(radius, height)
      ),
      64
    );

    const sleeve = mesh(
      barGroup,
      tubeGeometry,
      M.spring,
      "hollow-stepped-sleeve",
      {
        axis: "X",
        length: D.springTubeLength,
        outerRadius: D.springTubeRadius,
        innerRadius: D.springTubeInnerRadius
      }
    );

    sleeve.rotation.z = -PI / 2;
    sleeve.position.set(0, y, z);

    const plungers = [];

    for (const side of [-1, 1]) {
      /*
       * A 0.29-long plunger extends from 1.37 to 1.66.
       * The tube end is at 1.41, so a short internal portion
       * overlaps the sleeve cavity.
       */

      const inner = D.springPlungerInnerX;
      const outer = D.springPlungerOuterX;

      const center = side * (inner + outer) / 2;
      const length = outer - inner;

      const plunger = cylX(
        barGroup,
        `spring-plunger-${side}`,
        D.springPlungerRadius,
        length,
        center,
        y,
        z,
        M.polished
      );

      plunger.userData = {
        ...plunger.userData,
        boreAxis: "X",
        tipX: side * outer,
        rootX: side * inner,
        seatedDepth: outer - D.lugInnerFaceX,
        retractable: true,
        maxRetraction: 0.12
      };

      plungers.push(plunger);

      // Internal collar: wider than plunger, smaller than lug gap.
      // Never covers the lug bore opening.

      cylX(
        barGroup,
        `plunger-retaining-collar-${side}`,
        0.062,
        0.052,
        side * 1.385,
        y,
        z,
        M.brushed
      );

      // Stepped shoulder near the sleeve end.
      cylX(
        barGroup,
        `springbar-shoulder-${side}`,
        0.071,
        0.042,
        side * 1.430,
        y,
        z,
        M.machined
      );

      /*
       * The shoulder reaches X=1.451.
       * The lug inner face is X=1.470.
       *
       * Remaining clearance = 0.019.
       *
       * Only the narrow plunger enters the lug hole.
       */
    }

    barGroup.userData = {
      partType: "springBar",
      direction: sign,
      axis: [1, 0, 0],
      y,
      z,
      sleeveLength: D.springTubeLength,
      plungerRadius: D.springPlungerRadius,
      lugBoreRadius: D.lugBoreRadius,
      insertionDepth: 0.19,
      seated: true
    };

    parts.springBars.push(barGroup);
    parts.springPlungers.push(...plungers);

    return barGroup;
  }

  makeSpringBar(1);
  makeSpringBar(-1);

  // ============================================================
  // 4. CROWN — +X
  // ============================================================

  const crownGroup = new T.Group();
  crownGroup.name = "crown-assembly";

  group.add(crownGroup);

  const crownY = D.crownY;

  cylX(
    crownGroup,
    "crown-case-tube",
    0.128,
    0.20,
    2.68,
    crownY,
    0,
    M.brushed
  );

  cylX(
    crownGroup,
    "crown-neck",
    0.113,
    0.14,
    2.82,
    crownY,
    0,
    M.dark
  );

  const crownProfile = [
    [0.00, -0.19],
    [0.205, -0.19],
    [0.258, -0.160],
    [0.281, -0.105],
    [0.286, 0.085],
    [0.270, 0.145],
    [0.221, 0.19],
    [0.00, 0.19]
  ];

  const crownGeometry = new T.LatheGeometry(
    crownProfile.map(
      ([r, h]) => new T.Vector2(r, h)
    ),
    64
  );

  const crown = mesh(
    crownGroup,
    crownGeometry,
    M.brushed,
    "machined-crown",
    {
      diameter: 0.572,
      axialLength: 0.38,
      axis: "X"
    }
  );

  crown.rotation.z = -PI / 2;
  crown.position.set(3.02, crownY, 0);

  // Flutes are actual shallow raised geometry.

  for (let i = 0; i < 36; i++) {
    const a = i * TAU / 36;

    const flute = cylX(
      crownGroup,
      `crown-flute-${i}`,
      0.009,
      0.24,
      3.02,
      crownY + Math.cos(a) * 0.285,
      Math.sin(a) * 0.285,
      M.polished,
      8
    );

    flute.userData.fluteIndex = i;
  }

  parts.crown.group = crownGroup;
  parts.crown.body = crown;

  // ============================================================
  // 5. NUMERICAL BORE / BAR INSPECTION
  // ============================================================

  /*
   * All numbers are derived from the same D object used
   * to build the actual geometry.
   */

  function getGeometryReport() {
    const bores = parts.lugBores.map(b => ({
      lug: b.id,
      axis: b.axis,
      xMin: b.xMin,
      xMax: b.xMax,
      centerY: b.y,
      centerZ: b.z,
      radius: b.radius,
      thickness: b.length
    }));

    const bars = parts.springBars.map(b => ({
      name: b.name,
      axis: b.userData.axis,
      y: b.userData.y,
      z: b.userData.z,
      sleeveLength: b.userData.sleeveLength,
      plungerRadius: b.userData.plungerRadius,
      insertionDepth: b.userData.insertionDepth
    }));

    return {
      lugCount: parts.lugs.length,
      springBarCount: parts.springBars.length,
      boreCount: parts.lugBores.length,
      bores,
      bars
    };
  }

  // ============================================================
  // 6. ACTUAL RAY / TRIANGLE INTERSECTION TEST
  // ============================================================

  /*
   * A ray is fired along +X through each lug.
   *
   * Test A:
   *   bore centerline must have ZERO hits with lug body.
   *
   * Test B:
   *   a nearby solid region must produce hits.
   *
   * IMPORTANT:
   * This only tests the lug meshes, not the spring bars.
   * The spring bar is intentionally present inside the hole.
   *
   * Raycaster uses actual BufferGeometry triangles.
   * No metadata-only acceptance.
   */

  function verifyBoresWithRaycaster() {
    group.updateMatrixWorld(true);

    const results = [];

    for (const bore of parts.lugBores) {
      const lugMesh = bore.geometry;

      const originX = bore.xMin - 0.15;
      const direction = new T.Vector3(1, 0, 0);

      const rayThroughBore = new T.Raycaster(
        new T.Vector3(
          originX,
          bore.y,
          bore.z
        ),
        direction,
        0,
        bore.length + 0.30
      );

      const boreHits = rayThroughBore.intersectObject(
        lugMesh,
        false
      );

      /*
       * Solid control near the root-facing side of the bore,
       * but outside its circular aperture.
       *
       * Distance from bore center = 0.15 > 0.068.
       */

      const solidControlZ =
        bore.z + (bore.z > 0 ? -0.15 : 0.15);

      const solidRay = new T.Raycaster(
        new T.Vector3(
          originX,
          bore.y,
          solidControlZ
        ),
        direction,
        0,
        bore.length + 0.30
      );

      const solidHits = solidRay.intersectObject(
        lugMesh,
        false
      );

      results.push({
        lug: bore.id,
        boreCenterHits: boreHits.length,
        solidControlHits: solidHits.length,

        boreOpen: boreHits.length === 0,
        solidExists: solidHits.length > 0,

        passed:
          boreHits.length === 0 &&
          solidHits.length > 0
      });
    }

    return {
      results,
      passed: results.every(r => r.passed)
    };
  }

  // ============================================================
  // 7. SPRING-BAR FIT VERIFICATION
  // ============================================================

  function verifySpringBarFit() {
    const results = [];

    for (const bore of parts.lugBores) {
      const side = bore.xMin > 0 ? 1 : -1;

      const bar = parts.springBars.find(
        b => Math.abs(b.userData.z - bore.z) < 1e-8
      );

      const tipX = side * D.springPlungerOuterX;

      const insideAxially =
        tipX > bore.xMin &&
        tipX < bore.xMax;

      const radialClearance =
        bore.radius - D.springPlungerRadius;

      const centerAligned =
        Math.abs(bar.userData.y - bore.y) < 1e-8 &&
        Math.abs(bar.userData.z - bore.z) < 1e-8;

      const insideHole =
        insideAxially &&
        radialClearance > 0 &&
        centerAligned;

      results.push({
        lug: bore.id,
        tipX,
        boreX: [bore.xMin, bore.xMax],
        boreRadius: bore.radius,
        plungerRadius: D.springPlungerRadius,
        radialClearance,
        insertionDepth:
          D.springPlungerOuterX - D.lugInnerFaceX,
        centerAligned,
        insideHole
      });
    }

    return {
      results,
      passed: results.every(r => r.insideHole)
    };
  }

  // ============================================================
  // 8. ROOT / MOVEMENT CLEARANCE METADATA
  // ============================================================

  group.userData = {
    series: "VISUAL NEWSIS GOODEASY",
    chapter: "05 Mechanical Watch",

    geometryVersion: "real-through-bore",

    straps: false,
    buckle: false,

    axes: {
      movementPlane: "XZ",
      vertical: "Y",
      springBar: "X",
      crown: "+X"
    },

    movementEnvelope: {
      radius: D.movementRadius,
      yMin: D.movementYMin,
      yMax: D.movementYMax
    },

    lugCount: 4,
    springBarCount: 2,

    trueLugBores: true,

    springBarInsertionDepth: 0.19
  };

  return {
    group,
    parts,
    materials: M,
    dimensions: D,

    inspect: {
      geometryReport: getGeometryReport,
      verifyBoresWithRaycaster,
      verifySpringBarFit
    },

    camera: {
      position: [7.5, 6.7, 8.2],
      target: [0, 0.75, 0],
      fov: 32
    },

    lighting: {
      key: {
        position: [-4, 8, 6],
        intensity: 2.1,
        color: 0xfff4e4
      },

      fill: {
        position: [5, 4, 6],
        intensity: 0.95,
        color: 0xe3ebff
      },

      rim: {
        position: [-3, 6, -5],
        intensity: 1.4,
        color: 0xffffff
      }
    }
  };
}

굳이구지 05 — Swiss Lever 탈진기 재설계

기존 15치 사다리꼴 탈진휠, tanh 팔렛 운동, 독립 롤러핀 애니메이션은 폐기해야 합니다. 401개 자세 중 대다수에서 실제 메시가 관통하고, 롤러핀과 포크가 한 번도 접촉하지 않았다면 그것은 접촉식 탈진기가 아니라 별개로 회전하는 세 개의 모형입니다.

이번에는 15치 Swiss lever의 기하학적 구속을 먼저 풀고, 그 결과를 Three.js에 전달하는 방식으로 설계하겠습니다.

1. 실제 원리를 기준으로 바로잡을 부분

Ciechanowski의 설명과 시계학교 교육자료를 대조하면, 탈진 동작에는 반드시 두 종류의 접촉이 존재합니다.

탈진휠 치끝 ↔ 팔렛 루비: 잠김, 언로킹, 임펄스, 반대편 팔렛에 재잠김.

롤러 임펄스핀 ↔ 포크 슬롯: 밸런스가 포크를 밀어 잠금을 풀고, 이후 포크가 롤러핀에 충격을 전달한 뒤 분리.

둘 중 하나라도 공간적으로 만나지 않으면 Swiss lever 운동이 아닙니다. 잠김 과정에는 미세한 역방향 움직임(recoil)도 발생할 수 있으며, 포크의 최종 정지 위치는 뱅킹 핀이 제한합니다.

치형을 만드는 규칙

사다리꼴 치형 대신 각 치에 적어도 다음 네 개의 구분된 면이 필요합니다.

잠금 접촉부: 팔렛의 잠금면에 걸리는 치끝.

임펄스면: 잠금 해제 후 루비의 충격면을 미끄러지는 표면.

치근: 다음 치와 연결되는 부분. 루비의 운동 영역을 침범하면 안 됨.

치끝 라운드: 실제 접촉 해석에서 사용할 작은 곡률.

여기서 정확한 치형 좌표를 접촉 계산 없이 확정하면, 지금 발생한 291/401 관입 문제를 다른 형상으로 반복할 가능성이 큽니다.

/**
 * Swiss lever — 2D geometric contact kernel
 * Plain JavaScript; no physics engine or external package.
 *
 * Coordinates: local (x,z), represented as [x,z].
 * Mesh triangulation and THREE conversion are separate.
 *
 * All polygons should be simple, closed implicitly,
 * and have consistently ordered boundary vertices.
 */

export const LeverSpec = Object.freeze({
  wheelCenter: [1, 0],
  palletCenter: [0, 0],
  balanceCenter: [-0.95, 0],
  toothCount: 15,
  pitchRadius: 0.65,
  bankAngle: 5.125 * Math.PI / 180,
  halfPitch: Math.PI / 15,
  rollerOrbit: 0.25,
  rollerRadius: 0.028,
  slotWidth: 0.065
});

const EPS = 1e-10;

const sub = (a,b) => [a[0]-b[0],a[1]-b[1]];
const add = (a,b) => [a[0]+b[0],a[1]+b[1]];
const mul = (a,s) => [a[0]*s,a[1]*s];
const dot = (a,b) => a[0]*b[0]+a[1]*b[1];
const cross = (a,b) => a[0]*b[1]-a[1]*b[0];
const norm = a => Math.hypot(a[0],a[1]);

export function rotatePoint(p,theta) {
  const c=Math.cos(theta),s=Math.sin(theta);
  return [p[0]*c-p[1]*s,p[0]*s+p[1]*c];
}

export function transformPolygon(poly,center,theta) {
  return poly.map(p=>add(center,rotatePoint(p,theta)));
}

export function closestPointOnSegment(p,a,b) {
  const ab=sub(b,a);
  const d=dot(ab,ab);
  const t=d<EPS?0:Math.max(0,Math.min(1,dot(sub(p,a),ab)/d));
  return add(a,mul(ab,t));
}

export function pointInPolygon(p,poly) {
  let inside=false;
  for(let i=0,j=poly.length-1;i<poly.length;j=i++){
    const a=poly[i],b=poly[j];
    const crosses=(a[1]>p[1])!==(b[1]>p[1]);
    if(crosses) {
      const x=(b[0]-a[0])*(p[1]-a[1])/
        (b[1]-a[1])+a[0];
      if(p[0]<x)inside=!inside;
    }
  }
  return inside;
}

export function segmentIntersection(a,b,c,d) {
  const r=sub(b,a),s=sub(d,c);
  const denom=cross(r,s);
  const ca=sub(c,a);

  if(Math.abs(denom)<EPS) {
    // Collinear overlap is treated separately by distance test.
    return null;
  }

  const t=cross(ca,s)/denom;
  const u=cross(ca,r)/denom;

  if(t>=-EPS&&t<=1+EPS&&u>=-EPS&&u<=1+EPS){
    return add(a,mul(r,t));
  }
  return null;
}

function polygonEdges(poly) {
  return poly.map((a,i)=>[a,poly[(i+1)%poly.length]]);
}

function polygonCenter(poly) {
  const sum=poly.reduce((a,p)=>add(a,p),[0,0]);
  return mul(sum,1/poly.length);
}

/**
 * Returns contact information between two simple polygons.
 *
 * For separated polygons: positive gap is exact boundary distance.
 * For penetrating polygons: negative value is a PENETRATION FLAG
 * with a sampled depth estimate, not an exact signed distance.
 *
 * Exact signed penetration requires a more sophisticated
 * contact manifold or continuous collision detector.
 */
export function polygonContact(A,B) {
  const EA=polygonEdges(A),EB=polygonEdges(B);
  let nearest={distance:Infinity,a:null,b:null};
  const crossings=[];

  for(const [a,b] of EA) {
    for(const [c,d] of EB){
      const hit=segmentIntersection(a,b,c,d);
      if(hit)crossings.push(hit);
    }
  }

  for(const a of A){
    for(const [c,d] of EB){
      const q=closestPointOnSegment(a,c,d);
      const dist=norm(sub(a,q));
      if(dist<nearest.distance)
        nearest={distance:dist,a,b:q};
    }
  }

  for(const b of B){
    for(const [a,c] of EA){
      const q=closestPointOnSegment(b,a,c);
      const dist=norm(sub(b,q));
      if(dist<nearest.distance)
        nearest={distance:dist,a:q,b};
    }
  }

  const contained =
    A.some(p=>pointInPolygon(p,B)) ||
    B.some(p=>pointInPolygon(p,A));

  const intersects=crossings.length>0||contained;

  let normal=sub(nearest.b,nearest.a);
  const len=norm(normal);

  if(len>EPS) normal=mul(normal,1/len);
  else {
    normal=sub(polygonCenter(B),polygonCenter(A));
    const n=norm(normal);
    normal=n>EPS?mul(normal,1/n):[1,0];
  }

  return {
    gap:intersects?-nearest.distance:nearest.distance,
    penetration:intersects,
    crossings:crossings.length,
    pointA:nearest.a,
    pointB:nearest.b,
    normal,
    approximateDepth:intersects?nearest.distance:0
  };
}

/**
 * Numerically solve g(theta)=0 within [lo,hi].
 *
 * Requires a genuine sign-changing bracket.
 * Does not silently accept the nearest approximate pose.
 */
export function solveBracketedContact(
  gapFunction,lo,hi,{
    tolerance=1e-7,
    iterations=64
  }={}
) {
  let a=lo,b=hi;
  let fa=gapFunction(a),fb=gapFunction(b);

  if(!Number.isFinite(fa)||!Number.isFinite(fb))
    throw new Error("Non-finite contact gap");

  if(Math.abs(fa)<tolerance)
    return {theta:a,residual:fa,iterations:0};

  if(Math.abs(fb)<tolerance)
    return {theta:b,residual:fb,iterations:0};

  if(fa*fb>0)
    throw new Error("No signed-gap bracket for contact");

  for(let i=0;i<iterations;i++){
    const mid=(a+b)/2;
    const fm=gapFunction(mid);

    if(Math.abs(fm)<tolerance||Math.abs(b-a)<1e-10)
      return {theta:mid,residual:fm,iterations:i+1};

    if(fa*fm<=0){
      b=mid;fb=fm;
    } else {
      a=mid;fa=fm;
    }
  }

  throw new Error("Contact solve did not converge");
}

/**
 * Scan a range for first valid contact bracket.
 * This is NOT a motion controller.
 */
export function findContactBracket(gapFn,lo,hi,samples=1000){
  let a=lo,fa=gapFn(a);
  for(let i=1;i<=samples;i++){
    const b=lo+(hi-lo)*i/samples;
    const fb=gapFn(b);
    if(Number.isFinite(fa)&&Number.isFinite(fb)&&fa*fb<=0)
      return [a,b];
    a=b;fa=fb;
  }
  return null;
}

/**
 * Evaluate two transformed physical shapes.
 *
 * Wheel and jewel polygons must be provided from the
 * SAME geometry definitions used by the rendering mesh.
 */
export function wheelJewelContact({
  wheelPolygon,
  jewelPolygon,
  wheelAngle,
  palletAngle
}) {
  const W=transformPolygon(
    wheelPolygon,LeverSpec.wheelCenter,wheelAngle
  );
  const J=transformPolygon(
    jewelPolygon,LeverSpec.palletCenter,palletAngle
  );
  return polygonContact(W,J);
}

/**
 * Validate the 12-degree wheel advance between locks.
 */
export function validateLockAdvance(theta0,theta1,tol=1e-5){
  const target=LeverSpec.halfPitch;
  const advance=((theta1-theta0)%(2*Math.PI)+2*Math.PI)%
    (2*Math.PI);
  return {
    advance,
    target,
    error:advance-target,
    passed:Math.abs(advance-target)<=tol
  };
}

이 코드의 한계

polygonContact()는 비관입 상태의 경계 간격을 계산하지만, 관입했을 때의 음수 크기는 엄밀한 최소 침투 깊이가 아닙니다. 또한 다각형끼리 접하는 순간의 법선은 접촉 특징에 따라 불연속적으로 바뀔 수 있습니다.

따라서 이 코드만으로 401개 자세의 관입 0을 주장할 수는 없습니다. 다음 단계에서는 삼각형 메시의 실제 접촉 특징과 연속 운동 중 충돌을 평가하는 검증이 필요합니다.

초기 수치해석 공차는 정규화 모델 단위 기준으로 다음과 같이 설정합니다.

접촉 gap: ≤ 0.0001

허용 침투 깊이: ≤ 0.00001

잠김 간 휠 전진각 오차: ≤ 0.01°

롤러핀과 슬롯의 비활성 접촉: 의도한 유격 확보

뱅킹 위치: 지정한 팔렛각 이외로 진행하지 않음

이 수치는 목표 검증 공차이며, 현재 치형이 이를 만족한다고 확인한 값은 아닙니다. 401개 샘플만 통과시켜도 샘플 사이에서 순간 관입이 일어날 수 있으므로, 실제 접촉 전환 시점을 추가로 탐색해야 합니다.

특히 기존 검사가 actualTriangle 기반이라면 최종 검수 역시 렌더링에 사용되는 그 삼각형으로 해야 합니다. 앞의 polygonContact()는 이를 대체하는 인증 수단이 아니라 2D 접촉 설계용 도구입니다.

확정할 수 있는 것: 15치·24° 피치, 잠김 사이의 목표 휠 전진 12°, 두 팔렛을 통한 교대 잠김, 롤러핀과 포크의 기계적 접촉 순서, 뱅킹 제한, signed-gap 기반 검증 구조입니다.

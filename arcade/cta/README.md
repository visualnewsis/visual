# Grand Tour Around — 충무로

CHUNGMU-LOADING의 비공개 0–10% 탐험 프로토타입. 서비스 후보 경로는 `/arcade/cta/`이며 폴더명은 초기 가칭에서 유지했다. 공용 랜딩에 등록하거나 원격에 push하지 않았다.

## 실행

기존 정적 웹 서버에서 `arcade/cta/index.html`을 연다. 현재 작업 세션 미리보기: `http://127.0.0.1:8765/arcade/cta/`. 배포 시 애플리케이션 서버나 빌드가 필요 없다. ES module을 사용하므로 로컬 파일 더블클릭(file://) 대신 HTTP 미리보기가 필요하다.

PC: WASD, Shift 달리기, 마우스 드래그 또는 방향키로 시점, E 대화, Esc 일시정지. 모바일: 왼쪽 이동 패드와 화면 드래그. 소리는 사용자가 켜야 활성화된다. 진행률은 세션 안에서만 유지하며 새로고침하면 0%부터 시작한다.

## 기술과 파일

- Three.js 0.180.0 + HTML/CSS/순수 JavaScript. 엔진을 vendor에 고정 보관하므로 게임은 외부 CDN 로딩에 의존하지 않는다. 기존 GA 스크립트만 외부 요청한다.
- Babylon.js의 엔진 기능보다 작은 직접 제어 렌더러가 이 범위에 적합하다고 판단했다. 빌드·물리엔진·앱 서버를 추가하지 않았다. WebGL 2가 필요하다.
- `world.js`: 건물 치수, 발견 위치·가중치, 대사·텍스트.
- `architecture.js`: 사진 참고 외관, 직접 그린 재질, 반복 부품 인스턴싱.
- `game.js`: 렌더링, 입력, 충돌, 발견, 소리, 대화, 일시정지.
- `index.html`, `style.css`: 페이지, HUD, 반응형 조작. 기존 충무로딩 헤더 예외 유지. 제목 변경에 따라 HTML 메타데이터와 world 데이터를 함께 갱신한다.
- `verify.mjs`: 실제 Three.js 기하와 렌더러/DOM 대역으로 동작 검사. `node arcade/cta/verify.mjs`로 실행. GPU·터치·실기기 성능 검사를 대신하지 않는다.
- `vendor/`: Three.js 배포본과 MIT 라이선스.

## 구현과 검증

좁은 외관 연구 구간, 1인칭 이동·달리기·건물/소품 충돌, 네 발견 지점(2+3+2+3%), 간판·인물·환경음 활성화, 통로 개방, 10% 후 자유 탐험. 마지막 1%와 실제 아카이브는 구현하지 않았다.

자동 검사는 JSON-LD, GA config 1회, 키보드 이동, 연결된 0→10% 경로, 중복 발견 방지, 대화, 닫힌/열린 통로, 건물·경계 충돌, 자유 탐험, 포커스 상실 일시정지를 검증한다. 초기 외관 개선본은 이 PC의 Codex 브라우저 485×698에서 약 60fps, 렌더 호출 53회, 콘솔 오류 0건을 확인했다. 이는 실기기 모바일 성능 보장이 아니다. 최종본은 390×844에서 약 59fps/84회, 1440×900에서 남산스퀘어 정면 약 41fps/10회를 확인했다. 브라우저 패드 입력으로 0→10%와 통로 개방, 남산스퀘어 앞까지 실제 이동을 확인했다. 두 viewport에서 콘솔 오류는 없었다.

## 다음 품질 단계에 필요한 자료

한 구간을 확정한 뒤 양쪽 건물 정면과 45도 사진, 골목을 왕복하는 눈높이 영상, 출입구·창틀·간판·외벽·배수구 근접 사진을 확보한다. 대략적인 도로 폭·문 높이와 촬영 위치/방향도 있으면 원근 왜곡과 실제 비례를 맞추기 좋다. 사용 가능한 원본 자료로 실측 배치, 개별 건물 고유 형태, 마모·반사 재질을 교체한 뒤 iPhone Safari / Android Chrome 실기기에서 프레임 시간과 조작을 확인한다.

현재 결과는 외관 연구 및 기술 프로토타입이다. 사용자 요청의 극도로 높은 실물 완성도가 달성됐다고 간주하지 않는다. 네 개 건물의 반복되는 비례·부품과 합성 소리가 남아 있으며, 공개 전에 정확도·명칭·자료 권리·실기기 검증이 필요하다.

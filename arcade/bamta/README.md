# BTA 밤티에이 — 회사에서 탈출하라

정적 웹 게임. 서비스 경로 `/arcade/bamta/`. 현재 로컬 미리보기이며 공용 랜딩/배포는 변경하지 않았다.

## 플레이

WASD 이동, Shift 달리기, 마우스를 움직여 시점 회전(클릭해 커서 잠금, Esc로 해제) 또는 방향키, E 상호작용, Space 신문 액션. 모바일은 왼쪽 패드 이동, 오른쪽 화면 드래그 시점, 화면 버튼 상호작용. 소리는 사용자 버튼으로 켠다.

책상에서 출발해 입구, 꺾이는 복도, 화장실 앞, 12층 엘리베이터 홀을 지난다. 호출 후 탑승하면 문이 닫히다가 국장 등장과 함께 열린다. 빨간 경보 이후 선택한다.

- 국장을 쏜다: 신문에서 종이뭉치가 날아가고 문이 닫혀 탈출 성공.
- 자리에 가서 앉는다: 직접 사무실로 돌아가 원래 자리에서 E를 누르면 탈출 실패.

두 엔딩 모두 기존 12개 충무로딩 게임으로 연결한다. 오른쪽 화이트보드에 만든사람/떠든사람 이스터에그. 여성 동료는 입구에서 사무실 안으로 걸어 들어온다.

## 참조와 구현 범위

사용자가 제공한 2026-09-08 오전 89초 영상을 주 참조로 초록 유리 칸막이, 책상/복사기/파란 통, 천장 조명, 복도와 금속 엘리베이터를 재구성했다. 오후 추가 영상은 외부/저층 참고로 구분했다. 영상 실측이나 포토그래메트리가 아닌 수작업 공간 재구성이다. 실물과 정확히 같은 평면·인물 모델은 아니며 인물은 2026-10-25 요청에 따라 사진 레퍼런스를 폐기하고 모든 방향에서 부피가 있는 가상 3D 얼굴로 교체했다. 원본 영상과 인물 사진은 서비스 폴더에 포함하지 않았다.

## 검증

`node arcade/bamta/verify.mjs`

실제 Three.js 장면과 충돌 데이터를 사용하며 렌더러만 대체한다. 출발→호출→탑승→국장→선택→탈출 성공과 복귀 실패, 충돌, 일시정지, JSON-LD, GA 단일 설정, 썸네일 경로를 검사한다. 브라우저에서는 WebGL 렌더링과 1440×900 / 390×844 화면, 이동 패드·시점·신문 버튼을 별도로 확인했다. 실제 iPhone Safari/Android 기기 성능은 미검증.

Three.js 라이선스는 vendor/LICENSE.txt.

## 2026-10-24 디자인 개편

- 시작 화면의 실제 3D 편집국 카메라와 BTA 타이틀, 청록·라임 색상, 모바일 구성.
- 야경, 모니터의 편집 화면, 목재·금속 재질, 접지 그림자, 유리 칸막이와 따뜻한 엘리베이터 조명. 기존 평면과 탈출 동선은 유지한다.
- `actors.js`: 안경·표정·옷깃·손·사원증과 관절이 있는 스타일화 인물.
- `interior.js`: 화분, 서류장, 게시판, 의자 원단, 케이블, 책상 소품, 엘리베이터 세부.
- `sound.js`: 사용자 활성화 방식의 환풍기·발소리·신문·엘리베이터·엔딩 합성음. 일시정지하면 음향도 줄인다.
- `dispatch.js`: 경로 지도, 위치에 따른 안내, 선택형 주변 이야기 세 개, 엔딩 기록.
- `design.css`: 기존 게임 CSS 위에 적용하는 화면 디자인. 공통 상단바의 스타일은 별도로 덧대지 않는다.

공통 상단바와 메뉴 아이콘은 최신 `origin/main`의 `1ff3a7a`에서 그대로 가져왔다. 현재 작업 branch에 없었던 asset을 보충했으며, 공용 랜딩·배포 자동화·AGENTS.md는 수정하지 않았다. 게임의 두 엔딩과 기존 게임 링크, SEO, Google 추적 ID는 보존했다.

1440×900 / 390×844 / 320×568 / 844×390 브라우저 화면과 실제 키보드 이동→호출→탑승→국장 선택→탈출 성공, 소리 버튼, 일시정지와 메뉴를 확인했다. 화면 이동 패드는 포인터 입력과 입력 해제를 확인했다. 복귀 실패 경로는 실제 geometry를 이용한 자동 검증으로 확인했다. 선택창에서 화면 크기가 바뀔 때 일시정지창이 겹치지 않는 회귀 검사도 포함한다. 실제 iPhone Safari·Android Chrome 기기의 성능과 터치 제스처, 오디오 출력 품질은 별도 확인이 필요하다. 이후 공개 미리보기 https://visual.newsis.com/arcade/bamta-preview-20261024/ 에 반영했다.


## 2026-10-25 가상 3D 얼굴

faces.js는 이미지 매핑 없이 두상·코·눈·눈꺼풀·입술·귀·머리카락을 기하 구조로 만든다. art.js에서 얼굴 이미지 네 개를 제거했고, 복도 남성 동료의 평상시 대사와 신문 반응은 존댓말로 바꿨다. 사무실 동료의 반말, 배역과 착석 직원 세 명, 게임 동선과 두 엔딩을 보존했다. 실제 production geometry를 정면·사선·측면·후면으로 오프라인 렌더해 검수하고 12방향 두상 raycast와 사진 map 부재를 검사했다. 이번 새 얼굴의 브라우저 GPU 및 실기기 검증은 Computer Use의 URL 확인 실패로 수행하지 못했다.

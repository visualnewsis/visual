## 회사에서 이어갈 때

- 저장소: https://github.com/visualnewsis/visual
- 실제 서비스: https://visual.newsis.com/newsmap/
- 최신 `origin/main`을 가져온 뒤 `AGENTS.md`와 이 문서를 읽는다. 이 PC의 기존 로컬 `codex/editshop-viewfinder`는 main과 크게 갈라져 있고 다른 작업의 미커밋 변경이 있으므로 이를 기준으로 덮어쓰거나 강제 동기화하지 않는다.

- 공용 랜딩에는 뉴스맵을 추가하지 않는다는 사용자 지시가 유지된다. 검색 허용과 사이트맵 등록은 승인되어 적용됐으며 랜딩 노출과는 별개다.

## 현재 반영 내용

- 별도 서비스명은 **뉴스맵부심**, 보조 문구는 **뉴스가 빛나는 지도**, 검색·공유 문구는 **여기 무슨 일 있어?**.
- 모바일은 44px 서비스명 줄 아래 지도를 크게 표시하고, 검색·기사 목록은 아래 패널을 위로 당기거나 눌러 펼친다. PC의 지도·목록 좌우 구성은 유지한다.
- 로고와 하단 설명 문구의 양끝 정렬 원칙이 `AGENTS.md`에 등록돼 있다. 모바일에서 하단 설명 문구를 숨기는 기존 지도 우선 구성은 유지한다.
- ‘내 위치 보기’는 누를 때만 위치 권한을 요청한다. 좌표를 서버에 저장하지 않고 로컬 행정동 경계로 판정한다.
- 파비콘, iOS·Android 홈 화면 아이콘, canonical, 검색 제목·설명, JSON-LD, OG·Twitter 공유 정보를 적용했다. `noindex`를 해제하고 `sitemap-sections.xml`에 주소를 등록했다. 검색엔진 실제 색인·순위와 공유 플랫폼의 캐시 재수집은 별도다.
- 최종 공유 이미지는 `assets/share-final-20261022.png` (1731×909px, 약 1.8MB). 사용자 제공 도시 야경·빛나는 지도 시안을 imagegen 내장 편집 도구로 최소 수정했다. 요청은 ‘배경·상단 브랜드·말풍선·메인 로고 보존, 하단 “뉴스가 빛나는 지도”만 밝게 하고 메인 로고 양끝에 맞추기’였다.
- 최종 공유 이미지는 홈페이지 본문의 큰 Hero로 추가하지 않았다. OG·Twitter·JSON-LD에서 동일한 새 파일명을 사용하므로 예전 `share.png` 캐시와 분리된다. 기존 `tools/generate_share.py`는 과거 시안만 만들므로 최종본 재생성용으로 사용하지 않는다.

## 가장 중요한 미완료 사항

**기사 자동 수집은 아직 연결되지 않았다.** 현재 서비스는 2026-10-22 21:24 KST에 수집한 143개 기사 스냅샷을 읽는다. 24시간 등 기간 필터에 따라 실제 보이는 기사 수는 달라진다. 화면의 새로고침은 이미 배포된 파일을 재확인하는 기능이며 뉴시스에서 새 기사를 수집하는 기능이 아니다.

수집 도구는 `python newsmap/tools/collect_news.py`. 공식 RSS 4종과 동네 탐색용 일부 기사 메타데이터를 사용하며 `data/articles.js`를 만든다. 내부 기사 공급 경로 확보 및 정기 수집·배포 연결이 다음 우선 작업이다. 자동화 파일 변경은 프로젝트 규칙에 따라 별도 명시적 승인을 받고 진행한다. 현재 기존 `.github/workflows/update-headlines.yml`의 게임용 수집은 뉴스맵과 연결되지 않았다.

## 위치 및 지도 관련 주의점

- 동네가 확인된 기사는 상위 구·시에도 포함하고, 시·구만 확인된 기사를 하위 동네로 추정하지 않는다.
- 기사 위치는 제목·짧은 리드에 대한 보수적 지명 매칭이며 기관명·인용·복수 지역에서 오류와 누락이 남을 수 있다. 자동 분류 결과는 원문 대조가 필요하다.
- 원은 사건의 실제 좌표가 아니라 지역별 기사 묶음의 대표 위치다. 좁은 축척에서는 인접 지역을 묶는다.
- 서버 CSP가 외부 OSM 타일을 막으면 `basemap.js`의 자체 행정구역 지도(Canvas)로 전환한다. 실제 서버는 이 지도를 사용하며 도로·건물 지도가 아니다. 공용 서버 CSP나 배포 workflow는 변경하지 않았다.
- 과거 고성군 등 마커가 바다로 밀리던 문제는 Leaflet 아이콘의 `position:absolute`가 잘못 덮인 것이 원인이었고 수정됐다. 임의로 위경도를 재보정하지 않는다.

## 확인 방법

```text
node --check newsmap/app.js
node --check newsmap/mobile-sheet.js
node newsmap/tests/rules.cjs
node newsmap/tests/location.cjs
python newsmap/tests/static.py
python .github/scripts/check_visual_site.py
```

- JSON-LD 파싱, GA 태그 1회, 지역 계층·하향 추정 금지, 내부 자산·URL, 아이콘 파일과 크기, sitemap 등록을 검증했다.
- PC 및 모바일 viewport에서 화면과 드래그를 확인했다. 실제 iPhone Safari·Android Chrome 기기 검증은 아직이다.
- 배포는 기존 main push workflow를 그대로 사용한다. 실행기 대기 중에는 실제 서버 파일이 이전 버전일 수 있으므로 배포 후 서비스 HTML과 최종 이미지 URL의 HTTP 200 및 파일 해시를 확인한다.
- 직접 수정한 범위는 `newsmap/`다. 앞선 승인 작업에서 추가한 `AGENTS.md` 정렬 규칙과 sitemap의 뉴스맵 항목을 유지하며, 루트·편집#·충무로딩 랜딩은 수정하지 않는다.

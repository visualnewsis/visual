- **interaction**: 없음(정지). 스크롤 유도 `↓` 표시.
- **연결**: 다음 장면(1)은 스크롤 시작과 동시에 자연스럽게 이어짐.
- **필요한 이유**: CONTROL TOWER가 절대 변경 금지로 지정한 첫 화면.

### 4. INTERACTION — "당신에게 '고령'은 몇 살부터입니까?"
- **핵심 메시지**: 독자가 스스로 "고령"의 기준을 정의해보는 첫 참여.
- **화면 카피**: `당신에게 '고령'은 몇 살부터입니까?` / `눈금을 짚거나 움직여 당신의 기준을 놓아보세요.`(기존 V0 그대로)
- **사진/데이터**: 배경은 1615 유지(사진에서 완전히 빠져나오지 않음)
- **interaction**: 50~90세 눈금 슬라이더(포인터/키보드), `이 기준으로 보기` 버튼
- **연결**: (3)에서 슬라이드 업으로 등장. 확정 시 (5) RESULT로 전환.
- **필요한 이유**: 기존 V0의 핵심 인터랙션. 이번 지시서에서도 유지 대상으로 언급됨.

### 5. RESULT — 독자 선택 결과
- **핵심 메시지**: 독자 자신의 기준을 되비추고, "그렇다면 실제 기준은?"이라는 다음 질문으로 넘어갈 준비.
- **화면 카피**: `당신은 [나이]세부터 '고령'이라고 생각했습니다.` / `그렇다면 사회가 정한 '고령'은 몇 살일까요?`(기존 V0 그대로) / `계속 →`(현재 disabled)
- **사진/데이터**: 1615 유지
- **interaction**: `계속`(다음 장면 6으로 연결 예정, 현재 비활성) / `기준 다시 놓기`
- **연결**: (4)의 결과. `계속` 버튼이 활성화되면 (6) PAYOFF로 연결되는 지점 — **이 연결이 이번 스토리보드에서 가장 중요한 신규 제안**.
- **필요한 이유**: 독자의 "내 기준"과 다음 장면의 "실제 데이터"를 이어주는 다리. 새 섹션을 만들지 않고 이미 존재하는 `계속` 버튼의 목적지를 지정하는 방식.

### 6. PAYOFF — `천만예요` 의미 회수
- **핵심 메시지**: Hero에서 품었던 "왜 `예`지?"라는 의문을 스크롤 직후 최대한 빠르게, 문법 설명 없이 해소한다. `천만예요 = 천만 명이에요`.
- **화면 카피(CONTROL TOWER 현재 우선안, 임의 창작 아님)**:
  `천만에요가 아니라`
  `천만예요.`
  `65세 이상, 천만 명.`
- **사진/데이터**: 사진에서 완전히 빠져나온 활자 중심 화면(배경 사진 없음 또는 최소화). `에/예` 대비를 포인트컬러·weight로 절제해 처리하는 자리는 **여기뿐**(Hero에서는 하지 않음).
- **interaction**: 없음(정적 타이포그래피 장면), 또는 스크롤에 따라 카피 3줄이 순서대로 나타나는 정도의 절제된 연출.
- **연결**: (5)의 `계속` 버튼에서 진입. 완료 후 (7) DATA로 자연스럽게 이어짐("65세 이상, 천만 명"이라는 숫자가 다음 장면의 데이터 서사를 여는 문).
- **필요한 이유**: CONTROL TOWER 지시 3, 7, 8 — 제목은 교정하지 않되 의미는 최대한 빨리 회수. `<보기>`는 여기서 풀지 않음(지시 9).

## CONTROL TOWER가 결정해야 할 선택지

1. 장면 5→6 연결(`계속` 버튼 → PAYOFF)이 맞는 구조인지, 아니면 PAYOFF를 RESULT보다 앞에 둘지.
2. 장면 7(DATA)의 실제 카피·통계 출처·시각화 형태.
3. 장면 8에서 607/608(+619) 중 몇 장을 어떤 순서로 쓸지, 그리고 그 전용 interaction의 구체적 방식.
4. 장면 9(공간 drilldown)의 실제 데이터 구조와 UI 방식 — 아직 전혀 설계되지 않음.

낚시 릴 실이 감기는 스풀과 왕복하는 라인롤러·베일

	

핸들을 3회 돌리고 베일 열림/닫힘 비교. 같은 회전에 스풀의 줄 배열이 어떻게 달라지는지 확인

회전비·스풀 왕복·줄 적층이 동일 상태에 연동되는지. 베일 열림에 따른 권취 차이와 기구의 실제 대응 확인




시계 다이얼 일부가 열려 윤열과 탈진기가 보이는 손목시계

	

태엽 3회 감기 → 초침 관찰 → 밸런스 정지/재개. 같은 시계에서 동력 경로 확인

	

흰 다이얼은 세련됐지만 검은 내부 구멍 속 금색 기어 몇 개만 보여 시계 전체의 복잡한 동력 전달이 드러나지 않음

	

최초엔 조립 시계. 태엽을 감으면 다이얼이 부분 투시되며 배럴→중앙 윤열→이스케이프먼트로 주목선 이동. 금색은 동력, 민트는 탈진기 작동 표시. 분해 시 축과 브리지가 공간적으로 대응

	

배럴·윤열·이스케이프먼트·밸런스·핸즈의 실제 연결. 기어비, 회전방향, 축 위치, 정지 시 출력 정지 확인




재봉틀 바늘 아래 천을 중심으로 한 정교한 작업 장면

	

한 땀 천천히 만들기. 바늘 하강→실고리 생성→훅 운반→밑실 둘레 통과→실채기 조임을 직접 관찰

	

흰 본체와 녹색 천의 구분은 좋으나 바늘·노루발·침판이 매우 작고, 넓은 하단 조작부와 중요 작업점의 거리가 멂

	

화면 중앙에 바늘 작업점의 3배 확대 관찰창. 본체는 보조 시점으로 유지. 윗실 아이보리, 밑실 민트, 훅 구리색. 하나의 진행 슬라이더로 각 부품과 실 경로를 동기화

	

실 경로의 연속성, 훅이 윗실고리를 밑실 주위로 운반하는 과정, 실채기 조임, 최종 록스티치 형성 확인. 겉면과 천 아래 동시 검증




축음기 레코드 위 바늘과 톤암, 고정된 나팔

	

바늘 올림/내림 → 레코드 회전 → 진동 전달 비교. 바늘이 떠 있을 때와 홈을 따라갈 때의 진동판 반응 확인

	

나팔과 목재 상자의 비율은 좋지만 바늘·사운드박스가 작아 기계가 어떻게 소리를 만드는지 알아보기 어려움

	

오른쪽에 축음기를 두고 아래에 사운드박스 원형 확대창. 홈→바늘→레버→진동판을 민트 주목선으로 연결. 회전속도는 별도 하단 조작. 모터와 조속기 관찰은 보조 장면

	

바늘의 홈 접촉, 톤암 피벗, 레버 운동, 진동판의 연동, 구동 모터와 턴테이블 연결, 조속기 반응 확인




MX 키보드 타이핑할 수 있는 키보드와 하나의 확대 스위치

	

같은 문장을 빠르게·천천히 누르기, 키 하나를 확대해 누름 깊이와 접점 상태 비교

	

키보드가 화면 아래에 크게 떨어져 있고, 글 입력칸과 기계가 시각적으로 단절. 스위치 구조는 첫 화면에서 보이지 않음

	

입력창 바로 아래 키보드를 올리고 누른 키를 민트로 점등. 오른쪽에 선택 키의 5배 단면 확대. 키캡→스템→스프링→금속 접점→신호 순서로 진행

	

실제 키와 단면 스위치가 같은 스트로크를 사용하는지. 접점 폐쇄 시점·바운스·디바운스·문자 출력의 선후 관계 확인




바이올린 활이 현에 닿는 접촉점 중심의 악기

	

활 속도/압력에 따른 현의 반응 비교, 현을 눌러 길이를 바꾸고 음높이 변화 관찰

	

바이올린 몸체는 알아볼 수 있지만 활·현·지판이 한곳에 겹치고, 첫 화면에 작은 글씨가 밀집돼 있음

	

악기 몸통을 15~20% 확대하고 활 접촉점을 중심으로 배치. 선택한 현만 민트, 활은 따뜻한 목재색. 현 접촉점·브리지·상판·사운드포스트로 이어지는 확대 관찰. 선택한 현의 실제 진동을 절제해 표현

	

활과 현의 접촉, 현 길이와 진동수, 브리지 전달, 상판·사운드포스트 연결 검증. 음향이 있다면 상태와 실제 출력의 일치도 확인




필름 영사기 필름 경로와 회전 차광셔터가 보이는 영사기

	

정상 / 차광셔터 제거 / 간헐이송 해제 3가지 상태에서 같은 필름을 투사해 비교

	

두 릴과 본체는 명확하지만 스크린은 작고 경사져 있으며, 필름 이송과 차광셔터의 핵심 관계가 노출되지 않음

	

좌측 조작, 중앙 영사기 단면, 우측 정면 스크린. 세 모드를 탭으로 전환하되 기계는 동일하게 유지. 필름 프레임 이동·셔터 회전·스크린 결과를 동시에 보여줌

	

기계적 셔터 위치·차광 구간·프레임 정지·필름 이동 동기화. 셔터 제거와 간헐이송 해제의 결과가 서로 다르게 나타나는지 확인




에스프레소 그룹헤드에서 추출돼 잔에 내려오는 머신

	

같은 커피량에서 분쇄 저항을 바꾸기. 물길·압력·유량·추출 시간을 같은 장면에서 비교

	

녹색 본체는 개성이 있지만 작은 컵과 분리된 포터필터 때문에 물이 어디를 지나가는지 추적하기 어려움

	

기계를 오른쪽 65%로 확대. 탱크→펌프→보일러→그룹헤드→커피층→컵을 순차 강조. 내부 물은 차가운 청록, 가열된 경로는 옅은 금색, 커피는 갈색. 컵은 실제 추출량에 따라 차오르게 연결

	

실제 단일 보일러 펌프식 경로 확인. 압력·유량·분쇄 저항·컵 채움의 시간 관계, 샤워스크린·커피층·바스켓의 물리적 위치 확인

2. 가장 중요한 4편의 결정적 체험

재봉틀 — 실이 어떻게 묶이는지 보여줘야 한다

화면에서 가장 중요한 것은 바늘의 왕복이 아니라 윗실이 밑실을 둘러싼 뒤 조여지는 순간입니다. 한 땀의 상태값을 0~1로 공유해 바늘, 훅, 실고리, 실채기, 천 이송을 연결합니다. 단계마다 다른 완성 그림으로 바꾸면 안 됩니다.

영사기 — 세 번의 실험이 각각 다른 실패를 보여줘야 한다

정상은 정지된 프레임이 차례로 투사되고, 차광셔터 제거는 필름 이동 중에도 빛이 통과해 번짐이 생기며, 간헐이송 해제는 필름이 투사 구간에서도 계속 움직여 안정된 정지 프레임이 사라집니다. 셔터를 단순한 켜기/끄기 도형으로 대신해서는 안 됩니다.

시계 — 같은 축과 기어가 처음부터 끝까지 살아 있어야 한다

조립된 시계의 기어와 연구용 분해 모델이 별개라면, 아름답게 표현해도 학습 효과가 반감됩니다. 사용자가 감은 태엽이 동일한 배럴에서 윤열과 탈진기로 전달되어야 합니다.

에스프레소 — 추출의 결과보다 추출 과정이 먼저다

화면의 잔이 가득 차는데 물은 아직 커피층에 도달하지 않았다면 체험의 인과성이 무너집니다. 물 입자 장식 대신 연속된 유량·압력 상태로 경로와 컵의 부피를 계산해야 합니다.

3. 공통 UI는 최소화하고, 체험 방식은 다르게

8편의 공통 요소는 화면을 조작하기 위한 회전·확대·리셋·상태 보존 정도면 충분합니다. 나머지는 기계의 성격에 따라 달라져야 합니다.

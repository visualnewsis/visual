# 편집# 018 훈맹정음 100년 제작본

## 2026-11-02 본문 보강과 필수 체험 추가

사용자의 최신 지시에 따라 역사·구조만 있던 본문을 교육·학습 자료 지원·점역과 교정·악보·음성 병용·전자 점자·사용 환경으로 확장했다. 읽은 자료, 추가 취재 대상, 원문 미확인 범위는 [research.json](editorial/research.json)에 구분했다. 기존의 체험 배제 기획은 사용자가 이번에 변경했으며 프로젝트 정책을 수정한 것은 아니다.

체험은 ‘당신의 진심을 보다 많은 이에게 전해보세요’ → 100자 입력 → ‘점자로 옮기기’ → 원문과 점자 병렬 표시다. 퀴즈·점수·정답·시간 제한이 없다. 입력은 저장·전송하지 않고 브라우저에서 처리한다. 이모지·한자·단독 자모 등 검토 범위를 벗어난 입력은 조용히 누락하지 않고 지원 범위를 안내한다. 자동 점역은 전문 교정을 대신하지 않는다.

정적 WebAssembly 자산인 Braillify 2.2.0을 Apache 2.0 라이선스·NOTICE와 함께 포함했다. 별도 서버·프레임워크·빌드 시스템은 추가하지 않았다. 최초 점역 때만 약 6MB 엔진을 불러오므로 실제 모바일 데이터 환경에서 로딩을 추가 확인해야 한다. 해당 고정 버전의 공개 규정 예제 752건이 일치했다. [검증 기록](editorial/braille-verification.json)은 자체 예제 대조이며 독립 전문 검수와 구분한다.

기본 히어로는 ‘그런 점이 좋았다’를 실제 점자로 표시한다. 한글 풀이는 처음에 노출하지 않고 기사 마지막의 선택형 펼침 안에 둔다. 의미상 h1과 메타데이터의 현재 가제는 ‘점점, 문장이 손에 잡혔다 [훈맹정음 100년]’이며 최종 확정은 아니다.

공용 랜딩·헤더·더보기·배포 자동화는 변경하지 않았다. 임시 HTTPS 미리보기는 사용자가 Cloudflare 연결을 승인한 범위에서만 제공하며, 저장소·편집 자료·제작 도구는 미리보기 서버에서 차단한다.

2026년 11월 2일 사용자의 실제 제작 지시에 따라 만든 로컬 검토본이다. 최신 `origin/main`의 `ea91a0c8c9212afa5b83c6a17cb4c2bc7d2b4e87`에서 분리한 `codex/braille-100-018` 작업 사본에서 제작했다. 작업 폴더는 `braille-100/`이며 최종 서비스 주소 확정과 공개 배포는 별도다.

## 선택형 점자 스낵

사용자 최신 지시에 따라 본편의 여섯 점 설명 뒤에 ‘안녕하세요’·‘감사합니다’ 선택형 인사 체험을 다시 배치했다. 두 인사는 현재 고정 엔진에서 모두 8칸으로 출력된다. 본편에서는 단순 전환만 제공한다. 자세한 점자 탐색은 `learn.html` 부속 페이지에 두며 마지막 자기 문장 체험도 유지한다. 엔딩 뒤·자료와 제작 앞에 작은 새 탭 링크만 둔다. 펼치기나 중간 유도 링크는 없다.

스낵은 4점을 고정하고 1점만 켜고 꺼 초성 ㄱ(4점)↔ㄴ(1·4점)을 비교한다. 첫소리 예시임을 항상 표시하며 받침과 자음 순서의 일반 규칙으로 설명하지 않는다. 두 인사와 점자 칸 선택·확대를 제공하고 정답·점수·완료 조건은 없다. 전문 점역 감수와 실제 휴대폰 검증은 별도다. 공용 헤더·더보기·브랜드 배너는 기존 자산을 사용한다.

## 사진 근거와 원본 보존

제공 원본의 JPEG 내부 XMP `dc:description`을 추출한 기록은 [photo-evidence.json](editorial/photo-evidence.json)에 있다. 관찰 메모를 공식 캡션으로 바꾸지 않았다. 일부 `dc:creator` 필드에는 기자명 역순이나 영문 식별자가 있어, 캡션 본문에 명시된 기자명을 크레디트로 사용했다.

4번은 [뉴시스 사진 기사](https://mobile.newsis.com/view/NISI20261006_0021477826), 11번은 [뉴시스 사진 기사 전재](https://v.daum.net/v/fgKAARSg5h), 12·15번은 [뉴시스Pic](https://mobile.newsis.com/view/NISX20251103_0003388141)의 캡션과 대조했다. 원본 15장은 자료 브랜치와 기존 인수인계 사본에 그대로 남아 있다. `images/`에는 채택한 네 장의 720·1280·1920px 파생본만 두며, 크롭·합성·색상 연출 없이 원비율 리사이즈와 JPEG 압축만 적용했다.

원본 경로를 넘겨 파생본을 다시 생성할 수 있다.

```powershell
./braille-100/tools/prepare-assets.ps1 -AssetRoot '<인수인계 braille-100 폴더>'
```

## 로컬 실행과 검증

저장소 루트에서 실행한다. 별도 패키지 설치나 빌드가 필요하지 않다.

```powershell
node braille-100/tools/preview-server.mjs
node braille-100/tools/verify.mjs
```

미리보기: `http://127.0.0.1:8418/braille-100/`

`?nojs`는 로컬 검증 서버가 CSP로 스크립트를 차단하는 검사 모드다. 실제 HTML은 같으며 본문·사진·도해·출처와 헤더 대체 링크를 확인할 수 있다. 이 서버는 제작 도구이며 배포 뒤 실행할 서버가 아니다.

정적 검사는 JS·JSON-LD 파싱, 중복 ID와 내부 앵커, 자산 경로, 공용 더보기의 17개 이미지, 색 대비와 출처 기록을 확인한다. 브라우저에서는 320·390·430px과 기본 데스크톱 viewport, 원비율 사진 로드, 메뉴 열기·Escape·포커스 복귀, 더보기 이동과 마지막 브랜드 배너 바로 위 배치, 주소 복사를 확인했다. 실제 iPhone Safari·Android Chrome과 화면 읽기 프로그램으로 직접 검증한 것은 아니다.

## 공용 영역과 배포

공용 헤더·더보기·브랜드 배너 asset을 그대로 연결했다. 랜딩, 공용 데이터, 정책 문서, 배포 workflow는 수정하지 않았다. 원래 작업 사본의 미커밋 변경도 건드리지 않았다.

현재 `noindex,nofollow`이며 canonical·발행일을 만들어 넣지 않았다. OG·Twitter 이미지 경로는 로컬 검토용 상대경로다. 공개 전 최종 제목·서비스 주소·절대 공유 이미지 URL·발행일을 확정하고 인덱싱 설정을 전환해야 한다. 기존 Analytics ID는 실서비스 호스트에서만 한 번 초기화해 로컬 검토 기록을 보내지 않는다.

공용 `visual-header.js`의 실제 메뉴는 현재 9개로 AGENTS.md의 4개 항목 규칙과 다르다. 이번 콘텐츠가 공용 메뉴를 임의 수정하지 않았으며, 공용 정책과 구현의 조정은 별도 관리 사항이다.

## 삼단 검토 상태

앞선 기획 검토와 이번 제작 전 GPT의 캡션·설계 검토를 반영했다. 실제 화면 다섯 장의 GPT 업로드는 자동 승인 심사에서 거절됐다. 원본 사진 15장에 대한 승인과 별도로 미공개 화면·코드 전송 동의를 요청한 상태다. 최종 구현 화면에 대한 GPT·Claude 검토가 완료됐다고 보고하지 않는다. 전문 점역 검수와 당사자 감수 역시 대체하지 않는다.

# DMZ 인계 메모 (2026-10-05 밤)

DMZ(/dmz/) 작업을 이어서 진행할 때 시작 전에 반드시 최신 상태부터 가져온다.

## 1. 작업 시작 절차

- 저장소 상태·브랜치·미커밋 변경 확인 후 `git fetch origin` → 최신 origin/main 반영
- 최신 AGENTS.md 읽고 규칙 적용 (커밋은 dmz 파일만, push 직전 원격 재확인, force push·reset --hard 금지)
- 기준 커밋: e397ce96 (main, dmz-launch-20261006 브랜치 동일)
- 공개 주소: https://visual.newsis.com/dmz/ (main.js?v=20261005-8 로드되면 최신)

## 2. 지금까지 반영된 것

- 오프닝·클로징: GPU 변형 보간(image-morph.js) 미사용. CSS 이미지 레이어 교차 방식.
  image-morph.js는 랜드마크 좌표 데이터(export landmarks)만 hero.js가 가져다 씀. 변형 코드는 다시 켜지 말 것.
- 그림별 고정 정렬(hero.js computeAlign): 사진 묶음(0~2)은 첫 사진에, 조감 묶음(3~6)은 MAP에 맞춤.
  묶음 안 확대율 통일(교차 시 크기 변화 방지). 첫·마지막 사진 구도가 약 6% 확대됨.
- MAP 직전 그림 hero-between-map은 순서에서 제외(파일은 남김).
- MAP 정지 화면은 HERO 카메라 거리 그대로 캡처(이전 1.12배 당김 제거).
  조감 → MAP → 3D 같은 크기. 정렬 보정(entry)은 HERO→descend, end4km→rise 카메라 이동 중에 풀림 (main.js entryK).
- 오프닝 길이 500vh(OPEN 진행도 배분), 클로징 560vh 그대로. 중간 구간 길이·카메라 진행도는 변경 없음.
- 모바일 지뢰 폭발: incident 구간에서 세로 화면 oy(13% 올림) 해제 → 먼지 중심 화면 위 약 41% 위치.
- 나무: 잎 카드를 카메라 정면 빌보드로 변경(vegetation.js card(), leafMat 셰이더 corner 속성).
  칼날·줄무늬·판 제거. 잎 수·텍스처 해상도 동일. 경사면 줄기 sink 처리.

## 3. 남은 문제 (사용자 확인 필요)

- 실제 휴대폰(iPhone Safari·Android Chrome) 검증 안 됨. 스크롤 중 연속 움직임도 직접 확인 필요.
- 조감 그림 → MAP 교차 순간 강 위치가 약간 겹쳐 보임.
- 폭발 위치가 정중앙(50%)보다 약간 위.
- 모바일 "너무 빠르다": 오프닝 외 중간 탐사·폭발·클로징 구간은 아직 미조정. 빠른 구간만 개별 조정할 것(전체 일괄 변경 금지).

## 4. 수정 시 주의

- 수정 후 캐시 버전 갱신: index.html의 main.js?v=, main.js 안 import ?v= (현재 hero/main 20261005-8, vegetation/scene3d/xray 20261005-6)
- JS 문법 검사는 `node --input-type=module --check < 파일` 로 (일반 `node --check`는 이 환경에서 오류를 못 잡은 적 있음)
- 배포는 main push 시 자동. 배포 후 공개 페이지가 새 ?v= 를 불러오는지, 실제 화면에 반영됐는지 확인 후 보고
- 사용자 확인 전 재배포 여부는 그때그때 사용자에게 확인

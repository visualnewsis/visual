## 선택형 점자 스낵

사용자 최신 지시에 따라 본편의 여섯 점 설명 뒤에 ‘안녕하세요’·‘감사합니다’ 선택형 인사 체험을 다시 배치했다. 두 인사는 현재 고정 엔진에서 모두 8칸으로 출력된다. 본편에서는 단순 전환만 제공한다. 자세한 점자 탐색은 `learn.html` 부속 페이지에 두며 마지막 자기 문장 체험도 유지한다. 엔딩 뒤·자료와 제작 앞에 작은 새 탭 링크만 둔다. 펼치기나 중간 유도 링크는 없다.

스낵은 4점을 고정하고 1점만 켜고 꺼 초성 ㄱ(4점)↔ㄴ(1·4점)을 비교한다. 첫소리 예시임을 항상 표시하며 받침과 자음 순서의 일반 규칙으로 설명하지 않는다. 두 인사와 점자 칸 선택·확대를 제공하고 정답·점수·완료 조건은 없다. 전문 점역 감수와 실제 휴대폰 검증은 별도다. 공용 헤더·더보기·브랜드 배너는 기존 자산을 사용한다.

`?nojs`는 로컬 검증 서버가 CSP로 스크립트를 차단하는 검사 모드다. 실제 HTML은 같으며 본문·사진·도해·출처와 헤더 대체 링크를 확인할 수 있다. 이 서버는 제작 도구이며 배포 뒤 실행할 서버가 아니다.

## 공용 영역과 배포

공용 헤더·더보기·브랜드 배너 asset을 그대로 연결했다. 랜딩, 공용 데이터, 정책 문서, 배포 workflow는 수정하지 않았다. 원래 작업 사본의 미커밋 변경도 건드리지 않았다.

현재 `noindex,nofollow`이며 canonical·발행일을 만들어 넣지 않았다. OG·Twitter 이미지 경로는 로컬 검토용 상대경로다. 공개 전 최종 제목·서비스 주소·절대 공유 이미지 URL·발행일을 확정하고 인덱싱 설정을 전환해야 한다. 기존 Analytics ID는 실서비스 호스트에서만 한 번 초기화해 로컬 검토 기록을 보내지 않는다.

공용 `visual-header.js`의 실제 메뉴는 현재 9개로 AGENTS.md의 4개 항목 규칙과 다르다. 이번 콘텐츠가 공용 메뉴를 임의 수정하지 않았으며, 공용 정책과 구현의 조정은 별도 관리 사항이다.

## 4차 교열·디자인 검수

실제 GPT 대화에 수정 전후 PC·모바일 화면을 전달해 디자인을 의뢰했고, Claude에는 기사 원문과 수정 HTML·CSS·점역 UI 코드, 모바일 화면을 전달했다. 추상적 반복 해설만 줄이고 교과서 공급 시점·점역과 교정·악보·전자 점자·기념일 주제·조사 모집단은 유지했다. 사용자 지정 작은따옴표 소제목과 크레디트를 보존했다.

PC를 주 지면으로 히어로 좌우 조판, 역사 중앙 단일 열, 문서 비대칭 조판, 넓은 책 사진, 전체 폭 연표를 적용했다. 자기 문장 체험의 순서는 유지하고, 인사 체험 뒤 한 차례 예고와 06→07 연결 문장을 남겼다. 딥그린 색면은 자기 문장 구간 한 곳에 집중했다.

모바일 문장 사이 공백, 동적 점역 모듈 로딩, 잘못된 직접 인용 형태를 수정했다. 점역 모듈은 최초 제출할 때 불러오므로 엔진 로딩 실패가 인사 선택을 막지 않는다. Unicode 점자를 보존했다. 공식 브리핑으로 확인한 간접 서술은 직접 발언 따옴표를 쓰지 않는다.

검수·측정 기록은 `editorial/polish-review.json`, `editorial/polish-validation.json`에 있다. GPT 시각 검토는 확인한 화면에 한정하며, Claude 4차는 직전 실제 파일 검수와 전달한 수정 내역 대조를 구분한다. 독립 점역 전문가·점자 사용자 감수와 실기기·보조기기 확인, 최종 주소·OG 절대 URL·발행 날짜·색인 설정은 정식 출고 전에 남아 있다. 공용 파일·배포는 변경하지 않았다.

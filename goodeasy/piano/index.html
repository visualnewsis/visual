    02 — 소리 비교 실험

    무엇을 바꾸면
    소리가 달라질까요?

    기준 음은 C4입니다. 위에서 연주하면 마지막으로 누른 음으로 바뀝니다.

    비교한 실험 0 / 4

    실험 01 · 타격 세기

    세게 치면,
    소리만 커질까요?

    같은 음을 약하게, 강하게 쳤을 때를 비교합니다. 두 버튼을 차례로 눌러보세요.

    음량과 음색이 어떻게 다른지 들어보세요.

    버튼을 누르면 소리가 납니다.

    비교 결과 01

    강하게 치면 음량과 음색이 달라집니다.

    피아노는 타격 세기에 따라 음량과 배음의 비중이 달라집니다. 여기서는 강한 타격의 소리를 더 크게 만들고 높은 배음을 강조했습니다. 실제 피아노를 녹음한 소리는 아닙니다.

    그래프는 소리 차이를 보여주는 개념도입니다. 녹음 파형이 아닙니다.
    실험 02 · 해머 이탈

    해머가 현에
    붙어 있으면 어떨까요?

    해머가 현을 치고 떨어질 때와 계속 닿아 있을 때, 울림이 얼마나 남는지 비교합니다.

    두 버튼을 눌러 소리가 멎는 시간을 비교하세요.

    버튼을 눌러 울림을 비교하세요.

    비교 결과 02

    해머가 떨어져야 현이 계속 진동합니다.

    해머가 계속 닿아 있으면 현의 진동이 줄어듭니다. 잭이 타격 직전에 이탈하기 때문에 건반을 누르고 있어도 해머는 현을 친 뒤 떨어질 수 있습니다. 이 실험은 소리가 줄어드는 시간을 바꿔 차이를 표현했습니다. 실제 접촉력을 계산하지는 않습니다.

    액션 원리 자료 · Yamaha ↗
    실험 03 · 현의 조건

    건반 뒤의 현은
    왜 길이가 다를까요?

    현의 길이, 장력, 단위 길이당 질량을 바꿔 음높이를 비교합니다. 한 번에 한 조건씩 바꿔보세요.

    다른 조건을 유지하고 길이를 두 배로 늘려보세요.

    기준과 같은 음높이

    비교 결과 03

    현이 길어지면 음은 낮아집니다.

    다른 조건이 같으면 현의 길이가 두 배일 때 진동수는 절반이 됩니다. 장력을 높이면 음은 높아지고, 단위 길이당 질량을 늘리면 낮아집니다. 실제 피아노는 현의 길이와 굵기, 감은 선 등을 조합해 음높이를 맞춥니다.

    계산의 기준과 한계

    양 끝을 고정한 이상적인 현의 식으로 계산합니다. 진동수 = 기준 진동수 × √(장력 비율 ÷ 단위 길이당 질량 비율) ÷ 길이 비율. 현의 강성, 브리지, 공명에 따른 변화는 포함하지 않습니다. 그래프는 실제 진동을 측정한 파형이 아닙니다.

    현의 진동 관계 · OpenStax ↗ · 피아노 현 설계 · Yamaha ↗
    실험 04 · 반복 타건

    같은 음을 빠르게,
    어떻게 또 칠까요?

    그랜드피아노는 건반을 끝까지 놓지 않고도 같은 음을 다시 칠 수 있습니다. 반복 기구가 있는 모형과 없는 모형을 골라 비교하세요.

    비교할 기구

    건반을 놓는 정도를 먼저 골라보세요.

    비교 결과 04

    건반을 조금만 놓아도 다시 칠 수 있습니다.

    반복 기구는 해머가 원위치로 완전히 돌아오기 전에 다음 타격을 준비합니다. 이 모형에서는 건반을 놓은 정도에 따라 다시 소리가 나는지만 비교합니다. 실제 복귀 거리나 스프링, 잭의 접촉 운동은 재현하지 않았습니다.

    01 / 조사와 선택

    첫 화면에서 바로 연주하게 하기

    안재현 디렉터는 설명보다 연주를 먼저 배치하도록 정했습니다. Yamaha 자료로 건반·해머·현·댐퍼의 작동 순서를 확인했습니다. 건반은 HTML로 만들고 소리는 브라우저에서 합성해, 3D 모형을 불러오는 동안에도 연주할 수 있게 했습니다.

    02 / 연주와 관찰 연결

    마지막으로 누른 건반을 다시 보여주기

    건반을 누르면 음 번호, 누른 시간, 페달 상태를 저장합니다. 관찰 화면은 이 기록으로 기구를 움직이고 해머가 현을 치는 순간 같은 음을 냅니다. 기록은 페이지를 새로고침하면 지워집니다.

    03 / 모델링과 오디오

    3D 모형과 합성음 만들기

    Three.js로 부품의 형태와 회전축을 만들고 목재·펠트·금속 표면을 표현했습니다. 실측 도면을 옮긴 모형은 아닙니다. 소리는 Web Audio로 여러 배음을 합성했습니다. 건반을 누른 뒤 점차 줄어들고 손을 떼면 더 빨리 멎습니다. 키보드와 터치 입력으로는 실제 타건 세기를 측정하지 않으므로 첫 화면의 타격 세기는 일정합니다.

    04 / AI 작업과 수정

    첫 모형을 보고 다시 고친 것

    안재현 디렉터가 화면 구성과 수정 방향을 정하고, Codex가 입력·오디오·3D 코드를 작성했습니다. 첫 모형은 막대와 상자로 구성해 해머의 모양과 부품의 연결을 알아보기 어려웠습니다. 해머에 곡면을 넣고 회전축과 재질을 구분했습니다. 아래 이미지는 첫 모형과 수정한 화면입니다.

    05 / 현재 구현 범위

    되는 것과 아직 안 되는 것

    연주
    키보드·마우스·터치 입력으로 합성음을 냅니다. 실제 피아노 녹음과 타건 세기 측정은 지원하지 않습니다.
    관찰
    건반·해머·현·댐퍼의 작동 순서를 보여줍니다. 실제 부품의 치수와 접촉력은 계산하지 않습니다.
    소리 비교
    타격 세기, 해머 이탈, 현의 조건, 반복 타건을 비교합니다. 각각 단순화한 모형이며 실제 악기의 측정값은 아닙니다.
    아직 남은 일
    실측 자료를 바탕으로 기구 동작을 보정하고 녹음 음원과 공명을 검토해야 합니다. 실제 휴대전화에서 음질과 입력 지연도 확인해야 합니다.

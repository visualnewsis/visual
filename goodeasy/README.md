# GOODEASY · 아홉 편 개발

크리에이티브 디렉터 = 안재현. 정책은 저장소 AGENTS.md.

현재 순서: 피아노 / 기타 / 낚시 릴 / 카메라 / 기계식 시계 / 바이올린 / 필름 영사기 / 기계식 컴퓨터 키보드 / 에스프레소 머신.

- review/index.html은 개발 현황판이며 정식 랜딩이 아니다. 기존 승인 랜딩 시안은 이후 별도 구현한다.
- piano/는 기존 시제품의 완전한 정적 복사. shutter/piano와 기존 카메라는 보존했다.
- 나머지 여덟 편은 입력과 스냅샷 검증본. 3D, 정밀 기구 운동, 완성 디자인, 영어판은 아직 없다. noindex 유지.
- design/v1은 실제 ChatGPT에 의뢰하고 다운로드한 원본 18개 SVG/18개 PNG/명세. 실행 코드는 원본으로만 보관하고 서비스에서 로드하지 않는다. 낮은 시각 완성도를 반려하고 고품질 시안 재의뢰했다.
- 물리 수치는 가정이며 제조사 실측이나 물리 해석 결과가 아니다.
- 키보드 텍스트는 페이지 메모리만 사용하고 전송·로컬 저장하지 않는다. GA 이벤트에 입력 내용을 넣지 않는다.
- 정식 발행 전 각 편 대표 이미지·영어판·hreflang·공식 발행 목록·더보기 반영은 별도 작업. 현재 피아노 대표 이미지는 개발용 공통 임시 이미지임.

## 검증
- node goodeasy/tests/model.test.mjs: 여섯 편 상태 계산과 경계값.
- Python goodeasy/check.py 저장소경로: 8개 경로의 자산/링크/앵커/중복 ID/JSON-LD/GA/noindex.
- Chromium: 여섯 편 버튼 입력·릴 저항 0에서 슬립·카메라 촬영 기록·태엽 작동·프레임 이동·키 접점·포터필터 장착 조건과 추출량 확인. 릴 관찰 기록을 새 조작 후에도 보존.
- 390px viewport 여섯 편 넘침 없음·오류 로그 없음. 실제 iPhone/Android 기기 검증은 미완료.

## 편성 변경 · 사용자 ChatGPT 지시 반영
피아노 → 기타 → 낚시 릴 → 카메라 → 기계식 손목시계 → 바이올린 → 필름 영사기 → 기계식 키보드 → 에스프레소 머신. URL은 기존 slug를 유지하고 guitar/violin 추가. design/v1 원본의 번호는 과거 번호이며 변경하지 않았다. 사용자가 이 채팅에서 ChatGPT의 요청을 읽고 이어서 작업하도록 명시적으로 승인했다.

기타·바이올린 추가 검증: 기타 E2=82.4Hz와 E4 입력·직전 기록 보존, 바이올린 A4=440Hz Space 키 유지/뗌과 실제 수평 드래그 후 발음 중단·기록 전달 확인. 320px viewport 두 악기 넘침 없음, 브라우저 오류 없음. 실제 기기 음질은 미검증.

## 기타·바이올린 추가
사용자가 연결된 ChatGPT의 최신 지시를 읽고 반영하도록 이 채팅에서 승인했다. 원본 대화에서 기타를 02, 바이올린을 손목시계 다음 06으로 둔 9편 편성을 확인했다. 기타·바이올린 각각 PC/모바일/부품/조작계/명세를 추가 의뢰해 생성 보드 guitar-violin-v3.png를 다운로드했다. 이미지 생성으로 문서 ZIP이 빠져 별도 도구 제작을 다시 요청했다. 이미지의 잘못된 기타 줄 번호는 코드에 쓰지 않고 개방현 E2 A2 D3 G3 B3 E4를 적용했다.

기타·바이올린 구현 인계 ZIP GOODEASY_guitar_violin_handoff_v1.zip을 회수해 music-handoff-v1에 원본 보관했다. SVG 6개, 부품·좌표·입력·접근성 명세와 7→9편 CSV를 확인했다. 기타 줄을 가로지르는 드래그 입력과 바이올린 80ms 무이동 감지, 이동 샘플 기록을 코드에 반영했다. 생성된 참고 JavaScript는 실행하지 않고 자체 코드와 대조했다.

## 2026-10-24 사물별 작동 연구 보강
- 사용자가 Ciechanowski Mechanical Watch와 모바일 캡처를 제시하고, 현재 외형을 유지하며 분해·재조립과 체계적인 작동 실험을 전 편에 요구했다. 이후 키보드 MX 구조·바이올린·에스프레소의 품질 재작업을 명시했다.
- 레퍼런스의 공개 문서 및 실제 3D 회전·분해 슬라이더를 확인했다. 원문·코드·모델은 복제하지 않았다. 사실은 FHH, Epson, Yamaha, Canon, SHIMANO, CHERRY, National Science and Media Museum, La Marzocco 공개 자료와 대조하고 각 편에 링크했다.
- 기존 ChatGPT 대화에서 수동시계 조립·5실험 명세를 의뢰해 UI 본문을 검토했다. Markdown 원본 다운로드는 확인되지 않았으므로 다운로드 납품으로 표시하지 않는다.
- MX/Espresso 모델을 재의뢰해 v1과 v2 ZIP을 실제 회수했다. original은 mx-espresso-v1, mx-espresso-v2에 보존한다. 코드 검토에서 떠 있는 외벽, 막힌 바스켓, 잘못된 피벗, 접점 불일치, 스프링 기준점·스템 관통을 지적해 재수정했다.
- 런타임 사본에서는 Codex가 접점·스프링·캠 좌표, 상부 하우징 경사, 키캡 소켓, 필터·레버 동작을 보정했다. 머신 외장과 노출 그룹헤드·배출 경로를 다시 구성했다. 특정 브랜드 CAD와 동일하다고 주장하지 않는다.
- 바이올린 상판은 실제 f홀 개구부 및 UV를 추가하고 턱받침·내부 어두운 공간을 구성했다. 원본 v4는 보존했다.
- Codex가 별도로 작성한 research-math, research-watch, research-other, research 렌더러와 각 편의 정적 본문으로 총28개 실험을 연결했다. 한 WebGL 렌더러가 화면에 보이는 실험만 그리며 2D 캔버스로 복사한다. 정지·감속·시점 조작·숨김 상태와 원본 관찰 기록을 구분한다.
- 현재의 기어 이 수·중심거리·탈진기 잠김·바늘비·상대 노출·현 진동수·MX 바닥·스프링 기준점·컵20mL 상태를 수치 검사했다. 실제 시계 제작용 치형·유체/열/탄성/마찰 해석은 아니다. 각 실험의 한계를 본문에 명시했다.
- 실제 iPhone Safari/Android Chrome 기기 검증은 미수행. Chromium viewport와 실제 기기 검증을 구분한다.

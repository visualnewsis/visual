          <div class="structure-copy"><span class="section-label">02 · 여섯 자리의 짜임</span><h2 id="structure-title">점의 자리가<br>말의 자리가 된다</h2><div class="prose"><p>점자는 점의 개수와 위치를 구별해 읽는다. 한글과 마찬가지로 표기 규칙이 있다.</p><p>여섯 점식 점자 한 칸에는 <strong>세로 세 자리, 가로 두 자리</strong>의 점 위치가 있다. 점의 개수와 위치를 조합해 글자와 기호를 나타낸다.<a class="source-mark" href="#source-structure" aria-label="점자 구조 출처 2">[2]</a></p></div></div>

      <section class="chapter learning wrap" id="learning" aria-labelledby="learning-title">
        <div class="section-heading"><span class="section-label">03 · 손끝으로 배우는 글</span><h2 id="learning-title">글자를 ‘안다’는 것과<br>‘읽는다’는 것 사이</h2></div>
        <div class="prose learning-prose"><p>점의 배열을 외운 뒤에는 손끝으로 점을 구별하고 문장을 따라가는 연습이 필요하다. 중도 시각장애인에게는 익숙한 우리말을 손끝으로 읽는 법을 배우는 과정이기도 하다.</p><p>하상장애인복지관은 중도 시각장애인과 통합교육 시각장애 학생을 위한 한글 점자 읽기 교육을 운영한다. 학교에서 필요한 그래프와 도형, 시험 문제를 점자로 제작하고, 수능 모의고사는 점자형과 음성형으로 지원한다. <a class="source-mark" href="#source-learning" aria-label="점자 교육과 학습 지원 출처">[4]</a></p><p>수식과 외국어를 적는 점자도 배운다. 국립국어원의 온라인 강좌에는 수학·과학·통일영어점자가 있다. 하상복지관의 ‘점자세상’에는 중도 실명자를 위한 한글 점자 과정과 점역 실무 교육이 마련돼 있다. 외국어를 공부하고, 수식을 풀고, 시험을 준비하는 일에도 각 분야의 점자 규칙이 쓰인다.<a class="source-mark" href="#source-courses" aria-label="온라인 점자 학습 출처">[5]</a></p><p>읽을 책은 제때 도착해야 한다. 뉴시스는 2026년 10월 20일, 시각장애인용 교과서를 학기 시작 전에 제작·보급할 수 있도록 디지털 파일의 형식과 제출 절차를 명확히 하는 ‘교과용 도서에 관한 규정’ 개정안이 국무회의에서 의결됐다고 보도했다. <a href="https://mobile.newsis.com/view_amp.html?ar_id=NISX20261020_0003832732" target="_blank" rel="noopener">관련 보도 · 뉴시스 <span aria-hidden="true">↗</span><span class="sr-only"> (새 탭)</span></a></p></div>
      </section>

      <section class="chapter document wrap" id="document" aria-labelledby="document-title">
        <div class="document-copy"><span class="section-label">04 · 생활의 문서</span><h2 id="document-title">말을 전하기 위해,<br>먼저 살피는 손</h2><div class="prose"><p>투표 절차를 설명하는 안내문에도 점자가 쓰인다. 잘못 옮긴 글이나 빠진 내용은 없는지 확인하는 일도 필요하다.</p><p>일반 문자로 적힌 글을 점자로 옮기는 일을 ‘점역’이라고 한다. 잘못된 표기를 찾아 바로잡는 ‘교정’도 거친다. 점역·교정사 자격 검정에는 일반 문자를 점자로 옮기는 실기와, 잘못 표기된 점자를 바로잡는 실기가 포함된다. <a class="source-mark" href="#source-transcription" aria-label="점역과 교정 출처">[6]</a></p><p class="document-pause">누군가 읽을 문장을,<br>먼저 살피는 손이 있다.</p></div></div>
        <figure class="document-photo"><img src="images/document-1280.jpg" srcset="images/document-720.jpg 720w, images/document-1280.jpg 1280w, images/document-1920.jpg 1920w" sizes="(min-width:900px) 560px, (min-width:700px) 65vw, 100vw" width="1280" height="1371" loading="lazy" decoding="async" alt="‘시각장애선거인을 위한 투표안내문’ 표지의 점자 위를 손가락으로 짚고 있다."><figcaption><span>2025년 5월 19일, 과천 중앙선관위 선거종합상황실에서 직원이 투표안내문의 점자를 확인하고 있다.<a class="source-mark" href="#source-document" aria-label="투표안내문 사진 출처 3">[3]</a></span><span class="photo-credit">조수정 기자</span></figcaption></figure>

      <section class="chapter book" id="book" aria-labelledby="book-title">
        <div class="book-heading wrap"><span class="section-label">05 · 펼쳐진 책</span><h2 id="book-title">책을 읽고,<br>악보를 펼치고</h2><p>점자는 교과서와 투표안내문을 넘어<br>문학 작품과 악보, 전자 문서로도 쓰인다.</p></div>
        <figure class="book-photo wrap"><img src="images/book-1920.jpg" srcset="images/book-720.jpg 720w, images/book-1280.jpg 1280w, images/book-1920.jpg 1920w" sizes="(min-width:1280px) 1200px, (min-width:700px) calc(100vw - 80px), 100vw" width="1920" height="1215" loading="lazy" decoding="async" alt="펼쳐진 점자책의 두 페이지와 그 위에 놓인 두 손."><figcaption><span>2025년 11월 3일, 인천 송암점자도서관에서 한 시각장애인이 점자책을 읽고 있다.</span><span class="photo-credit">전진환 기자</span></figcaption></figure>
        <div class="prose book-prose"><p>점자는 소설이나 안내문을 옮기는 데에만 쓰이지 않는다. 악보도 점자로 적는다. 실로암시각장애인음악재활센터에서는 음악 점역사가 악보를 해석해 점역하고, 시각장애인 음악 교정사가 규정에 맞게 교정한다. <a class="source-mark" href="#source-music" aria-label="점자 악보 제작 출처">[7]</a></p><p>영국 왕립시각장애인협회(RNIB)가 2024년 공개한 조사에서, 점자를 아는 성인 참여자들은 종이 점자와 음성, 점자 디스플레이를 함께 활용했다. 약 포장의 표시를 확인하거나 책·문서를 읽을 때도 점자를 썼다.<a class="source-mark" href="#source-rnib" aria-label="영국 RNIB 점자 사용 조사 출처">[8]</a></p><p>전자 점자 단말기에서는 작은 핀이 오르내리며 글을 표시한다. 미국 의회도서관의 국립시각장애인·독서장애인도서관서비스(NLS)는 이용 자격을 갖춘 회원에게 전자 점자 단말기를 무료로 대여한다. 단말기를 스마트폰이나 컴퓨터에 연결하면 전자 문서도 점자로 읽을 수 있다.<a class="source-mark" href="#source-digital" aria-label="전자 점자 단말기 출처">[9]</a></p></div>
      </section>

      <section class="chapter access wrap" id="access" aria-labelledby="access-title">
        <div class="section-heading"><span class="section-label">06 · 100년 뒤의 질문</span><h2 id="access-title">‘점자가 있다는 것’과<br>‘읽을 수 있다는 것’ 사이</h2></div>
        <div class="annual-messages"><h3>기념일마다 이어온 말</h3><p class="annual-intro">최근 네 차례의 한글 점자의 날 기념식 주제에는 일상과 희망, 편리한 삶과 마음이 담겼다. 문화체육관광부와 한국시각장애인연합회가 함께 마련한 행사다.</p><ol>
          <li><time>2022</time><div><h4>한글 점자, 일상 속 새로운 시작</h4><p>재활·자립, 교과서와 도서 제작 지침, 온라인 점자 교육에 기여한 이들이 포상을 받았다. <a href="https://mobile.newsis.com/view/NISX20221103_0002072019" target="_blank" rel="noopener">뉴시스 보도 <span aria-hidden="true">↗</span><span class="sr-only"> (새 탭)</span></a></p></div></li>
          <li><time>2023</time><div><h4>점자로 여는 희망, 새로운 도전</h4><p>중도 시각장애인이 점자를 배워 꿈을 키우는 과정을 영상에 담았다. 책과 민원 안내 자료의 보급, 점자를 알리는 활동도 조명했다. <a href="https://www.mcst.go.kr/servlets/eduport/front/upload/UplDownloadFile?pFileName=%281103%29%EB%AC%B8%EC%B2%B4%EB%B6%80%EB%B3%B4%EB%8F%84%EC%9E%90%EB%A3%8C-%ED%95%9C%EA%B8%80_%EC%A0%90%EC%9E%90%EC%9D%98_%EB%82%A0_%EA%B8%B0%EB%85%90%EC%8B%9D_%EA%B0%9C%EC%B5%9C.pdf&amp;pPath=0302000000&amp;pRealName=20231103085043811994203850_PRESS20231103085043028387.pdf" target="_blank" rel="noopener">문체부 자료 <span aria-hidden="true">↗</span><span class="sr-only"> (새 탭)</span></a></p></div></li>
          <li><time>2024</time><div><h4>점자로 더 편리한 삶,<br>함께 만들어가는 세상</h4><p>기념식 참석자들은 점자·촉각 전시를 관람했다. 문체부는 정보에 접근하는 데서 나아가 차별 없이 문화를 향유하고 참여할 수 있어야 한다고 밝혔다. <a href="https://gonggam.korea.kr/newsContentView.es?b_list=9&amp;code_cd=0110000000&amp;content=NC002&amp;mid=a10214000000&amp;nPage=334&amp;news_id=fabbadca-2bac-41ac-a302-c61d496390be&amp;section_id=" target="_blank" rel="noopener">정부 정책주간지 <span aria-hidden="true">↗</span><span class="sr-only"> (새 탭)</span></a></p></div></li>
          <li><time>2025</time><div><h4>손끝으로 이어온 문자,<br>마음으로 만드는 세상</h4><p>생활용품에 점자를 표시한 기업, 중도 실명자를 위한 교육법을 개발한 이, 정확한 점자 자료를 보급한 이들이 포상 대상으로 선정됐다. <a href="https://mobile.newsis.com/view/NISX20251104_0003388790" target="_blank" rel="noopener">뉴시스 보도 <span aria-hidden="true">↗</span><span class="sr-only"> (새 탭)</span></a></p></div></li>
        </ol><p class="annual-outlook">해마다 주제는 달랐지만, 포상 대상에는 점자 교육과 정확한 자료 제작에 힘쓴 이들이 거듭 이름을 올렸다.</p><aside class="reported-message"><span class="section-label">2026 · 훈맹정음 100주년 특별전</span><p>김혜경 여사는 10월 7일 특별전을 관람한 뒤, 장애 유무와 관계없이 누구나 배우고 소통하며 문화와 일상을 함께 누리는 사회로 나아가기를 바란다는 뜻을 전했다고 청와대가 서면 브리핑에서 밝혔다.</p><div class="report-source"><a href="https://www.president.go.kr/briefings/75j0FMZH" target="_blank" rel="noopener">청와대 서면 브리핑 <span aria-hidden="true">↗</span><span class="sr-only"> (새 탭)</span></a> · <a href="https://www.newsis.com/view/NISI20261007_0021480076" target="_blank" rel="noopener">방문 현장 · 뉴시스 <span aria-hidden="true">↗</span><span class="sr-only"> (새 탭)</span></a></div></aside></div>
        <div class="prose access-prose"><p>점자를 배우고 쓸 여건은 충분할까. 국립국어원이 공개한 2025년 점자 인식 조사에서 <strong>20~69세 시각장애인 응답자 500명</strong> 가운데 점자를 사용할 수 있다고 답한 비율은 14.4%였다.</p><p>같은 조사에서 시각장애인 응답자 74%는 점자 발전을 위해 교원 양성과 교육 활성화가 시급하다고 답했다. <a class="source-mark" href="#source-survey" aria-label="2025년 점자 인식 조사 출처">[10]</a></p></div>
        <div class="access-facts"><div><strong>14.4<span>%</span></strong><p>점자를 사용할 수 있다는 응답</p></div><div><strong>74<span>%</span></strong><p>교원 양성·교육 활성화가 시급하다는 응답</p></div><p class="fact-scope">국립국어원 2025 국민의 점자 인식 조사 공개 안내 · 시각장애인 응답자 500명(20~69세) 기준. 두 수치는 서로 다른 질문의 응답이다.</p></div>
        <p class="access-close">누군가의 말이 전해지려면,<br>그 말을 읽을 자리가 필요하다.</p>
      </section>

function renderDots(text, target = dots) {
  const fragment = document.createDocumentFragment();
  let word;
  for (const char of text) {
    if (/\s/.test(char) || char === '\u2800') {
      const space = document.createElement('span');
      space.className = char === '\n' ? 'braille-break' : 'braille-space';
      fragment.append(space);
      word = undefined;
      continue;
    }
    if (!word) {
      word = document.createElement('span');
      word.className = 'braille-word';
      fragment.append(word);
    }
    const mask = char.codePointAt(0) - 0x2800;
    const cell = document.createElement('span');
    cell.className = 'braille-cell';
    for (const bit of [0,3,1,4,2,5,6,7]) {
      const dot = document.createElement('i');
      dot.className = mask & (1 << bit) ? 'raised' : '';
      // Standard literary Korean output is six-dot; support any eight-dot output faithfully.
      if (bit >= 6 && mask < 64) dot.hidden = true;
      cell.append(dot);
    }
    word.append(cell);
  }
  target.replaceChildren(fragment);
}

}

if (form) {
  form.hidden = false;
  document.getElementById('message-nojs').hidden = true;
  input.addEventListener('input', () => {
    revision++;
    if (!result.hidden) { result.hidden = true; status.textContent = '말을 고쳤습니다. 다시 점자로 옮겨보세요.'; }
  });
  form.addEventListener('submit', async event => {
    event.preventDefault();
    const text = input.value.normalize('NFC').trim();
    if (!text) { status.textContent = '전하고 싶은 말을 먼저 적어주세요.'; input.focus(); return; }
    if (Array.from(text).length > 100) { status.textContent = '한 번에 100자까지 옮길 수 있습니다.'; return; }
    // Limit unsupported input explicitly rather than silently dropping or inventing glyphs.
    if (/[^가-힣a-zA-Z0-9\s.,!?·:;'"()\-]/u.test(text)) {
      status.textContent = '완성된 한글, 영문, 숫자와 기본 문장부호로 적어주세요. 이모지·한자·단독 자모는 아직 지원하지 않습니다.';
      return;
    }
    const currentRevision = revision;
    submit.disabled = true;
    form.setAttribute('aria-busy', 'true');
    status.textContent = '당신이 쓴 말을 점자로 옮기고 있습니다.';
    try {
      const {loadBrailleEngine} = await import('./braille-engine.mjs');
      const translate = await loadBrailleEngine();
      if (revision !== currentRevision) { status.textContent = '말을 고쳤습니다. 다시 점자로 옮겨보세요.'; return; }
      const translated = translate(text);
      if (!translated || /[^\u2800-\u28ff\s]/u.test(translated)) throw new Error('지원하지 않는 표현');
      original.textContent = text;
      braille.textContent = translated;
      renderDots(translated);
      result.hidden = false;
      status.textContent = '점자로 옮겼습니다. 아래에서 확인해보세요.';
    } catch {
      result.hidden = true;
      status.textContent = '지금은 이 문장을 옮기지 못했습니다. 연결을 확인하거나 더 짧고 간단한 문장으로 다시 시도해주세요.';
    } finally {
      form.removeAttribute('aria-busy');
      submit.disabled = false;
    }
  });
}

import * as binding from './vendor/braillify/index_bg.js';

let ready;
export function loadBrailleEngine() {
  if (!ready) ready = (async () => {
    const response = await fetch(new URL('./vendor/braillify/index_bg.wasm', import.meta.url));
    if (!response.ok) throw new Error('점역 자료를 불러오지 못했습니다.');
    const {instance} = await WebAssembly.instantiate(await response.arrayBuffer(), {'./index_bg.js': binding});
    binding.__wbg_set_wasm(instance.exports);
    return binding.translateToUnicode;
  })().catch(error => { ready = undefined; throw error; });
  return ready;
}

function inspect(cell,index){document.querySelectorAll('#greeting-dots .braille-cell').forEach(x=>x.setAttribute('aria-pressed',String(x===cell)));const copy=cell.cloneNode(true);const visual=document.createElement('span');visual.className='braille-cell';visual.append(...copy.childNodes);document.getElementById('inspect-dots').replaceChildren(visual);document.getElementById('inspect-description').textContent=document.getElementById('greeting-text').textContent+' · '+(index+1)+'번째 칸 · 솟은 점 '+cell.dataset.points;}

function prepareCells(){const target=document.getElementById('greeting-dots');target.removeAttribute('aria-hidden');target.setAttribute('role','group');target.setAttribute('aria-label','인사말의 점자 칸 살펴보기');[...target.querySelectorAll('.braille-cell')].forEach((cell,index)=>{const button=document.createElement('button');button.type='button';button.className='braille-cell';const order=[1,4,2,5,3,6,7,8];const points=[...cell.children].flatMap((dot,i)=>dot.classList.contains('raised')?[order[i]]:[]).sort((a,b)=>a-b).join('·');button.dataset.points=points;button.setAttribute('aria-label',(index+1)+'번째 칸, 솟은 점 '+points);button.setAttribute('aria-pressed','false');button.append(...cell.childNodes);cell.replaceWith(button);button.addEventListener('click',()=>inspect(button,index));});const first=target.querySelector('button');if(first)inspect(first,0);}

# 굳이구지 · 피아노 v2

크리에이티브 디렉터 = 안재현. 2026-10-23.

최신 origin/main에서 분리한 `piano-finish` 관리 작업 트리에 구현했다. 기존 공유 checkout의 피아노 시제품과 카메라, 공용 랜딩·헤더·배포 workflow를 덮어쓰지 않았다. 이 버전은 공개 발행 전 로컬 검토본이다.

## 작동 범위

- 첫 화면의 실제 DOM 건반: 클릭, 물리 키보드, 다중 포인터, 가로 글리산도, 서스테인·음량. 첫 건반 입력으로 Web Audio 활성화. 녹음 음원이 아닌 합성음.
- PC C4–C6 / 모바일 C4–C5. 3D 라이브러리와 무관하게 입력 코드부터 실행.
- 마지막 연주 음과 누른 시간·진입 시 페달 상태를 관찰 기록으로 복사해 보존. 타임라인 조작은 이 기록을 덮어쓰지 않는다.
- Three.js WebGL 기구: 베지어 곡면 해머 펠트, 목재 생크·위펜·잭·반복 레버·너클·백체크·캡스턴·핀, 현과 댐퍼. 고정 축 회전, 절차적으로 생성한 목재·펠트 표면, 금속·도장 재질과 조명.
- 관찰: 타현에 소리를 동기화한 재생/일시정지/처음, 0.25·0.5·1·2배, 스크럽·Home/End·Shift+방향키, 6단계 이동, 분해·조립, 드래그/방향키 회전·휠 확대, 측면/사선, 부품 목록·모델 탭 선택, 라벨, 전체 화면(미지원 시 인라인 확대).
- 분해 중 재생·스크럽 잠금. WebGL 초기화 실패 시 작동하는 SVG 측면도로 전환. reduced-motion에서는 관찰 자동 재생을 하지 않는다.
- 제작 과정에 실제 조사·GPT 디자인 의뢰·초기 시각 실패와 코드 재구현을 기록. 크레딧은 첫 체험 하단·제작 과정·푸터에 유지.

## 실행

정적 HTTP 서버에서 이 폴더의 `index.html`을 연다. 배포 후 서버 프로그램은 필요 없다. ES 모듈을 쓰므로 파일을 file://로 여는 방식은 지원하지 않는다. 런타임 외부 CDN은 필요하지 않다. 로컬 `vendor/`의 Three.js는 기존 저장소 자산과 동일한 버전이며 MIT 원문을 함께 보관한다.

## 검증

- node --check: piano.js / observation.js / scene.js / motion.js.
- node shutter/piano/experiment.test.mjs: 현 튕김·댐퍼 감쇠·해머 타현 단일 발음·원본 기록 보존 통과.
- node shutter/piano/audio.test.cjs: 타현 오디오의 즉시 시작·음높이·정지·감쇠·첫 화면 음성 채널 보존 통과.
- node shutter/piano/motion.test.mjs: 잭 이탈 < 타현 < 반발, 누름 길이별 유한한 동작 범위, 댐퍼·페달 ON/OFF 분기 통과.
- HTML 중복 ID·상대 자산 존재·JSON-LD JSON 파싱·기존 GA 로더/config 각 1회.
- Chromium 브라우저: 흰/검은 건반 클릭, 물리 W 키의 C♯4 입력·뗌, 소리 활성 상태, C♯4/G4 관찰 전달, 단계/스크럽/Home/End/배속, 분해 중 잠금, 조립 복귀, 부품 메뉴·선택·닫기·시점 복귀 확인. 최종 브라우저 오류 로그 0개.
- CSS viewport 1440×900, 390×844, 320×667 및 844×390 확대 화면. 가로 넘침 없음, 작은 화면의 부품 사전이 화면 안에 표시됨.
- 실제 iPhone Safari·Android Chrome, 물리 다중 터치·헤드폰 음질·입력 지연·WebGL 미지원 장치는 검증하지 않았다. 브라우저 입력과 코드 검증을 실제 기기 검증으로 표현하지 않는다.

## 표현의 한계

특정 피아노의 실측 CAD·제조 설계도가 아니다. 접촉 구속·이스케이프먼트 치수·백체크 포착 조건을 물리 솔버로 검증하지 않았다. 작동 순서를 보여주는 시각 모델이며 프리뷰는 화면 비율에 맞게 가로 비례를 조정한다. 관찰 시간은 이해를 위해 확대했고, 누른 길이를 반영하되 빠른 타격 구간을 실제 측정 기록으로 표시하지 않는다. 현 진동은 과장된 시각 표현이다. 88건반, 전체 그랜드 외장, 녹음 음원·공명·조율·고장·수리는 범위에 없다.

공개 발행 URL·작품 번호가 정해지지 않아 noindex를 유지하고 canonical/og:url을 추측하지 않았다. 정식 발행 시 확정 URL·대표 이미지·공통 더보기·발행 목록 연결이 필요하다. 이번 구현에 공개 배포나 랜딩 추가를 포함하지 않는다.

## 디자인 원본

사용자 승인 레퍼런스와 GPT 의뢰·회수 원본은 공유 checkout의 `shutter/design-requests/`, `shutter/design-replies/`, `shutter/references/`에 보존돼 있다. 받은 정적 이미지를 완성된 3D 자산으로 간주하지 않고 코드로 재구현했다. 미래 시리즈 랜딩 레퍼런스는 개별 체험 첫 화면과 별개다.

2026-10-23 수정: 관찰 재생이 타현 시점을 지날 때 선택 음을 한 번 발음한다. 배속은 동작 시간에만 적용해 음높이는 유지한다. 페달 OFF는 관찰상 손 뗌에 감쇠, ON은 재생 종료까지 지속. 일시정지·스크럽·분해·메뉴·탭 이탈은 관찰 음성을 중단한다. 첫 화면 연주와 관찰은 별도 음성 채널이다. 직접 만지기에서는 현 튕기기·해머 타격·댐퍼 들기/내리기를 3D와 같은 오디오 채널에 연결했다. 관찰 기록은 보존하고, 실험 모드에서는 재생·스크럽·분해를 잠근다.

후속 보강: 직접 실험 UI와 3D 부품 탭(현/해머/댐퍼), 입력→소리/3D/관찰 기록 SVG 구조도, 첫 실패→수정→실제 연결→남은 검증의 제작 기록을 추가했다. 이 단계에서도 랜딩·타 콘텐츠·공용 파일·배포 설정은 수정하지 않았다.

후속 검수: Chromium에서 E4/A4 기록 유지, 현 튕김·댐퍼 버튼, 3D 댐퍼 직접 탭으로 들기/내리기, 실험 중 타임라인 잠금, 관찰 복귀 후 재활성화, 제작 과정 이동 시 실험 종료를 확인했다. 390×844 및 320×667 viewport에서 본문 가로 넘침 없음. 제작 구조도는 작은 화면에서 내부 가로 스크롤로 읽을 수 있다. 실제 휴대전화 검증은 별도다.

외부 원격 검토 요청에 따라 https://visual.newsis.com/shutter/piano/ 를 미리보기 주소로 사용한다. noindex 유지, 확정된 미리보기 canonical·OG URL과 실제 화면 공유 이미지를 추가했다. 공용 랜딩·발행 목록에는 추가하지 않았다.

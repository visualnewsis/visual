# GOODEASY 02 기타 · 06 바이올린 — 모델 v4

**상태: 실제 사용자 캡처를 바탕으로 수정한 Three.js 절차적 모델. 시각 품질 미승인.** 원본 v3 파일은 수정하지 않았습니다. 정밀 CAD, 음향 시뮬레이션, 실측 복원이 아닙니다.

## API / 구성

```js
import {buildGuitar} from './guitar.js';
import {buildViolin} from './violin.js';
const guitar=buildGuitar(THREE,materials);
const violin=buildViolin(THREE,materials);
scene.add(guitar.group);
// each: {group, strings:[{midi,from,to,mesh}], bow?, parts:{...}}
```

`THREE`는 기존 앱의 로컬 Three.js 인스턴스를 주입합니다. npm 추가 패키지, 외부 모델/텍스처 로더, 네트워크 요청은 없습니다. `model-utils.js`, `surface-utils.js`는 같은 폴더에 배치하세요. X는 넥→몸통, Y는 상판 법선, Z는 현 나열 방향입니다. `from/to`는 **group-local 좌표**이고 group의 변환이 항등일 때 월드 좌표와 일치합니다. 기타 MIDI `[40,45,50,55,59,64]`, 바이올린 `[55,62,69,76]`.

## 캡처에서 발견된 문제와 수정 근거

1. **기타 몸통**: 사용자 캡처에서 허리와 상·하부 바웃 전환이 급하고 장난감처럼 보임. v4는 상부 바웃 반폭 .485, 허리 .363, 하부 바웃 .632의 26개 제어점, 320개 centripetal Catmull–Rom 샘플로 윤곽을 재구성. 바디 길이 약 2.015 시각화 단위. 실물 기타의 특정 모델을 복제하지 않음.
2. **기타 측판**: 기존 v3의 단일 Shape ring extrusion 대신 outer/inner 320개 점을 대응시킨 **속 빈 벽 + 안쪽 벽 + 상하 립**의 폐쇄 표면으로 구성. `Y=.085`(상판 하부)에서 `Y=-.115`(후판 상부)까지 연결. 내측 윤곽은 중심방향 .033 근사로 실제 균일 두께 오프셋은 아님.
3. **바이올린 상판 계단**: v3 격자 셀의 centroid clipping을 완전히 제거. 윤곽을 직접 `THREE.ShapeUtils.triangulateShape`로 삼각분할한 뒤 **균일 3단계 1→4 subdivision**(이웃 셀 T-junction 없음), 거리 기반 아치 변위, 법선 재계산. +Y 와인딩 강제. 경계에서 아치가 0으로 수렴해 측판에 접속. 별도 surface-utils.js 참조.
4. **바이올린 측판**: y=-.10부터 아래로만 내려가던 v3와 달리 상판 가장자리 `Y=.106`에서 후판 상단 `Y=-.105`까지 외벽·내벽·상하 립을 잇는 hollow ribs. 상판 아치 최대 높이 약 .138. f홀은 실제 구멍이 아닌 검은 표면 근사이며 각 제어점을 새 아치 높이에 맞춰 배치.
5. **재질·구도**: 기존 기본 나뭇결 텍스처의 반복/고대비를 줄여야 함. v4 기본 나뭇결 함수는 줄 수를 줄인 임시 개선이며, **실제 목재 질감 승인 수준은 아님**. 사용자가 제공하는 wood material을 그대로 우선 적용함. 구도·조명 수치는 아래 참조.

## 여전히 미검증

- 실제 브라우저 WebGL 렌더와 세부 실루엣, 목재 텍스처의 주기성, 음영/그림자, 모델 자체 충돌·자체 관통.
- 아치 표면의 모든 삼각형 법선 및 뒷면 culling을 다양한 카메라 각도에서 확인하지 못함.
- 바이올린 브리지 발과 새 상판의 접촉을 전 영역에서 검사하지 못함. 브리지 크라운·현·활털 위치는 v3 좌표에 기초한 근사.
- f홀은 관통되지 않음. 목재 두께, 내부 브레이싱/사운드포스트/베이스바, 실제 현장력·물리 음향·마찰은 구현하지 않음.
- `hollowRibs` 내측 오프셋은 정밀 기하 오프셋이 아니라 중심방향 근사. 국부 급곡률에서 두께 편차 가능.
- 앱 CSS 겹침은 이 모듈의 수정 범위 밖. 실제 PC·모바일 FPS와 터치 입력도 미검증.

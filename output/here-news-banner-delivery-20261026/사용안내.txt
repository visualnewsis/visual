여기뉴스 플로팅 배너 · 2026-10-26

구성
- night-map.html: 선택한 지도·야경 배경 동작 예제
- navy.html: 단색 네이비 동작 예제
- here-news-banner/: 실제 삽입용 CSS, JS, 이미지
- images/: 펼침 배너·접힘 아이콘 PNG, 1배 및 2배 크기

삽입 방법
1. here-news-banner 폴더 전체를 기존 사이트의 원하는 경로에 복사합니다.
2. HTML의 </body> 앞에 아래 중 하나를 추가합니다.

지도·야경 배경:
<script defer src="/here-news-banner/banner.js" data-theme="night-map"></script>

단색 네이비:
<script defer src="/here-news-banner/banner.js" data-theme="navy"></script>

src 경로는 실제 올린 경로로 수정하세요. CSS와 이미지는 JS 경로 기준으로 자동 불러옵니다.
외부 폰트, 프레임워크, 별도 서버 프로그램이 필요하지 않습니다.
예제를 파일로 직접 열어도 볼 수 있으며, 운영 사이트 배포 전 실제 사이트에서 확인해야 합니다.

동작
- 스크롤 160px까지: 화면 하단 중앙, 460×110px
- 160px 이후: 우측 하단, 80×80px
- PC 마우스 오버: 우측에 펼침. 마우스가 나가면 접힘
- 모바일: 화면 폭에 맞게 축소, 아이콘을 누르면 여기뉴스 원문 서비스로 이동
- ×와 Escape: 아이콘으로 접음. 새로고침하면 기본 상태로 복원
- 링크: https://visual.newsis.com/newsmap/ (새 탭)
- reduced-motion 설정 시 파동 애니메이션 중지

색상과 문구
- 뉴시스 민트 #00B4C9 / 네이비 #102A38
- 여기 무슨 일 있어?
- 지도에서 뉴스로 확인
- 실제 HTML 텍스트와 원본 로고 형태 사용

배포 참고
이 패키지는 납품용입니다. 뉴시스 본 사이트 공용 영역에 자동 설치하지 않았습니다.
기존 추적 태그를 추가·변경하거나 별도 추적 ID를 만들지 않습니다.
운영 사이트의 CSP에서 해당 정적 CSS/JS/이미지 경로를 허용해야 합니다.

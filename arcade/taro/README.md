# 충무로 타로#

카드 두 장의 선택을 오늘 읽을 기사로 연결하는 VISUAL NEWSIS 인터랙티브 프로젝트입니다.

## 실행

정적 파일 서버에서 `taro/` 폴더를 열면 됩니다. ES Modules와 JSON fetch를 사용하므로 파일을 직접 더블클릭하지 말고 로컬 서버 또는 GitHub Pages에서 실행하세요.

## 데이터 연동

- `data/cards.json`: 카드 정보
- `data/results.json`: 36개 카드 조합 해석 및 기사 카테고리
- `data/articles.json`: 추천 기사 목록

향후 `js/article.js`의 데이터 공급부를 VISUAL NEWSIS API 또는 RSS 어댑터로 교체할 수 있습니다.

## 타로 카드 자료

카드 앞면은 Wikimedia Commons의 공개 도메인 Rider–Waite–Smith 덱 이미지(`RWS Tarot` 파일 세트)를 사용합니다. 해설은 전통적인 정방향 상징과 키워드를 바탕으로 프로젝트 문체에 맞게 새로 작성했으며, 특정 사이트의 문장을 복제하지 않았습니다.

## 이미지 제작

`assets/master/tarot-master.png`는 제공된 인물 사진을 정체성 참조로 사용해 70대 초반의 세련된 노신사 장면으로 제작했습니다. 얼굴형과 눈·코·입 비율을 유지하면서 자연스러운 은회색 깐머리, 짧고 정돈된 은회색 수염, 네이비 금장 더블브레스티드 재킷, 충무로의 오래된 서재와 카드 테이블을 적용했습니다. 이미지 생성은 기본 내장 이미지 도구를 사용했습니다.

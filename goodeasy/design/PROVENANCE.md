## 기타·바이올린 추가
사용자가 연결된 ChatGPT의 최신 지시를 읽고 반영하도록 이 채팅에서 승인했다. 원본 대화에서 기타를 02, 바이올린을 손목시계 다음 06으로 둔 9편 편성을 확인했다. 기타·바이올린 각각 PC/모바일/부품/조작계/명세를 추가 의뢰해 생성 보드 guitar-violin-v3.png를 다운로드했다. 이미지 생성으로 문서 ZIP이 빠져 별도 도구 제작을 다시 요청했다. 이미지의 잘못된 기타 줄 번호는 코드에 쓰지 않고 개방현 E2 A2 D3 G3 B3 E4를 적용했다.

기타·바이올린 구현 인계 ZIP GOODEASY_guitar_violin_handoff_v1.zip을 회수해 music-handoff-v1에 원본 보관했다. SVG 6개, 부품·좌표·입력·접근성 명세와 7→9편 CSV를 확인했다. 기타 줄을 가로지르는 드래그 입력과 바이올린 80ms 무이동 감지, 이동 샘플 기록을 코드에 반영했다. 생성된 참고 JavaScript는 실행하지 않고 자체 코드와 대조했다.

## 2026-10-24 실제 3D 재작업
- 사용자 품질 반려 후 ChatGPT 대화에서 실제 ES 모듈을 의뢰해 models-v2, v3, v4 원본을 회수했다.
- v2 코드에서 속 찬 기타 측판, 잘못된 프렛 거리, 누운 바이올린 브리지, 현 관통과 활 접촉 오류를 지적해 v3를 받았다.
- 실제 guitar-actual-q1.png와 violin-actual-q1.png를 ChatGPT에 첨부해 외곽 계단, 측판 단절, 나뭇결과 미감 문제를 재의뢰했다. v4는 부드러운 윤곽과 삼각분할 상판으로 교체했다.
- assets/models는 검토한 v4의 런타임 사본이다. 기타 프렛 수 메타데이터는 실제 생성 개수로 바로잡았다. Codex가 조명, 반사 환경, 구도, 모바일 확대, 현 입력 투영, 상태 연결과 별도 스위치 관찰을 구현했다.
- 낚시 릴·카메라·시계·영사기·키보드·에스프레소 머신은 Codex가 작성한 절차적 3D이며 제작사 CAD가 아니다. 피아노와 기존 shutter 원본은 보존했다.
- actual-q4 이미지는 실제 서비스 개발본의 브라우저 캡처다. 이미지 생성 보드와 구분한다.
- noindex 개발 검토본이며 실제 iPhone/Android 기기 검증과 정밀 기구 검증은 남았다.

# 통이 피아노 최신 샘플

**현재 버전은 호출형이다.** 옆 시연 패널은 제거했다. 작은 통이 호출 → 안내 → ×로 복귀. 자동 반복 등장은 없다. 상단 장면 선택은 샘플 확인용이다.

새 Mac 실행/브랜치/과거 샘플/실서비스 철회/검수/남은 문제는 [통합 인계서](../../docs/handoffs/tongi-20261107/README.md)를 먼저 읽는다.

저장소 루트에서 `python3 -m http.server 8798 --bind 127.0.0.1`을 실행하고 http://127.0.0.1:8798/output/tongi-piano-demo/ 를 연다. 현재 Windows에서는 서버가 실행 중이다. 서버 실행 상태는 다른 컴퓨터로 이전되지 않는다.

피아노 실제 원본 파일은 변경하지 않았다. 샘플 복사본에만 레이아웃 조정/강조가 있고 원본의 연주·3D 스크립트를 재사용한다. 이 브랜치를 main에 병합하거나 샘플을 실서비스에 배포하지 않았다.
